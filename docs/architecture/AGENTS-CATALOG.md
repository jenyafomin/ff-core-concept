## Рамка (из рефрейма)
Каждый агент = **оператор над графом**: читает узлы → рассуждает → пишет узлы/связи + след.
Поэтому «цель агента» = какая операция над графом создаёт ценность. Большинство агентов
**горизонтальны** (работают над любым узлом любого направления); направления дают им контекст,
а не отдельный код.

## A. Горизонтальные агенты (ядро платформы)

|---|-------|------------------------------|-----------|--------|
| 1 | **Голос→Узел** | голосовое → текст → структурированный узел с тегами/уровнями | 🟢 Легко | Whisper уже стоит; one-shot: аудио→reasoning→файл |

## B. Направление-специфичные (те же операторы + контекст)
- **Финансы:** логгер транзакций → категоризатор → агрегатор трат (🟢→🟡).
- **Разработка:** связывание задач с проектами/кодом, контекст репозитория (🟡).
- **Духовное:** дневник состояний/дыхания + синтез рефлексии (🟢 захват, 🟡 динамика).
- **Коммуникация:** люди + обязательства + задолженности (см. #13, 🟠).
- **Обучение:** планировщик курсов/программ + связи с другими направлениями (🟢→🟡).

## Главный вывод: сложность кластеризуется на ОДНОЙ оси

Сложность агентов не случайна — она зависит от одного вопроса:

> **«Нужно ли агенту действовать САМОМУ, ПОМНИТЬ между сессиями и ДОТЯГИВАТЬСЯ наружу?»**

- 🟢 **Легко** = one-shot оператор «граф → reasoning → граф». Запускаешь руками, ничего нового
  не нужно — работает поверх `docs/` + Claude Code уже сегодня. Сюда попадают 8 из 15.
- 🟡 **Средне** = нужна дисциплина структуры/консистентности (схема узла, теги, идемпотентность).
- 🔴 **Сложно** = нужна **автономия + персистентность + интеграция** (расписание, внешние API,
  состояние, оркестрация). И все 🔴/🟠 делят ОДИН корень — именно те пробелы, что назвал Скептик.

## Стратегический порядок (падает из триажа)
1. **Фаза 1 (почти бесплатно сейчас):** one-shot операторы — дайджест, разбор инбокса,
   планировщик, исследователь, черновик, «что застряло». Любой = скилл над `docs/`.
2. **Фаза 2 (дисциплина структуры):** шаблон узла/frontmatter + теггер/линкер/дедуп —
   делает агрегацию надёжной.
3. **Фаза 3 (одна трудная способность):** рантайм автономии/персистентности/интеграции.
   Он открывает СРАЗУ push-брифинг, экстракторы, трекер обязательств и Центр брейншторминга.
   Инвестировать в него стоит ОДИН раз — и осознанно, потому что это и есть зона заброса.

**Вывод для владельца:** 8 из 15 агентов можно начать хоть сегодня поверх текущего сетапа —
они и есть «лёгкое». «Сложное» — это не отдельные агенты, а одна общая инфраструктура
(автономия+интеграция), которую честнее строить позже и сознательно.
