# 90-historical — Historical / Superseded Documents

**Group purpose:** Documents that are no longer active but MUST NOT be deleted.
The rule: NEVER DELETE — move here instead. History is always preserved.

## What lives here
- `YYYY-MM-DD-HANDOFF-*.md` — session handoff snapshots (superseded by STATE.md)
- `YYYY-MM-DD-stress-test-*.md` — raw stress tests superseded by VERDICT files
- Any document marked `Status: superseded` or `Status: archived`

## Ordering rule
DATE prefix: `YYYY-MM-DD-` on all files.
Add a comment at top of each file: `# HISTORICAL — superseded by [link]`

## Process
- When a document is replaced: set `Status: superseded`, add Superseded-by link, MOVE here.
- Never edit a historical document (it is a record of the past state).
- This folder grows over time. That is correct.
