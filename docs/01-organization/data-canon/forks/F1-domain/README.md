# 🚨 F1 — «Домен» = ? (БЛОКЕР №1)

## Вопрос
Что канонически значит слово **«домен»** в субстрате? От ответа зависит нумерация `02-domains`
и половина переезда brain-единиц (R-B). Это блокер №1 — пока он открыт, всё ниже «стоит на песке».

## Варианты
- **(А) Концерн-домен** — кластер 7 ценностей по общей заботе (**D1–D4**); ось деривации
  `ценность → концерн → домен`. Тогда `02-domains` = 4 слота.
- **(Б) Data-домен** — граф-субъект: **`knowledge-graph` — единственный честный домен**, а
  Эпистемика / Витальность / Управление = грани/policy ВНУТРИ него, не отдельные домены. Тогда
  `02-domains` = 1 слот.

## Ход мысли — что учесть (открыто, не исчерпывающе)
- Слово «домен» несёт ДВА несовместимых смысла: (А) **концерн-домен** — кластер 7 ценностей по
  общей заботе (D1-D4); ось деривации ценность→концерн→домен. (Б) **data-домен** — граф-субъект:
  тогда `knowledge-graph` — единственный честный домен, а Эпистемика/Витальность/Управление =
  грани/policy ВНУТРИ него, не отдельные домены.
- Хребет сейчас говорит `01-values → 02-domains(4)`, НО 7 ценностей не выводят честно 4 data-домена
  (`knowledge-graph` — прыжок, не деривация). Это шов.
- От ответа зависит: нумерация `02-domains` (4 или 1), половина переезда R-B, downstream форки F3
  (ось `02-project`) и F4 (узел «платформа»).
- Не ограничиваясь этим, учесть: как «домен» соотносится с примитивами (спайн: домен = ГДЕ анатомия
  специализируется под правила) и не спутать домен с policy-кластером.
- Критерий выбора: что даёт честную ось деривации + checkable-предикат «какой домен получает слот
  `02-domains/`».

## От чего зависит / downstream
- **Нумерация `02-domains/`** — 4 слота (А) или 1 слот (Б).
- **Половина переезда R-B** — раскладка brain-единиц по доменам.
- **F3** — ось уровня `02-project` (что за равноправные звенья).
- **F4** — узел «платформа»/«модуль».
- **CONFUSIONS-REGISTER C8** — это тот же живой шов, презентованный как путаница.

## Ход мысли — раунд 2026-07-22 (ответ владельца + синтез)
- **Владелец (голос):** «домен для меня — больше субъект данных в графе, чем кластер забот».
  → выбор варианта **Б**, и это вскрывает корень: слово несло два несовместимых смысла.
- **Расщепление слова (следствие):** «домен» = data-субъект; группировка ценностей (бывшие D1–D4)
  — НЕ домен, а отдельное понятие (концерн-кластер ценностей) на оси ценностей, со своим именем.
- **Ложная ось убрана:** `ценность → домен` не деривация (7 ценностей не выводят домены честно —
  `knowledge-graph` был прыжком). Ценности и домены — ДВЕ РАЗНЫЕ оси.
- **Число слотов `02-domains` не фиксируется числом ценностей.** Домен = ГДЕ анатомия примитива
  специализируется под правила (спайн). Наполняется реальными субъектами данных с checkable-предикатом,
  а не «4 по заботе». Сегодня честно стоит один субстрат `knowledge-graph`; Эпистемика / Витальность /
  Управление = грани/policy ВНУТРИ него, не отдельные домены. Домены растут по мере реальной специализации.

## РЕШЕНИЕ: **Б — домен = субъект данных графа** (статус review, ждёт финального кивка → ADR)
1. «Домен» канонически = **data-субъект** (регион, где анатомия примитива специализируется под правила).
2. **Расщепить слово:** концерн-кластеры ценностей (бывшие D1–D4) — НЕ домены; отдельное понятие на оси
   ценностей, требует своего имени (открытый под-вопрос для ADR).
3. **Убрать ложную ось** `ценность → домен`; ценности и домены — независимые оси деривации.
4. `02-domains/` наполняется субъектами данных по checkable-предикату, НЕ числом ценностей. Стартовый
   честный слот — `knowledge-graph`; Эпистемика/Витальность/Управление = грани/policy внутри, не домены.
5. **Downstream:** F3 (ось `02-project`) и F4 (узел «платформа») переоценить под «домен = data-subject».
   `CONFUSIONS-REGISTER C8` можно закрывать этим решением.
