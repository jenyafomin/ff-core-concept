# 🧭 Реестр путаниц (systemic disambiguation)

> **Зачем.** Мы повторяем одни и те же путаницы каждую итерацию. Вместо того чтобы
> объяснять их в чате заново — **они живут ЗДЕСЬ как знание.** Новый агент, которому не
> сказали ни слова, натыкается на путаницу → находит этот файл → **сам разрешает.** Это и
> есть «системное решение»: контекст сам подсказывает, что чем является.
>
> **Растёт.** Каждый раз, когда холодный агент/владелец спотыкается о неоднозначность —
> добавляем строку. Источник живых кейсов — blind-comprehension эксперимент (см. Related).

## Правило пользования
Наткнулся на «две вещи выглядят одинаково / что каноично?» → **сначала сюда**, потом действуй.
Не нашёл строки → это НОВАЯ путаница: разреши с владельцем и **допиши строку** (LOSE-NOTHING).

## Механизм роста (система, не разовость)
- Новая путаница → строка здесь + (если каноничная развилка) → `FORKS-open.md`.
- Спайн-концепт (`spine.concept.json`) держит краткий `disambiguations[]` и **роутит сюда** за полным списком.
- Цель: чтобы «решать путаницы» не требовало человека — репозиторий отвечает сам.
