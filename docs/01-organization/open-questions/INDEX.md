## Как пользоваться
- Любой агент, породивший вопрос владельцу/к дизайну, **ОБЯЗАН завести строку здесь** (id · вопрос · статус · где живёт).
- Статусы: `open` (ждёт ответа) · `answered` (владелец ответил → ссылка на решение) · `parked` (отложен осознанно) · `obsolete`.
- id формата `Q-YYYY-MM-DD-NN`. Отвеченный вопрос НЕ удаляем — меняем статус + линкуем решение (провенанс).
- Разросшийся кластер вопросов → выносим в под-папку, здесь оставляем строку-указатель.
