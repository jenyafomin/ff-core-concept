# БАГ шлюза: интерактивные кнопки AskUserQuestion не доставляются

> Дом починки — шлюз `agents-manager` (`/Users/mac16/Documents/IT/Apps/TOOLS/agents-manager`).

## Симптом
Интерактивные кнопки **AskUserQuestion** НЕ доходят до владельца через шлюз agents-manager —
владелец видит **только текст**. Вопрос с вариантами-кнопками теряется (владелец не получает выбор).

## Следствие для агентов
Любой агент, работающий **ПОД шлюзом**, должен задавать вопросы **обычным текстом** и **никогда не
полагаться на AskUserQuestion** для получения решения владельца. Варианты выкладывать текстом (список),
ждать текстовый ответ.
