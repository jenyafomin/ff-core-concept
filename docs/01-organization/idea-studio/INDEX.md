# Идейная студия — указатель

Двойник «Идей»-студии из проекта-шлюза (agents-manager), перенесённый в FF **с памятью**.
Способ: раскладываем ценности на **направления (в FF — концепты)** и идеи **по файлам**, сквозное
поднимаем в **инфраструктуру** — сосед ценностей. Всё — артефактами, а не в чате.

## Файлы

| Файл | Что внутри |
|------|-----------|
| `METHOD.md` | Метод: лестница цель→ценность→направление→идея→инфраструктура; формы папок; развилки; правило подъёма в инфраструктуру; циклы самокритики; **память**. |
| `MEMORY.md` | Живая память студии: где что лежит · решённое · открытые развилки · журнал сессий. Читать в начале хода, дополнять в конце. |
| `TOPIC-PROMPT.md` | Готовый «мозг» топика (текст для `/prompt` нового топика-студии). |

## Как завести живой топик (один ручной шаг владельца)

1. Создать топик в FF-группе Telegram.
2. В нём: `/bind /Users/mac16/Documents/IT/Apps/FF-Personal-Managment` (иначе топик уйдёт в cwd группы — Cardex).
3. Вставить `/prompt` с текстом из `TOPIC-PROMPT.md` (или дать мне номер топика — положу `PROMPT.md`+`config.json` сам).
