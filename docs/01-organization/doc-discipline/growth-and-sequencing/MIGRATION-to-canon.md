# 🧭 MIGRATION-to-canon — как привести существующий (замусоренный) проект к канону `doc-tree.md`

> Переиспользуемый чек-лист. Обобщён из 8 шагов R-A (`restructure-2026-07/README.md`), но применим к ЛЮБОМУ
> проекту, где дерево доков разъехалось. Строгость: soft — наводить порядок отдельным прогоном, warn-не-block.
> **На диск — только по явному «строй».** Каждая фаза обратима (редирект-стаб, не `rm`; статус, не удаление).

## Фазы (по порядку; каждая ссылается на закон doc-tree.md)

**A · Снять карту.** Сгенерировать авто-вид дерева (`node tools/lint/doc-tree.mjs` или аналог), отметить папки
с перегрузом (много loose-файлов разных типов) и конкурирующие «читай первым». _Закон №8_ (авто-вид > рукопись),
_№4_ (loose = запах). Ничего не двигаем — только диагноз.

**B · Стейджить loose-файлы в plural-контейнеры.** Груда карт → `maps/`; предложения → `_proposals/`; разбор →
свой плюрал (`analyses/ questions/ decisions/`). Датированные версии кладём В ОДНУ папку. _Закон №4_ (группируй по типу),
_№2_ (один дом на тему), _№6_ (плюрал-контейнеры без номера, файлы внутри нумеруются).

**C · Свести дубли-поколения → редирект-стабы.** Несколько поколений одного концепта → у старых корневой
`_ARCHIVED.md`/шапка-указатель на актуальный дом; тело НЕ трогаем. _Закон №9_ (статус, не удаление), _№10_ (LOSE-NOTHING:
новее побеждает как направление, ничего не стирается).

**D · Один канонический вход.** Убить конкурирующие «читай первым»: ровно один навигатор-вход (напр. `INDEX.md`),
прочие «read-first» переразмечены в роли (живой стейт / архив). _Закон №8_ (один навигатор на трек; INDEX = единственная точка входа).

**E · Коммит-чекпоинт ПЕРЕД и ПОСЛЕ каждого крупного переезда.** commit до перекладки ≥N файлов; после — `git diff --stat`
+ unit-survival чек (каждая несущая единица «был→стал» на месте), затем commit. Анти-P01 (перекладка роняет предыдущую). _Закон
«строгость/исполнение»_ (переезды обратимы, план отката до миграции).

**F · Related-link check + regenerate auto-view.** После каждого переезда — проверить, что нет битых ссылок (критерий «готово»),
перегенерировать авто-вид дерева, подтвердить, что 🔴-перегрузы упали и стабы видит машина. _Закон №8_ (правдивый авто-вид).

## Провенанс
Первый исполненный экземпляр этого playbook = R-A (`../restructure-2026-07/README.md`). Deliverable S06-5 = этот файл.
После уборки проект переходит в режим контролируемого роста — см. CGC (`./CONVENTION-controlled-growth-cycle.md`).
