# Doc Discipline — стандарт документации

> Как устроена сама эта система документов: статусы, именование, где что лежит.

Что сюда кладём:
- Конвенция именования и статусов (наследник `docs/topics/00-canon/DOC-CONVENTION.md`).
- Правило роста дерева: узел = ФИНАЛ (файл) либо АБСТРАКЦИЯ (папка заранее).
- Правило «никогда не удалять — помечать archived/superseded».
- Карта frontmatter-полей (Status, Owner, Date, Scope, Related).
