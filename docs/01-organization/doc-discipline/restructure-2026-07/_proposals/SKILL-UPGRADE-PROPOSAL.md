# 🔧 doc-discipline — апгрейд (синтез критик × абстракт-мыслитель)

> ⚠️ **НЕ применено.** Правки скилла/реестра/хуков = R1–R3 → через `agent-builder` **после «да» владельца**.
> Здесь — согласованный диф + обоснование. Источник: 2 фоновых агента (2026-07-19).

## Организующий принцип (абстракт-мыслитель)
**«ТИП решает ДОМ».** Размещение перестаёт быть *решением* и становится *следствием*: концепт объявляет
тип → тип объявляет дом (через `homeRule` в реестре) → файл сам себя маршрутизирует. Желание владельца
«общаться концептами с id» — это **вход маршрутизации**, не стиль. Всё остальное — либо дом (истина),
либо указатель (вид), либо стейджинг, текущий к дому.

## Корневая причина повторных ошибок (критик)
Правило R1 **никогда не было вшито в живой `SKILL.md`** — патч 2026-07-17 остался «не применён»
(блокировка записи вне `.claude/`), и петля не закрыта. Я не мог следовать правилу, которого нет в
файле, что читаю. Плюс `section-types-registry` **до сих пор предписывает** `decisions/`-кучу (устарело,
противоречит O-14). Проверка нумерации/ссылок — «по памяти», а не хуком.

## Разделение труда (канон, абстракт-мыслитель) — во избежание размножения ролей
| Часть | Единственная работа | Шов к следующему |
|-------|--------------------|------------------|
| concept-first | КАК думаем + тип ВОПРОСА в `concept.json` | сигнал «кристаллизовать» + типизированный концепт → doc-discipline |
| doc-discipline | ГДЕ живёт (тип файла/папки, R1, один дом) | резолвит `homeRule` → план размещения → библиотекарь |
| библиотекарь | *раннер* doc-discipline: осушает `_inbox` → дома | пишет дома + регенерит авто-виды/указатели |
| `_inbox` | буфер-стейджинг произведённого (в git, не истина) | библиотекарь опустошает |
| `_logs` | тонкий след диалога-как-темы (gitignore, только указатели) | `canon_links` наружу в дом |
| session-logging | *процедура*, ведущая `_logs` (NN, concept.json, STATE sync) | пишет `canon_links` в дома doc-discipline |

## 🔴 U-6 — реальное противоречие (нашёл абстракт-мыслитель)
| | `session-logging` (существующий скилл) | `_logs` (мой MAP-target §C) |
|--|--------------------------------------|------------------------------|
| путь | `logs/conversations/NN/` | `docs/_logs/` |
| имя | по номеру `NN` | по **дате** |
| сырой запрос | **НЕ хранить** | «запрос (чистый, копипаст)» — **хранить** |
Одна сущность — противоположные конвенции. **Рекомендация:** победа за последней директивой владельца
(«хранить чистый запрос») → `_logs/` (underscore) + **дата + NN**, хранить чистый запрос; обновить
`session-logging` под это через agent-builder. **Ждёт твоего решения.**

## Что НЕ ломать (критик)
Двухфазность **«сначала опиши — исполняй по „строй“»** и рефлекс **консолидируй-первым/один-дом**
работают. Хук ужесточает ТОЛЬКО механическое (нумерация, ссылки) — не трогает обратимый гейт.
