## Боль (что сигналит проблему)
Заходишь в `docs/02-project/core/01-brain/` — а там **папки без нумерации** и **файлы валяются в корне**.
Плоский безномерной корень = смелл: «здесь что-то сделано неправильно». Правило: **у всего свой дом и
номер**; loose-файлов в корне быть не должно.

## Как исполнять — по ЭТАПАМ (главный концепт, см. аспект 10)
НЕ разом. Идём **папка за папкой / уровень за уровнем**; на каждой задаём вопрос **«что должно быть в этой
папке, чтобы она была ПОЛНОЙ?»** (цель · анализы · decisions · вопросы · идеи). Рекурсивно: глобальные уровни —
по несколько проходов, глубже — реже, но с вниманием к деталям. Механика переноса — тем же протоколом
(карта from→to → builder `git mv` LOSE-NOTHING → проверки оркестратора → правило в `doc-discipline` + линт).
