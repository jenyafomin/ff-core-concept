# 05 · Паттерн «`01-overview/` первым»

## Смысл (голос владельца)
Каждая нумерованная область начинается с **`01-overview/`** = «как мы понимаем контекст». Там —
**концепт и идеи** (что вообще делаем, во что смотрим), прежде чем разворачивать нумерованных детей.

## Рекурсивно
- `01-brain/01-overview/` → концепт brain + `01-values/`, `02-domains|modules/`.
- `02-infrastructure/01-overview/` → общий разбор: что нужно в инфре + вопросы + понимание БД.
- Тот же паттерн в любой новой крупной области.

## Что кладём в overview
- **Концепт** (одной картиной, высотно) — родня `concept-first`/`*.concept.json`-навигатору.
- **Идеи** — типы `idea`/`ideas` (заведены 2026-07-20): одна идея = `.idea.md`, агрегатор = `ideas/`.
- Overview — стейджинг понимания; по мере созревания **кристаллизуется** в нумерованных детей
  (values → domains → …), а сам остаётся ВИДОМ-входом.

## Отличие overview от topics
- `overview` = постоянный **вход-обзор** области (ВИД, живёт всегда).
- `topics/` = **временный** стейджинг обсуждения, обязан мигрировать (аспект 03).
