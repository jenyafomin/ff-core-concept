### Модель логов (`_logs/`, из речи владельца) — сессия-как-тема
Новая тема = папка с **датой создания**; внутри — по папкам, **свой номер** (= номер этого диалога). На каждый ход диалога:
1. **запрос** (чистый, копипаст из чата),
2. **разбор** (как понял/разложил),
3. **возможный результат** = **чистый концепт** (лучше `*.concept.json`, который перечисляет) или файл.
→ Дальше стараемся общаться **концептами**. (Формализовать в скилле `session-logging`.)
