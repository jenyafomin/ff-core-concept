## Новые узлы (расширение грамматики)

- **N-008 · principle · Папка типов с версиями.** В каждом проекте — папка со структурами всех
  известных типов; у типа могут быть версии (напр. `анализ v1` / `v2`); тип самоопределяется во
  frontmatter самой папки («эта папка — анализ, v2»).
- **N-009 · principle · Индексы-навигация с агрегациями.** Индексы помогают «путешествовать» по
  папкам и **агрегируют по группам** (аналитика · вопросы · идеи) на уровне проекта. Идея может
  жить **проектно-глобально** или **локально** в конкретном месте.
- **N-010 · concept · Домены.** Единая точка, где определяются домены. Домен подразумевает ~8-10
  пунктов. У каждого домена **может быть своя структура** (описана во frontmatter, переписываема со
  временем), выраженная **правилами**. Пример: `backend` → endpoints; `frontend` → hooks / infra.
- **N-011 · principle · Правила как wildcard/паттерн, не путь.** Правило не про конкретный путь, а
  про шаблон: «если в проекте есть `backend`, то внутри появляется особый тип папок». **Scope
  правила:** либо только на этом уровне, либо baked/по всему дереву. Правило = **категория +
  структура** (два измерения).
- **N-012 · principle · Группы приоритета по символу-префиксу.** Несколько групп информации,
  задаваемых префиксом (`_`, `%`, `+`, …); символы несут **приоритет** (кто выше/ниже) и
  группируют содержимое.
- **N-013 · principle · Рост: дата → перегруппировка.** По умолчанию новый поток =
  последовательность по дате (новый чат = дата-поток). Затем — **перегруппировка/переосмысление**
  (объекты растут постепенно, сразу не угадать). Но **стараться предугадывать** внутреннюю
  структуру папок (напр. `ideas` → сразу папка-под-идею; `index` показывает на группы:
  backend-идеи / frontend-идеи).
- **N-014 · constraint · Нужна БД.** Полной индексации «скрытым анализом» не добиться → нужна
  **база данных**. Структура строится в координации с БД/субстратом, **планируем со стороны brain**.
- **N-015 · open-question → агентам · Проверить против ценностей brain.** Оправдывает ли
  memory-unit-дизайн (7 ценностей) модель «**ячейки памяти → группы → самосвязывающийся граф**»
  (глобально: группа 1, группа 2; внутри проекта — свои; self-link как граф всех данных).
- **N-016 · decision · Складывать в правильное место.** Вопросы/идеи по brain — **сразу в brain**;
  внутри `core/brain` можно завести особые делящие папки. Инвариант: каждая папка **расширяется
  вглубь как дерево**, НО любая созданная папка **описана определённой структурой** (или пишется
  новый вариант описания).
