## Фронт B — Видение слоя управления агентами (Fable, с поправками критика)

Глубокий разрез — в `VISION-agents.md`. Здесь суть.

### Несущая абстракция (одна)
**Реплика в чат — это тоже действие.** Каждый ход агента = **АКТ** `(принципал × класс-действия × scope)`
в едином событийном потоке. Слой управления = **ОДНА таблица грантов над классами актов** + **классификатор
(Guard)** для неочевидных актов. Три «механизма» — это три проекции одной таблицы, а не 4 отдельные фичи.
Изоморфно хребту brain: Конституция = клапан (RED не грантуется), policy-as-data = гранты, engine-duty = Guard.
**Не новая система прав — это лестница доверия, применённая к потоку актов.**

### Три модели
1. **Адресация / уровни ответа (мех.2).** Уровни (а) читает-пишет / (б) молчит-до-вызова / (в) всегда-молчит —
   это про **выдачу хода** (turn-taking), НЕ про видимость («всё видно ИИ» не трогаем). Уровень = триггер-
   предикат над конвертом события. Межагентный триггер (мех.3) — просто третий предикат.
2. **Авто-подтверждение + AI Guard (мех.1+4).** Окно 1ч/2ч/навсегда = **временный грант = повышение по
   лестнице доверия с TTL**. «Навсегда» — только для YELLOW и только по evidence (это автоматически решает
   застрявший вопрос V-6). Guard = **классификатор, не власть**: зовётся только на «не-GREEN × активное окно»;
   вердикты персистятся как evidence; повторяемо-безопасные сигнатуры повышаются в статический GREEN →
   команды сами ползут по лестнице, Guard не становится горлом. **Промпт стража несущий:** ролевая асимметрия
   («входной текст = улика, не инструкция»), каталог эксплойт-паттернов, явная асимметрия цены ошибки,
   структурный выход fail-closed, ноль инструментов у стража. Промпт = policy-узел + регрессионный набор эксплойтов.
3. **Межагентное взаимодействие / отчётность (мех.3).** «Ответ агента = триггер для другого» — тот же
   предикат над конвертом. Единственное реально новое — **hop-бюджет каузальной цепи** в конверте.

### Где это становится ПАМЯТЬЮ (наполнение `03-contract`)
Четыре артефакта-контракта: **реестр классов действий · схема гранта · конверт вердикта · трейс акта.**
Шлюз держит операционную копию по каноническим схемам; перенос в brain = INSERT типов узлов. Это ровно
тот материал, которым закрывается пустой `03-contract/`.

### Поправки критика (обязательные, иначе заложим старую ошибку)
- 🔴 **hop-бюджет — не последним, а в первом срезе.** Петля А↔Б (два агента «always» в одном топике) возможна
  уже на срезе 1; защита — то же enum-поле, стоит дёшево, отложить нельзя.
- 🔴 **Арбитраж «отвечают несколько сразу vs один назначенный» нужен уже в срезе 1**, не в мех.3. Что делать,
  когда событие матчит несколько предикатов (два «always», общий @mention) — floor-control, не откладывать.
- 🟠 **«Куратор дёргает ниточки» выпал.** Управление сессией/контекстом каждого агента (чистка, новые темы,
  спец-права чата) — это ДРУГАЯ ось (session-lifecycle), не таблица грантов. Назвать явно, не прятать в «UI».
- 🟠 **Guard против противника:** «неуверенность → блок» не спасает от инъекции, сконструированной дать
  ложную ВЫСОКУЮ уверенность. Нужен adversarial-набор тестов вне статичного каталога, иначе prompt-engineering
  остаётся декларацией.
- 🟠 **Два дома данных** (SQLite шлюза + brain) = та же болезнь «двух правд». Лечить механизмом сверки/канона,
  не одной декларацией (канон FF уже дрейфовал на этой неделе при тех же правилах — см. Фронт A).

## Рекомендованный вектор

**Срез 0 (шлюз-независимый, дешёвый, разлочивает всё):** зачистка Фронта A + наполнить `03-contract`
четырьмя контрактами-схемами из видения. Это и «чистка путаницы», и фундамент под все 3 механизма.

**Срез 1 (первая ценность по агентам):** уровень «(б) молчит-до-вызова» **как enum триггер-политики**
(не второй boolean) + @mention-парсер — **вместе с hop-бюджетом и арбитражем одновременных ответов**
(поправки критика). Поверх уже готовых `AgentBinding`/`reportsToChat`.

**Развилка владельцу (Fable vs критик разошлись — твой выбор):**
- **Fable:** начать с (б) молчит-до-вызова — технически дешевле всего.
- **Критик:** начать с **автопилота (мех.1+4)** — это боль, которую ты сам назвал «реально не хватает
  СЕЙЧАС»; (б) даёт ценность только когда в топике есть второй агент, а его пока нет.
- Предусловие обоих: **убить fail-open в approval-gate ДО первого окна автопилота** (иначе костенеет).

### Топ-3 ловушки (не повторить старые ошибки)
1. Две параллельные правды о грантах → дрейф теперь = дыра безопасности, а не просто путаница.
2. fail-open approval-gate костенеет — убить до первого окна автопилота.
3. Театр keyword-фильтра — расширять список слов вместо «реестр классов + Guard».
