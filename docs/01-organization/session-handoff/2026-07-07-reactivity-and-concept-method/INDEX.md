## ▶ Мини-хендофф темы 03 (СТАРТ СЛЕДУЮЩЕЙ СЕССИИ)
**Цель:** углубить 7 ценностей в КОНЦЕПТЫ (L2) → затем идеи (L3).
- Ценности примерно описаны (`02-project/core/01-brain/values/V1…V7`), базис собран; часть FQ ещё открыта.
- **Метод (из нового промта):** по каждой ценности спросить «X — ЧЕГО именно?» → развернуть в
  ВАРИАТИВНОСТИ/векторы = концепты («что и как именно делаем»). Держать **абстрактно, но чётко**;
  НЕ падать в банальные инструменты (фильтры и т.п.). Критика — дополняющая.
- Идеи (L3) пишутся ПОЗЖЕ, внутри папки соответствующей ценности (идея-1,2,3), каждая = решение
  конкретной проблемы + паттерн из CS.
- **Кандидат начать:** Ц-2 Тождество («тождество — чего?») или пройти все 7 одним кругом «X чего именно?»
  для карты, затем углубляться. Владелец выберет порядок.
- Не забыть подтянуть кейс «реактивность» как готовый стресс-тест концептов (что он вскрыл по каждой ценности —
  уже в таблице §5 синтеза).
