# Session Handoff — точка восстановления

> Чтобы контекст не терялся при компакте и сессии не коллидили. Читать ПЕРВЫМ при возобновлении.

Что сюда кладём:
- `STATE.md` — канонический снимок «где мы» (наследник `docs/base/STATE.md`).
- Хендоффы по дате (`YYYY-MM-DD-HANDOFF.md`) — снимок сессии, не перетирает предыдущие.
- Логи агентских прогонов — ТОЛЬКО ссылками (основная работа живёт в документах доменов).
- Правило: одна сессия = один файл-хендофф; старые не удаляем.
