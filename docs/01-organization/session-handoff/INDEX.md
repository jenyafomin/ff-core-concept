# Session Handoff — точка восстановления

> Чтобы контекст не терялся при компакте и сессии не коллидили. Читать ПЕРВЫМ при возобновлении.

Структура (см. скилл `session-logging`):
- `STATE.md` — живой снимок «где мы», читать первым.
- **Сессия = ПАПКА** `<дата>-<контекст>/` (напр. `2026-07-06-reorg-brain/`):
  - `INDEX.md` — хендофф сессии (список тем + сделано/нет).
  - `NN-<тема>.md` — тонкий лог темы: суть · агенты · решения · **→ проекция в канон-док**.
- **Тема = проекция документа**, а не копия контента: логи ссылаются на реальные доки, не дублируют.
- Старые сессии не удаляем; тема разрослась → становится папкой (правило роста).
