# Тема 02 — Общие типы-разделы + правило роста

## Что обсудили
- Типы (`values/scenarios/decisions/open-questions/todo/plan`) — переиспользуемые ШАБЛОНЫ (аналогия «домен»),
  а не папки одного модуля.
- Разводка «4 дома»: вопрос-владельца / вопрос-агента / задача / решение — не смешивать.
- Правило роста: **абстракция = папка, финал = файл**; структуру не знаем наперёд → идём последовательно
  (даты/номера), пересобираем в структуру позже.

## Решения
- Реестр типов в `doc-discipline`; правило роста зафиксировано отдельным узлом-папкой.
