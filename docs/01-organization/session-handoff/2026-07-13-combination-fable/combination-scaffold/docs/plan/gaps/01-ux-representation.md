# GAP-01 · План не учёл слой представления/UX концептов

## Суть
План «Combination» описал контракт модулей и версии, но НЕ описал, **как человек и агент это просматривают**:
- два экрана (кнопки ↔ контент),
- два режима (визард-последовательность / дерево по логике концептов),
- копируемый полный путь, короткие title, области видения/комментариев.

## Почему важно
Без слоя представления «объединение» есть только в смысле (граф связей), но не в виде — текст сыплется в
чат. Это прямой источник проблем PRB-01/02/03.
