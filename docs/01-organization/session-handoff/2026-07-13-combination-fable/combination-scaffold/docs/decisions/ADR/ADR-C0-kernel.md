# ADR-C0 — Kernel, seed-словарь и апгрейд ядра

- **Status:** draft (proposed) · Owner: jenya.stasik@gmail.com · Date: 2026-07-13
- Related: `../DECISIONS-LOG.md` (CDL-01,02), `../../infrastructure/INDEX.md` (M0), `../../SURVIVING-CUT.md` S1

## Context
Чтобы Brain, шлюз и прикладные модули стали экземплярами одного класса «модуль», нужно отделить то, что
модулем быть НЕ может (иначе реестр модулей жил бы в удаляемом модуле, а Конституция снималась бы
деинсталляцией — циркулярность). Critic показал: наивная формулировка «ядро свободно от словаря» ложна —
ядру нужен минимум доменных типов, чтобы вести реестр.

## Decision
1. **Kernel = неудаляемое ядро:** движок субстрата (nodes/edges, canonical_id, bitemporal) + Конституция
   (инварианты) + реестр типов + шина портов + integrity-обязанности.
2. **Seed-словарь ядра:** `Module, Manifest, Version, Type, Port, LineageEdge` — регистрируются самим ядром
   на bootstrap (self-hosting: ядро описывает себя своим же словарём до появления внешнего реестра).
3. **Апгрейд ядра — отдельная ось (kernel-ABI версия):** ЕДИНСТВЕННОЕ место, где допустима настоящая
   миграция субстрата (смена алгоритма canonical_id, формата bitemporal). Редкое governed-событие, НЕ через
   INSERT-not-migrate, с планом отката. Модули апгрейдятся линзами (ADR-C2); ядро — миграцией.

## Alternatives considered
- **Brain целиком = модуль** — отвергнуто: циркулярность, Конституция деинсталлируема.
- **Ядро без seed-словаря** — отвергнуто (critic): реестр невозможен без доменных типов.
- **Апгрейд ядра теми же линзами** — отвергнуто: формат хранения самого ядра меняют линзы поверх? нет,
  линза предполагает стабильный формат хранения.

## Consequences
- (+) Чистая граница; dogfooding (реестр = узлы на субстрате).
- (−) Нужен явный bootstrap-протокол и редкий, но реальный механизм миграции ядра (сложность есть, спрятать
  нельзя).
- Открытый вопрос CQ1: детальный протокол апгрейда ядра.

## Validation
- Тест: система поднимается «с нуля» и регистрирует свой seed-словарь без внешнего реестра.
- Тест: смена kernel-ABI версии на игрушечном изменении формата проходит с откатом.
