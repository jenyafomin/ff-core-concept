# ADR-C3 — Port Bus / Capability Broker (черновик-контекст)

- **Status:** draft (context only) · Owner: jenya.stasik@gmail.com · Date: 2026-07-13
- Related: M3, `../DECISIONS-LOG.md` (CDL-12), Engine Contract #15 (Brain)

## Context
13 портов шлюза (IChannel, IAgentRunner, IApprovalGate…) + Engine Contract #15 Brain + key-custody нужно
свести в единую **шину способностей**: модуль объявляет требуемые/предоставляемые порты, ядро сводит.
Critic: порт несёт ПОВЕДЕНИЕ, не только форму → шина должна проверять поведенческий контракт.

## Decision (направление, не финал)
Порты = «валюта модулей». Object-capability модель: модуль получает только объявленные способности.
Поведенческий контракт (идемпотентность/доставка) декларируется и проверяется contract-тестами (M4).
Key-custody: кто держит ключи при форке/переносе.

## Открыто
Гранулярность способностей; связь с sandbox (M7/CQ3). Детализировать, когда манифест «Плана» затрещит на портах.
