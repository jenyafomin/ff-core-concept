# Combination — открытые вопросы (CQ)

- **Status:** active · Owner: jenya.stasik@gmail.com · Date: 2026-07-13
- Источник: возражения critic + слепые пятна Fable. Формат: вопрос · почему важно · статус.

| CQ | Вопрос | Почему важно | Статус |
|----|--------|--------------|--------|
| **CQ1** | Как апгрейдить сам kernel (canonical_id-алгоритм, формат bitemporal)? | единственное место настоящей миграции субстрата; INSERT-not-migrate тут не работает | 🔴 open → ADR-C0 раздел |
| **CQ2** | Порядок/конфликт линз при мульти-lineage (узел от двух предков)? | коммутативность не гарантирована; чтение неоднозначно | 🔴 open → ADR-C2 |
| **CQ3** | Модель sandbox/capability для исполнения ЧУЖОГО кода против общего субстрата с PII? | крупнейшее упущение Fable; без неё marketplace небезопасен | 🟡 open → M7/ADR-C4 |

| **CQ7** | PII/право на забвение truth-узлов vs INSERT-immutability | шире слепого пятна А; юр-риск by design | 🟡 open → связать с Brain hard-erase |
| **CQ8** | Канал обновления форка (upstream-patch notification)? | lineage статичен; форк не слышит патчи предка | 🟢 later → CV3 |

## Как закрывать
Не гадать. CQ1/CQ2/CQ6 — первыми (лежат на M0/M2/M1, фундамент). Метод закрытия — «первый боевой ход»:
написать манифест «Плана» и прогнать через него шлюз; где манифест затрещит — там вопрос становится ADR.
