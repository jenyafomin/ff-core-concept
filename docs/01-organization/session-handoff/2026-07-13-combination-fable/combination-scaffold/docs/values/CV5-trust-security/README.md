## Чего именно

## Направления
### D5.1 — Sandbox исполнения чужого кода (несущая, NEW)
- **Развилка:** чужие линзы и портовые адаптеры исполняются против общего субстрата с PII. Нужна
  **capability/sandbox-модель** (что модулю дозволено; изоляция). Кандидат-паттерн: object-capabilities +
  тонкий sandbox-рантайм Combination (M7). Пока владелец единственный автор — можно ослабить, но заложить.
### D5.2 — Provenance утверждений
- **Развилка (решена как обязательное):** штамп `module@version` на КАЖДОЙ записи (ретрофит невозможен) → M4.
### D5.3 — Install-time scope прав
- Модуль на установке декларирует требуемые порты/данные; ядро валидирует политики ≤ Конституции; approval-
  гейт на install (переиспользовать гейты шлюза).
