## Чего именно (объекты)
Lineage форка; объявленная совместимость; конкурирующие версии/форки; канал обновления форка.

## Направления

### D3.1 — Форк и его связь с оригиналом
- **Развилка (решена):** форк = новый `module_id` + **lineage-ребро** на родителя + унаследованные
  canonical_id типов предка. Форк без изменения словаря = **drop-in замена**. Расширил словарь → объявляет diff.

### D3.2 — Закон совместимости
- **Развилка (Fable → правка critic):** совместимость = **пересечение словарей по диапазонам версий**.
  Правка: НЕ только словарь — второй гейт **поведенческий контракт порта** (at-least-once vs exactly-once,
  идемпотентность). Манифест декларирует поведение; conformance-suite проверяет. Конституция = **пол**.

### D3.3 — Конкурирующие версии и канал обновления форка (NEW, critic)
- **Развилка:** два форка «Плана» взаимозаменяемы, пока говорят на `Task@2`. Но lineage статичен — если
  предок починил баг, форк не узнаёт.
- **Идея:** опциональная подписка **upstream-patch notification** (форк слышит патчи предка). Позже.
