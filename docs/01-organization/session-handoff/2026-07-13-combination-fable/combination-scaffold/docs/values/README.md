# Ценности Combination — компас

- **Status:** draft — cycle 1 (расхождение BA + схождение Fable/critic) · Owner: jenya.stasik@gmail.com · Date: 2026-07-13
- Метод: value-decomposition (различай вниз — объединяй вверх). Источник расхождения: `../../VALUES-diverge-BA.md`.

## Цель (корень)
Объединить память (Brain) и исполнение (шлюз) в одну систему, где способности подключаются **модулями как
marketplace** — с апгрейдами и совместимостью версий поверх живой БД. См. `../product/VISION.md`.

## 6 ценностей (грани цели)

| # | Ценность | Чего именно (объекты) | Приоритет | Задевает инфру |
|---|----------|------------------------|-----------|----------------|
| **CV1** | **Модульность / подключаемость** | единица «модуль», манифест, граница kernel/module, реестр/discovery, изоляция сбоя | **must-now** | M0, M1 |
| **CV2** | **Эволюционируемость без поломок** | «новая версия», апгрейд-как-добавление (bitemporal), линзы, откат, видимость апгрейда | **must-now** | M2 |
| **CV3** | **Совместимость и форки** | lineage форка, объявленная совместимость, конкурирующие версии, канал обновления форка | **must-now** | M2, M8 |
| **CV4** | **Суверенность / переносимость** | export/import, key-custody, «один субстрат vs федерация», cutover | soon | M6, M3 |
| **CV5** | **Доверие / безопасность чужого кода** | install-time scope прав, provenance модуля, sandbox/staging чужого кода | soon | M4, M7 |
| **CV6** | **Marketplace-экономика** | author/license, обмен, рейтинг/доверие автора | later | (поля манифеста) |

## Правило подъёма в инфру (теги)
Идея с ≥2 тегами ценностей → сквозная → поднимается в `../infrastructure/`. Примеры сквозных: «модуль как
узел графа» (CV1+CV2), «PEP-на-модуль» (CV1+CV5), «INSERT-not-migrate как версионирование» (CV2+CV3),
«форк-как-lineage-ребро» (CV1+CV3), «мост Brain↔шлюз» (CV1+CV4).

## Направления по ценностям — см. `CVn-*/README.md`
Каждая ценность вскрыта на 2–4 направления с развилками и пулом идей. must-now (CV1–CV3) проработаны
глубже; CV4–CV5 — до развилок; CV6 — заметка «дёшево сейчас».
