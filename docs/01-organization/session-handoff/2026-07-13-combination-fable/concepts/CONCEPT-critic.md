# CONCEPT — critic: попытка опровергнуть разрез Fable

- **Type:** raw (сырой вывод агента critic) · **Status:** done · Date: 2026-07-13
- **Concept (выжимка):** направление Fable верное, но 5 из 6 тезисов «трещат», тезис 5 «Combination без
  движка» — падает. Форсированные правки уже сведены в `../SURVIVING-CUT.md`. Ниже — сырьё целиком.

## Вердикты по тезисам
| # | Тезис | Вердикт | Что ломается |
|---|---|---|---|
| 1 | Kernel vs Module | ТРЕЩИТ | bootstrap-циркулярность (kernel сам тащит словарь); апгрейд kernel не описан |
| 2 | Манифест / Postgres extension | ТРЕЩИТ | линза=код → код участвует в совместимости; аналогия рвётся на поведении портов; нетотальные линзы |
| 3 | Один субстрат + scratch | ТРЕЩИТ | «федерации нет» ложно сейчас; erase scratch без синхронизации с truth = тихая потеря аудита |
| 4 | Апгрейд-линза / форк | ТРЕЩИТ | цепочки линз дороги; кэш=копия конфликтует со слепым пятном A; порядок линз при форке не определён |
| 5 | Combination = контракт, не движок | ПАДАЕТ | conformance-suite требует рантайм/sandbox → это и есть третий движок, непризнанный |
| 6 | Слепые пятна A/Б/В | ВЫЖИВАЕТ частично | верно опознаны, но список неполон |

## Новые риски (Fable не назвал)
1. Безопасность чужого кода в marketplace — крупнейшее упущение (манифест ≠ безопасность поведения; нет sandbox/capability).
2. PII/право на забвение truth-узлов vs INSERT-not-migrate (шире слепого пятна A).
3. Мультитенантность — чей граф, изоляция пользователей.
4. Синхронизация форков — lineage статичен, форк не слышит патчи предка.
5. Uninstall/осиротевшие узлы при INSERT-not-migrate.
6. Governance-версионирование самой Combination (ретро-эффект смены правил гейтов).

## Практический guardrail
Brain не построен, шлюз построен. Не переписывать рабочий шлюз ради чистоты недостроенного Brain — нужен
явный cutover-ADR (шаги, откат, критерии). Иначе разрез = повод заморозить развитие рабочей системы.
