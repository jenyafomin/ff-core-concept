## По-настоящему НОВОЕ (сверх прошлого плана) — на заметку

   (тихо/не тихо). Новое: **глобальный default-on** + переопределение по топику + «синтез из правил».
   Это не флаг на агенте — это **политика форматирования финального хода** на уровне шлюза.

   (один слой). Новое: между личностью и сессией — слой «агент/зарезервированный слот». Влияет на
   ключ сессии и на репликацию. Развилка F-a.
3. **Оркестрация ↔ worktree ↔ концепт** (C-12): один чат порождает параллельные ветки-агенты, потом
   мерж; пересечения выносятся в модули; концепт = карта мержа. Развилка F-c.
4. **Wildcard на каждом уровне вложенного концепта** (C-2) и **wildcard-поиск концептов** (C-1).
5. **Хедер-строка «тема разговора»** (C-6), **rename-в-любой-момент + transfer чата** (C-8),
   **pin/приоритет темы** (C-7), **счётчик репликаций личности** (C-10) — мелкие заострения.
