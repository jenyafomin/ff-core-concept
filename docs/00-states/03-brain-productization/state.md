# 📍 STATE-03 — Brain как запускаемая база (productization)

> Реальный экземпляр `state`. Отличается от state-00 (global-build = ЧЕМ/как собираем инфраструктуру)
> и state-02 (agent-mechanics): здесь — **выбор направлений**, которые быстрее всего доводят brain до
> «можно запускать как базу и строить на нём». Фаза: пощупать направления (не строить вслепую).

## На чём работаем (тема)
Определить 4–6 направлений развития brain и их порядок так, чтобы получить **минимальную запускаемую
базу** (substrate + движок + первая ценность M3 «агент с памятью, переживающей сессии»), а дальше
наращивать модули. Каждое направление → своя развилка «что даёт результат раньше».

## Кандидаты-направления (черновик, ждут разбора — см. concept.json хода)
1. **N-A — Замкнуть модель субстрата** (integration D-1..D-8): hard-erase, разводящее правило D-7,
   4 фокус-вопроса владельца. Гейт: без замкнутой модели движок строить рано.
2. **N-B — Ратифицировать стек/движок** (DEC-9 Postgres, Fable-гейт) → engine-spec / ADR-0004.
3. **N-C — M0→M3 walking skeleton** в новом репо `TOOLS/` (первая переживающая память).
4. **N-D — Контракт brain↔agents** (`03-contract/`): чем движок кормит слой агентов.
5. **N-E — Оркестрация (state/plan/task/loop)** — ратификация ADR-DRAFT (state-02), разв.6 материализации.
6. **N-F — Гигиена дерева/реестра** (O-21 унификация) — снимает трение навигации (частично сделано D-1).
7. **N-G — Углубление памяти: условия «зелёного» по ценностям + пересмотр путей** (заведено 2026-08-04).
   Дом: `docs/_inbox/2026-08-04-picture-coverage/DIRECTION.md` (+ карта покрытия `analyses/00-COVERAGE-MAP.synthesis.md`,
   M1=19%/M2=35%). Две стороны: (а) дыры→условия зелёного по граням; (б) пересмотр неверных прежних путей.
   Гейт: корень («что есть зелёное») обдумать до фан-аута по 42 граням.
