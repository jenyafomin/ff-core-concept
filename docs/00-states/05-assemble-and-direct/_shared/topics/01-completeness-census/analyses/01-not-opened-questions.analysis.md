# НЕ-открытые вопросы — перепись полноты (линза: вверх)

## Метод
Взял цель как решётку из трёх ног (**тождество · правда · согласие**) + 7 ценностей + 5 гейтов + слой агентов.
Наложил на неё ВСЁ уже-открытое (8 ночных нод, S1-S4, OWNER-QUEUE, task-pool). Искал клетки, где НЕТ
сформулированного вопроса — не «задача не сделана», а «вопрос ещё не назван, потому не попадёт в гейт».
Проверил grep-ом (0 хитов подтверждают отсутствие, не память): `identity merge/split` — 0; `threat model /
модель угроз / untrusted agent` в `03-unit` и `00-states` — 0; `отравление/poison` — только россыпь упоминаний,
ни одной ноды-keystone.

## Ключевое наблюдение (одна фраза)
**Из трёх ног цели «согласие» доведено до ADR-0009 + полной лестницы стирания; «тождество» держится на
`canonical_id` + промоушен-предикате (одна сторона — рождение единицы); «правда» не имеет ни ноды-keystone,
ни анти-тавтология-теста — только 🟠-задачи.** Перепись ширины (G5) и хребта (G2) эту асимметрию не ловят
структурно: обе живут ВНУТРИ уже-открытых веток. Пробелы ниже — там, где вопрос ещё не открыт.

## Ранжирование — топ-3 «следующих вопроса» для итераций 6+

**#1 · U1 — Keystone правды (анти-тавтология для «правды»).**
Наибольший рычаг: закрывает самую грубую асимметрию цели (одна нога из трёх без keystone). Симметрично тому,
как S3 — анти-тавтология-тест ставки form-agnostic, здесь нужен «анти-отравление / конфликт-арбитраж»-тест как
несущий, не 🟠-хвост. Автономно открываем концепт-нодой (abstract+critic); может родить ADR-класс. Дёшево
открыть, дорого игнорировать.

**#2 · U2 — Фальсификация полноты G1 («какую форму мы забыли?»).**
По логике самого Закона-1 это единственный НЕОБРАТИМЫЙ класс ошибки, и он единственный из гейтов без
адверсариал-прохода. Плюс уже есть конкретный расход: 3-швов-в-DIRECTION vs 5-швов-в-HANDOFF не сведены.
Один architect+critic прогон «missing form». Должен идти ДО S2 (S2 замораживает формы).

**#3 · U3 — Минимальный контракт актора-агента.**
Claim цели структурно нефальсифицируем, пока актор = голая строка. Не «строить слой агентов» (это owner-объём),
а «какой минимум модели актора делает „агент не может X" проверяемым». Разблокирует осмысленность G2/G4 и I-7.
Смешанный: автономная часть (минимальный контракт) + owner-часть (объём).

> Далее по рычагу: **U4** (арбитраж — owner/ADR, но черновик решётки автономен) · **U5** (merge/split тождества)
> · **U6** (threat-model рамка) · **U7** (свежесть).

## Где дыр НЕТ (честно — не раздуваю)
- **Согласие/стирание-механика — полна концептуально.** ADR-0009 (①②③), «шов двух веществ», лестница Ст-1..N с
  честным СТОП, referent-роль, admission-форма + меню R4. Остаток здесь = **build-долг** (by-ref PII, монумент
  на диске), НЕ незаданный вопрос.
- **Различение форма/политика (Закон-1) — полно.** Растворяет F1-форк, разводит content/type-gate. Открытое —
  ratification (owner), не новый вопрос.
- **Направление промоушен-предиката (Закон-2) — открыто корректно.** Оператор честно отложен на S3
  (Q-L2op), не преформулирован. Это НЕ пробел — это правильно-отложенное.
- **Дома/размещение доков — покрыто с запасом** (Q-OQ-D, Q-L1dom). Скорее переспрошено, чем недоспрошено.
- **Ширина поверхности (G5) — процесс есть** (перепись 19 граней, критические 20% ранжированы). Пробел не в
  ширине граней, а на уровень ВЫШЕ — асимметрия трёх ног цели (U1/U5), которую пофасетная перепись не видит.

## Критический пробел (если называть один)
**U1 — нога «правда» без keystone.** Проект назвал цель тремя словами (тождество·правда·согласие) и вложил
несоразмерно: согласие → ADR + S3-класс глубины; правда → россыпь 🟠. «Готовность» рискует быть объявленной по
двум ногам, а третья вскроется после заморозки форм. Это не дыра в реализации — это **не-открытый вопрос**,
и переписи G2/G5 его структурно не ловят.
