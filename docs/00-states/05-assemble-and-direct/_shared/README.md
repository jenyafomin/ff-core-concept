# _shared — служебное (переиспользуемое)

> Идея владельца (08-04): чтобы наработки не терялись между сессиями/планами, держим здесь
> **переиспользуемые состояния и паттерны**, на которые планы ссылаются ЯВНО (а не копируют). Плюс
> **снапшоты** ключевых развилок/решений — как точки возврата и материал для переиспользования.

## Что сюда кладём
- **reusable-states/** — шаблоны состояний/планов, годные для многих направлений (напр. «глубокое начало
  плана»: разведка → развилки → адверсариальный гейт → синтез).
- **snapshots/** — датированные снимки важных развилок/вердиктов (напр. вердикт Fable о единице зелёного),
  чтобы новее-побеждает-но-ничего-не-стёрто (LOSE-NOTHING).
- **patterns/** — механики взаимодействия команд (совет, дебаты, голосование, контрподпись).

## Правило ссылки
Состояние/план ссылается на `_shared/...` по пути в своём frontmatter (`reuses:` / `snapshot_of:`),
не дублируя контент. Снапшот — только УКАЗАТЕЛЬ + краткая выжимка, истина — в исходном доме.

> Пока пусто (каркас). Наполняется по мере того, как совет и планы выделяют переиспользуемое.
