## ⭐ Fable cross-cut — 2 связи, которые отдельные команды увидеть не могли

1. **Law-2 ↔ I-4 (связаны!).** Единственное доказательство Закона-2, что он не тавтология, — исключение
   «монумента». Оно опирается ровно на грань ③ ADR-0009, которую I-4 сейчас откладывает. Когда поле ③
   спроектируют, монумент получит стираемое имя-требователя → это признак «своего жизненного цикла» ВНУТРИ
   «терминальной грани» → **S3-доказательство обязано включить пробу «монумент с атрибуцией»**, иначе
   единственное исключение Закона-2 зашатается в день, когда ③ приземлится. (Не смертельно — задача для S3.)
2. **«Куча отсрочек» сходится в ОДНУ точку — первый прод-payload.** R4-политика, судьба Формы-4, грань ③ —
   все становятся «должны» в один момент. Записи пилота — **тихая зона жертвы** (навсегда неклассифицируемы,
   без метки времени, без атрибуции). Каждая команда оценила СВОЮ отсрочку; никто не оценил КУЧУ.
   **→ Завести ОДИН реестр отсрочек + триггеров** (R4-критик уже заметил: один триггер не фальсифицируем).

## ⭐ R4 — самый острый ход (Fable): «отложить» — неверное слово, ты УЖЕ решаешь

Разведи два разных вопроса:
- **ЗАХВАТ сигнала** (если источник ga-rentacar несёт дату рождения / права) — **делать СЕЙЧАС**, неклассифицированным.
  «Не захвачено» = retrofit-НЕВОЗМОЖНО (append-only). «Захвачено-но-не-размечено» = retrofit-ДЁШЕВО.
- **ПОЛИТИКА** (что делать с этими классами) — может ждать.
Тогда решение владельца становится: *«записи пилота ДО появления поля X = принятая безвозвратная потеря»* —
открытый риск превращается в **оценённую потерю**, а не молчаливый провал.
