# Q-L2op — оператор promotion-предиката: пространство форм и их фальсификаторы

## Вопрос · ставка
Закон-2 (`two-laws.invariant-candidate.md:100-126`) ратифицирует ФОРМУ-ставку: «что-то повышается до
ЕДИНИЦЫ, когда несёт признаки СВОЕГО роста по трём осям — собственная идентичность · собственное
состояние-во-времени · локус согласия/стирания». **ОПЕРАТОР** (логическая форма объединения трёх осей в
булев предикат «единица / не-единица») СОЗНАТЕЛЬНО не зашит (`:107-112` warn-блок: «оператор = линза S3,
анти-тавтология-тест»).

**Задача этой ноды — НЕ выбрать оператор.** Задача (линза abstract-thinker, ВВЕРХ): (1) РАЗЛОЖИТЬ
пространство операторов; (2) для каждого назвать РЕАЛЬНУЮ структуру, которая его ФАЛЬСИФИЦИРОВАЛА БЫ
(классифицирует очевидно неверно против уже принятого — ADR-0009 ③, §5); (3) назвать оператор, который
нельзя фальсифицировать, ТАВТОЛОГИЕЙ; (4) сформулировать, что должен проверить S3, чтобы выбор оператора
был честным (не подгонка под желаемый ответ «time-on-edge проходит»).

**Ставка:** S3 — несущая ставка ВСЕГО проекта (доказать хребет НЕ тавтологично, `DIRECTION:44,76-78`). Если
оператор подгоняется под time-on-edge, «доказательство» ложно (G2 зелёный по построению — не по факту).
Эта нода вооружает S3 честным тестом; сам оператор остаётся owner/S3-решением.
