# Q-L2op — линза-синтез: сделать выбор оператора честно фальсифицируемым (НЕ выбрать)

## Conceptual Model: оператор promotion-предиката Закона-2

### The core insight
Спор «строгая-конъюнкция vs ≥2-из-3 vs идентичность-необходима» — во многом **ложная развилка ВТОРОГО
порядка.** Настоящий груз лежит НИЖЕ: в **операционализации трёх осей** — «что в ДАННЫХ считается СОБСТВЕННЫМ
I / S / C». Как только оси получают честные, НЕ-круговые детекторы (own-I ≠ хэндл; own-S ≠ любое значение-во-
времени; own-C ≠ стираемость), три оси начинают вести себя как ВЛОЖЕННЫЕ, а не ортогональные (own-S и own-C
почти всегда тянут own-I), и выбор join'а во многом форсируется. Оператор нельзя выбрать честно, пока оси не
операционализированы и не ПРЕД-зарегистрированы.

### Mental model
Думай о промоушене как о **тесте на гражданство, а не о подсчёте очков.** Плохой оператор (≥2-из-3, дизъюнкция)
= «набери 2 балла по любым признакам» — тогда монумент (у него есть хэндл + он стираем) «покупает» гражданство,
не будучи растущей сущностью. Честный оператор спрашивает ОДНО: **«обязана ли эта структура адресоваться
независимо, ПОТОМУ ЧТО несёт свою историю или своё согласие, которые нельзя разместить плоско?»** — и `S`/`C`
здесь СИМПТОМЫ этого «обязана», а не отдельные монеты. Монумент отвечает «нет» (терминальная грань, не растит,
согласие — на родителе) → остаётся гранью. Стинт отвечает «да» (сосуществующие корригируемые интервалы, которые
`foldEdges` не выражает плоско) → единица.

### Пространство операторов (кратко — полный разбор в analysis §2)
- **(a) строгая конъюнкция (I∧S∧C).** Фальсификатор: **стинт-ребро** (нет своего C — наследует) → AND ложно
  ОТКАЗЫВАЕТ в единстве (fail A3/F6). Риск = false-negative, убивает ставку.
- **(b) I необходима; S,C — индикаторы.** Фальсификатор: **монумент/payload с hash-хэндлом** — ЕСЛИ own-I
  операционально = «есть хэндл», ложно повышает (fail A1). Честность (b) целиком на НЕ-круговом детекторе own-I.
- **(c) ≥2 из 3.** Наивный фальсификатор (монумент) **НЕ срабатывает** после честного C=нет [исправлено критиком];
  НИ одна проба текущего банка его чисто не фальсифицирует → рискует быть «различием без разницы» с (b); честно
  тестируется только held-out ≥2-без-роста структурой в S3.
- **(d) иное.** дизъюнкция = фрактальный взрыв (почти тавтология); **ось-коллапс (d2)** = ключевой разрез (оси
  вложены → вопрос растворяется в «честно определи own-I»); лексикографический = зависит от «неоднозначного I».

### Ведущая ГИПОТЕЗА (НЕ вердикт, НЕ выбор)
Наиболее фальсифицируемым-и-честным выглядит НЕ конкретный join, а **(d2)/(b)-заострённая: own-I необходима,
где own-I честно определён как «несёт свою историю (own-S) ИЛИ своё согласие (own-C), не размещаемые плоско», а
S/C — диагностические симптомы.** Это единственная форма, чей фальсификатор конструктивен (предъявить own-S или
own-C БЕЗ own-I — контрпример вложенности). Но это ГИПОТЕЗА к фальсификации S3, не решение владельца.

### Validated assumptions (подтверждено источниками)
- Оператор СОЗНАТЕЛЬНО оставлен owner/S3-линзой (`two-laws.invariant-candidate.md:107-112,135-144`).
- Монумент = грань, НЕ единица (ADR-0009 ③; UNIT-SPEC §4 `:69-71`) — независимый якорь A1.
- Стинт-ребро с собственным циклом → reify-to-unit (F6; Q-S3scope `:69-77`) — якорь A3.
- Согласие/референт живут на ЯДРЕ единицы, раз на единицу (UNIT-SPEC §3 `:53`, Ц-7) → стираемость грани ≠ own-C.

### Ограничение пространства операторов: ось own-C структурно вакуумна до промоушена [2-й критик, Finding 3]
`synthesis/03-l2op.critic-2.md` (независимый 2-й проход) нашёл глубокое, чего не было в 1-м: **own-C, как
операционализирована (§4: «согласие СОБСТВЕННОЕ, не наследуемое»), не имеет НИ ОДНОГО положительного (`да`)
примера во всём банке — и это СТРУКТУРНО, не случайно.** `referent/owner/visibility_scope` (Ц-7) живёт
раз-на-ЯДРЕ-единицы (`UNIT-SPEC-v1.design.md:53`); любой pre-promotion кандидат по построению ЕЩЁ БЕЗ своего
ядра → своего `referent/owner`-поля нет → own-C читается «нет» **тавтологически для ЛЮБОГО кандидата**, не
только монумента. **Следствие (назвать явно):** любой оператор, ТРЕБУЮЩИЙ own-C как необходимое условие —
строгий AND (a); (c) для структур без `I` — негласно ВЫРОЖДАЕТСЯ в предикат над `I`+`S` только. Это усиливает
гипотезу (d2): own-C похоже не независимая ось, а СЛЕДСТВИЕ промоушена, не его причина. (Класс: CONCERN к
S3-процедуре, не вето — нода и так не выбирает оператор.)

### Open tensions
- **Независимы ли три оси?** Монумент — острая проба: он ЕСТЬ локус стирания, но НЕ единица → «локус стирания»
  сам по себе не может быть осью-промоушена; должно быть «СОБСТВЕННЫЙ, не родительский». Если own-C и own-S оба
  предполагают own-I — оператор частично малформед (это (d2)). Finding 3 усиливает: own-C, возможно, вообще НЕ
  тестируема до промоушена. НЕ разрешено на бумаге.
- **(c) отличима ли от (b)?** Без held-out пробы ≥2-из-3 может быть практически неотличима от «own-I необходима».

### What S3 must check (чтобы выбор был честным — 5 защит, analysis §5)
1. **Пред-регистрация** оператора И детекторов осей ДО прогона time-on-edge (иначе тюнинг под желаемое).
2. **Свидетель исключения** — ≥1 структура, помеченная НЕ-единицей, одобренная независимо (монумент/payload).
   Нет исключения → тавтология-повышения.
3. **Held-out проба** — структура, НЕ использованная при дизайне осей; вердикт = предсказание, способное выйти
   неверным. {time-on-edge + монумент} недостаточно (оси могут быть с них считаны).
4. **Прогон против банка якорей** A1–A5 (независимо решённых) — противоречие ратифицированному = фальсификация.
5. **Само-проверка на тавтологию** — каждый кандидат везёт свой фальсификатор; не строится ни один → отклонить.
6. **Зуб ВКЛЮЧЕНИЯ для оси C [Finding 3]** — прежде чем опираться на ЛЮБОЙ C-зависимый оператор (a; (c) без I),
   S3 обязан либо (i) построить ≥1 held-out пробу с ГЕНУИННЫМ own-C=«да» (отдельный согласующий субъект —
   со-подписант / совместная опека / второй консентирующий, отличный от referent родителя), либо (ii) честно
   признать own-C структурно недостижимой до промоушена и разрешить (d2) в пользу «C = следствие, не причина
   промоушена». Иначе тест C-оси ПУСТ (аналог residual-near-empty из S3fixclass): банк A1–A5 полон
   ИСКЛЮЧЕНИЙ, пуст на ВКЛЮЧЕНИЯХ по C.

### What this model does NOT cover (честные границы)
- НЕ выбирает оператор (owner/S3).
- НЕ даёт финальную операционализацию осей — только КАНДИДАТ-детекторы (analysis §4); их код/пред-регистрация = S3.
- Знаки I/S/C предварительны; их уточнение = сам предмет S3.
- N-020-топик используется лишь как held-out проба, не разрешается здесь (owner-топик).
