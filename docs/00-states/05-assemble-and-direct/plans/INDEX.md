## Два закона (несущее — каждый план их несёт)
Из DIRECTION §1/§7 (abstract-thinker свёл 4 нити к 2 принципам):
1. **ЗАКОН-1 — Форма retrofit-невозможна, политика retrofit-дешева.** Закладываем СТРУКТУРУ
   (choke-point/идентичность) сейчас; enforcement-логику — когда угодно. Растворяет F1-форк.
   Форму admission-гейта кладём сейчас; fail-open/closed + классы = R4 (owner-форк, НЕ следствие закона).
2. **ЗАКОН-2 — Юнит-статус зарабатывается жизненным циклом.** Растит идентичность+состояние+согласие →
   повышается до ЕДИНИЦЫ. Один promotion-предикат = файл↔единица + монумент-рекурсия + N-020 +
   состояние-ребра. Keystone, НЕ отложенный (анти-тавтология-тест ставки).

## Зависимость (критическая цепь — DIRECTION §2)
```
C (гейты необратимого · форки владельца) → A (заложить швы) → B (доказать хребет) → D (наполнить ширину)
        S1                                     S2                  S3                     S4+
```
- **C→A→B→D строго последовательны** для ядра: нельзя начинать D-стройку, пока A не заперла швы (иначе миграция).
- **D параллелизуема веером** ПОСЛЕ A+B (разные грани — разные топики/команды, слияние в `../state.md`).
- S1 разблокирует НАПРАВЛЕНИЕ, не «всё» — жёсткая ставka «хребет выживает в коде» = S3, впереди.

## Doc-discipline (как этот контейнер устроен)
- **`plans/` = плюрал-контейнер** (сборщик однотипного), без номера. Дети — папки-узлы, нумерованы по смыслу.
- **Каждый план = ПАПКА** (потенциал роста), навигатор = `README.md` (ВИД + спека узла, пока не разделился).
  Когда план растит артефакты (напр. S1 Step-0 architect-draft) → они в под-папку (`work/`, `draft/`), корень чист.
- **S4..SN свёрнуты в один узел `04-S4plus-breadth/`** — это ОДИН вид работы (перепись ширины, параллельный
  веер), а не N разных планов. Когда веер раскрывается на конкретные грани, каждая грань = под-папка внутри 04.
  (Причина: избежать преждевременного взрыва N пустых папок; DIRECTION §3 сам держит S4..SN как один диапазон.)
- **Отложенное (за воротами)** — НЕ заводим планами: контракт brain↔agents · арбитраж 7 ценностей (→ADR).
  файл↔единица · монумент-рекурсия · N-020 **свёрнуты в Закон-2** → закрываются внутри S3, не отдельными планами.
