# S4..SN — Наполнить ширину (перепись граней)

> Позиция в цепи: **D (наполнить ширину).** ОДИН узел на диапазон S4..SN (это один ВИД работы — перепись,
> параллельный веер), не N разных планов. Когда веер раскрывается на конкретные грани — каждая грань
> становится под-папкой ВНУТРИ этого узла. (DIRECTION §3 · doc-discipline: узел заводим папкой.)

> ⚠️ **PRE-S4 ВОРОТА (owner):** перед первой сессией S4 владелец **ратифицирует список «критических 20%
> граней»** — иначе G5 геймится задним числом той же командой (DIRECTION §3). Это блокирующее условие входа.

## entry-branch
**D · одна грань за сессию** (правило движения: одна ветка/оборот). Веером — независимые грани в разных
топиках/командах, слияние статусов в `../../state.md`. Кандидаты — 16 пустых граней переписи (см. `census`).

## carried-concepts
- **G5** — критическая ширина зелёная (80/20: несущие грани, НЕ все 19).
- Оба закона держатся: любая грань, растящая идентичность+состояние+согласие, повышается по Закону-2;
  формы Закона-1 уже заперты (S2/S3) → грани строятся без миграции.
- Отложить-с-домом (НЕ терять, I8): §9-5/6/7/8/9 · S11/S12 · F2/F3/F4 · **F5→FORK-2** (см. пул).

## gate (DoD — уточнить на входе, per-грань)
- Ратифицированные «критические 20% граней» → зелёные (перепись 🟥→✅ по несущим, не по всем 19).
- Каждая грань закрыта дизайном/фальсификацией с якорем `file:line` (не прозой).
- Не-несущие грани — `deferred-с-домом`, не потеряны.

## team-rules (скелет — доразвернуть на входе каждой грани)
- **Читать холодным стартом:** этот README · ратифицированный список 20%-граней · `census` §1 (матрица 19
  граней с `file:line`) · релевантные `T-D1b-*` из пула.
- **Кто критик:** `critic` (адверсариал ДО фиксации, per-грань) — правило «фальсификация до стройки».
- **Агенты/линзы:** per-грань — `builder`/`analyst`/`critic`; веером параллельно (разные команды/топики).
- **Формат выхода:** дизайн/тест грани + обновление матрицы переписи; хендоф по шаблону на грань.
- **Синхронные волны под шлюзом** (≤3-6, `run_in_background:false`); веер = несколько синхронных волн, не мега-фан-аут.
