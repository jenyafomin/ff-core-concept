# S2 entry-spec — что именно закладываем

> **Закон-1 в деле:** кладём ФОРМУ (гнездо/choke-point/идентичность), НЕ политику. Всё помечаем `provisional`
> (F6-форма фальсифицируется в S3). НИКАКОЙ enforcement-логики. Правим документ UNIT-SPEC, не код.

## Дельты формы (retrofit-НЕВОЗМОЖНЫЕ — заложить до первого прод-payload)
1. **§6 Deref-seam (F1)** ⚠️самый срочный — единая воронка payload-deref, БЕРУЩАЯ `viewer`, покрывающая
   **весь CRIT-1 периметр** (интерактивный `get()` · fold/компакция ADR-0010 · snapshot/rebuild · durable-fs
   eager-hydrate `store-durable-fs.ts:171`), а не только `get()`. Форма = параметр `viewer` в воронке; политика
   `read:payload` — пустая/за швом (Закон-1). §9 честно называет read-side статус = ambient-authority до политики.
2. **§4 Opaque edge-identity (F6)** — форма `Edge` заморожена append-only, ключ идентичности = только
   opaque-поля (не интервальные значения). **Помечено `provisional` — направление F6 фальсифицируется в S3.**
3. **§4 Admission-гейт форма (F2/R4)** — присутствие точки-решения на входе + слот классификатора классов-
   референтов. **R4 ратифицирован (S1): default = A (вынужденный, осознанный) для пилота; политика классов
   отложена.** Форма несёт слот, дефолт помечен «A ратифицирован, политика TBD, классификатор = задача».
4. **§4/конверт акта — Форма-4 valid-time/as-of (ратифицирована «в область сейчас»)** — поле as-of/valid-time
   на конверте акта (отдельно от зарезервированных edge `validFrom/validTo`). Форма = присутствие поля;
   политика свежести отложена.
5. **R4 capture-form (уточнение Fable)** — зарезервировать в форме захвата возможность нести DOB/license
   **неразмеченными** (не-захват = retrofit-невозможно; захват-без-разметки = дёшево). Спека называет:
   «пилот захватывает широко, разметка/политика позже; записи до поля-разметки = принятая потеря».

## Дельты честности §9 (retrofit-дёшево, но заносим тут — готовит G3)
- **§9 три-полки** (armed / promise / open) — вставить блок; текст сейчас звучит до-честно (D2-F3).
- **§9 F1-honesty** — назвать read-side гарантию как ambient-authority/дисциплина кода, не субстрат.
- **§9 D5-N023** — одна фраза: третий класс актора (user-authored tool), CANNOT-list актор-агностичен.

## Fable cross-cut → занести здесь (чтобы не потерять)
- **Defer-ledger (ОДИН реестр отсрочек+триггеров).** Завести файл-реестр: R4-политика · Форма-4 freshness-
  политика · грань ③ · F6-финализация — все сходятся в ОДНУ точку (первый прод-payload). У каждого — триггер
  (R4-критик отметил: текущий триггер не фальсифицируем → дать объективный порог).
- **S3-нагрузка (Law-2 ↔ I-4 связь).** S3-доказательство ОБЯЗАНО включить пробу «монумент с атрибуцией»:
  когда грань ③ получит стираемое имя-требователя — единственное исключение Закона-2 не должно зашататься.
  → занести как предусловие в план S3 (`../03-S3-prove-stake/`).
