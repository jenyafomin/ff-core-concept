## Где мы
**Единственная не-бумажная сфера — это РЕАЛЬНО работающий софт** (`/Users/mac16/Documents/IT/Apps/TOOLS/agents-manager`,
процесс pm2 `agent`, ветка `feat/sdk-runner`). Прогресс здесь **НЕ заблокирован** замком ядра FQ25.
Работает и одобрено (approved): per-topic сессии, topic/reply-осведомлённость (**ADR-0002-topic**,
подтверждено по логам), SDK-раннер с per-tool approval-гейтом (**ADR-0001**:
`canUseTool → SdkToolGate → ToolApprovalGate`, 3 кнопки ✅ Раз · ♾️ Всегда · ⛔ владельцу).
**Draft / кода нет:** мульти-роли + авто-одобрение (**ADR-0002-access-roles**, R3, «блокер №1») — клапан
доверия работает только для single-owner; без него ночная/фоновая автономность невозможна.
**Живые баги:** дубль голосового (убивает фоновых агентов ×4/сессия, приходит как «молчание»);
`P6-permission-stream-closed` (тот же `SdkToolGate`). **Долг формализации:** M-P2 Telegram-адаптер
«уже работает как код», но не сведён в доменную схему (node/edge `conversationRef`+`Topic.threadId`).

## Куда идём (Definition of Done)
Сфера «здорова и растёт без ядра», когда: (1) **дубль-баг** починен (дедуп входящих + не-kill фоновых);
(2) **MVP авто-одобрения** (turn-scoped доверие + журнал 3 типов + конфигурируемый deny-list, область=топик)
за флагом в проде — блокер №1 снят безопасно; (3) **P6** закрыт на той же чистой базе (одна работа с №2);
(4) e2e-валидация ADR-0001 из Telegram пройдена (была pending); (5) M-P2 сведён код↔схема (граница код/оркестрация).
