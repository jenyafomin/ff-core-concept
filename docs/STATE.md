## Что это за проект
Личная система управления жизнью = **второй мозг, который ещё и действует**: единый граф знаний
(модуль информации) + слой агентов, которые читают его, делают работу и пишут обратно (модуль
управления агентами). Строится на Claude Code, файлы = истина. Подробно: `docs/product/VISION.md` §7,
`docs/product/SYSTEM-IN-PLAIN-WORDS.md`.

## 📐 Модель данных — где мы (главное)
**Простой концепт (после стресс-теста, `docs/product/CONCEPT-2026-06-15-data-model-stress-test.md`):**
> Узел = типизированная, датированная, со статусом единица смысла. У неё ОДИН дом (контекст+важность)
> и МНОГО связей. Всё (задача/метрика/человек/коммит/агент/сообщение) — узел с типом + рёбра. Типы =
> правила (базовые + от модулей). Граф = память.

6 граней узла: id+тип+title+description+body · время (событие/истинность) · статус · ОДИН дом · N связей · важность.

**Стресс-тест (50 ячеек) вскрыл 4 ОСИ, которых не хватает:**
1. **Время** — метрики/ряды, расписания, время истинности vs время файла (самая дорогая).
2. **Принадлежность vs связь** — каскад контекста/важности идёт только по одному родителю → полиморфизм
   и каскад несовместимы; важность не контекстна.
3. **Статус знания** — факт/гипотеза/предложение/архив свалены вместе.
4. **Типы** — закрытый enum vs «типы-модули со своей валидацией» (архитектурный разрыв).
+ инфра: циклы в связях не защищены, `maxDepth` не в коде, нет обратного поиска/фильтра по дате,
`description` ещё не добавлен.

**Решено консилиумами №1/№2 (`docs/council/COUNCIL-2026-06-14-c1*`, `*c2*`):**
- Ноль новых kind (тонкий фильтр); сообщение-агрегатор = `kind=message`+body+links на файлы/коммиты.
- Уровни = вычисляемый zoom по умолчанию + опц. авторские. Важность = ручная 1-5 + наследование + touch
  (НЕ центральность). maxDepth=3 мягкий. Фасеты/направления = рёбра/теги к group-узлу.
- Файлы = ИСТИНА; индекс = эфемерная производная, отложен до ~300 узлов (потом SQLite, не DuckPGQ).
- Канонический запрос: `getContext(узел, бюджет)` — контекст-конверт.
- Ресёрч (`docs/research/RESEARCH-2026-06-14-graph-architecture.md`) подтвердил: «файлы=истина +
  встраиваемый индекс + MCP»; Mongo как «идеал» не подтвердился.
