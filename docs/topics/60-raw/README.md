# 60-raw — Raw Agent Outputs

**Group purpose:** Verbatim outputs from individual agents in a council session.
These are SЫРИЁ (raw material) — never edited after writing. Syntheses in 10-synthesis read from here.

## What lives here
- `YYYY-MM-DD-session-name/agent-role.md` — one file per agent per session
- Session folders are date-prefixed; files inside are role-named (analyst.md, architect.md, critic.md…)

## Ordering rule
DATE prefix on the SESSION FOLDER: `YYYY-MM-DD-session-name/`.
Files inside: role name (no date — date is in the folder).
Read in folder order = chronological session order.

## Process
- Agent raw outputs are written here immediately during/after a council session.
- They are NEVER edited after writing (immutable record).
- Synthesis agent reads from here and writes to 10-synthesis.
- This group can grow large — that's expected and correct.
