## Новые ветки (голос 04.07, владелец сформулирует для Fable)
1. **MCP-расширение агентов:** агент подключает MCP-серверы → новые инструменты (Gmail/Calendar/Notion/
   Drive/БД/кастом). Per-topic/per-project scope; гейт правами (canUseTool) + правило «MCP-выход непроверен
   до ратификации». claude.ai-коннекторы требуют OAuth (недоступны из шлюза — авторизовать на claude.ai).
2. **Лог/статус-группа:** отдельный топик/группа, куда оркестратор пишет статусы; логи = УЗЛЫ в BRAIN
   (session/agent/status = типы), «обновить статус» = запрос к графу. = цель C (наблюдаемость).
3. **Система памяти:** per-principal×project; фундамент — те же узлы логов/статусов + линзы.

**Новые ветки (фиксировать, работать в разных местах):**

4. **САМОУЛУЧШЕНИЕ встроить гибко в агентов** (не только вокруг БД); возможно два модуля — различны, но хорошо дружат.
