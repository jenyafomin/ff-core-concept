# 10-synthesis — Synthesis Outputs

**Group purpose:** Final outputs of deliberation: SYNTHESIS-*, SWEEP-*, VERDICT-*, CONCEPT-*
after a council or research session. These are distilled conclusions — not raw agent output.

## What lives here
- `YYYY-MM-DD-SYNTHESIS-topic.md` — synthesis from a multi-agent series
- `YYYY-MM-DD-SWEEP-topic.md` — sweep/overview of a session series
- `YYYY-MM-DD-VERDICT-topic.md` — verdict / gate result
- `YYYY-MM-DD-CONCEPT-topic.md` — conceptual formulation after deliberation
- `YYYY-MM-DD-COUNCIL-topic.md` — synthesized council outputs (non-raw)

## Ordering rule
DATE prefix: `YYYY-MM-DD-` — most recent synthesis is the most relevant.
Read in reverse-chronological order for current status.

## Process
- Syntheses are WRITTEN BY an agent after reading raw outputs.
- They become targets for owner annotation and possible promotion to 00-canon.
- Never delete — if superseded, add `Status: superseded` and link to replacement.
