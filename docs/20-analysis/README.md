# 20-analysis — Analysis Artifacts

**Group purpose:** In-depth analyses, research, capability maps, deep-dives, rationales.
These inform decisions but are not decisions themselves.

## What lives here
- `YYYY-MM-DD-ANALYSIS-topic.md` — multi-lens analyses
- `YYYY-MM-DD-RESEARCH-topic.md` — research outputs
- `YYYY-MM-DD-CAPABILITY-MAP-topic.md` — capability/feature maps
- `YYYY-MM-DD-DEEPDIVE-topic.md` — focused technical deep-dives
- `YYYY-MM-DD-RATIONALE-topic.md` — rationale documents (why a choice)
- `YYYY-MM-DD-FACETS-topic.md` — facet explanations
- `YYYY-MM-DD-UNIVERSAL-NODE-topic.md` — node-model canvases
- Non-dated architecture reference docs (AGENT-WORKSPACES, AGENTS-CATALOG, etc.)

## Ordering rule
DATE prefix: `YYYY-MM-DD-` for dated analyses.
Non-dated files: CAPS topic name, sorted alphabetically.

## Process
- Analysis files are inputs to syntheses and council sessions.
- They do not become canon directly — their conclusions get promoted via ADRs or SPECs.
