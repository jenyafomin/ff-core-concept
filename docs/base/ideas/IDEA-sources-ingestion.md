## Сырьё (из Telegram)
Ссылка на Instagram reel + «Мне нужно вести и изучать все источники».

## Суть
Источник (рилс, видео, статья, ссылка) — это тип узла, который система **втягивает и изучает**:
сохраняет → агент-исследователь конспектирует → заметка(и) в базе знаний с уровнями L1/L2/L3.

## Место в системе
- Новый `kind: source` (или `note` с тегом `source`) в графе `@ff/core`.
- Слой захвата (вход) + агент-исследователь (каталог агентов, лёгкий).
- Цепочка: источник → изучение → заметки → связи с направлениями.

## Легко / сложно
- 🟢 Сохранить ссылку как узел с метаданными.
- 🟡 «Изучить» текстовые источники (статьи, YouTube-субтитры) → конспект.
- 🔴 Видео-источники из Instagram: нет простого API, скачивание рилсов хрупкое и против ToS;
  извлечь аудио → у нас есть Whisper, но достать само видео из IG — отдельная нетривиальная задача.

## Риски
- Превратится в свалку ссылок, которые никто не изучает (нужен триггер «изучить»).
- Скрейпинг IG ненадёжен и юридически серый.
