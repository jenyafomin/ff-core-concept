# Категория «service» (технический срез)

Цель классификации. Ячейки указывают на неё через `facet-of` (НЕ через `home`).

## Поведение (комментарии)
- Категория — это узел-**цель** `facet-of`, а не «папка». Поэтому она НЕ перетягивает `home` и не каскадит контекст.
- `kind-of`→`type-file` — «умная категория» привязана к типу (N-087): может нести свои доп. поля/уровни определения.
- Открытый вопрос (Q3, N-086): можно ли одному узлу быть И категорией, И домом-папкой — решаем консилиумом позже.
