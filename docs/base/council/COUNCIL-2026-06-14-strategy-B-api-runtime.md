## Что оценивали
Полный автономный мульти-агентный рантайм на API-ключе (Agent SDK / Managed Agents), не подписка.
Агенты действуют сами, оркеструются, общаются, держат состояние, авто-чистят контекст, по расписанию.

## КОНСЕНСУС (сложился к раунду 2 — конкретная минимальная архитектура)
**Первый шаг B = ОДИН cron-агент на Haiku («B-lite»), proposal-only, с human-gate и бюджет-предохранителем.**
Все пять ролей сошлись на этой петле:
1. **Тик = STATELESS-редьюсер** (Architect): читает граф `@ff/core` (через MCP) → один ход → пишет
   узел `proposal`. Состояния между тиками нет → окно пересобирается из графа → **авто-чистка
   контекста становится НЕ-проблемой** (чистить нечего).
2. **Human-gate между `proposal` и `commit`** (не между тиками). Обратимые действия можно
   авто-апрувить; необратимые (письмо/календарь/деньги) — только после `approve`.
3. **След** до/после каждого тика (переиспользуем `trace.ts`).
4. **Бюджет-предохранитель:** счётчик токенов/стоимости узлом в сторе; превышение дневного
   потолка → тик делает no-op; жёсткий месячный потолок (~$15) → стоп + уведомление + ручной resume.
5. **Model-routing:** Haiku на рутину (~$2/мес), дорогие модели только на синтез/неоднозначность.
   Главная утечка денег — НЕ агенты, а оркестратор с длинным контекстом ($150–600/мес).

Прочее:
- **Отвергнуты Managed Agents (Pattern C)** — вендор владеет состоянием/топологией/автономией =
  lock-in. Только Agent SDK + свой тонкий оркестратор (Pattern B).
- **Пререквизит в сторе `@ff/core` (Architect, конкретно):** добавить СЕЙЧАС — (1) тип узла
  `proposal` (status: draft|approved|committed|rejected); (2) оптимистичная конкурентность
  (`expectedVersion`/CAS), иначе два тика затрут друг друга; (3) idempotency-key на `commit`
  (commit-once по proposalId), иначе ретрай cron дублирует сайд-эффект; (4) узел-счётчик бюджета.

## 🔑 Объединяющая рамка (Reframer, принята): A и B — ОДНА труба с растущим клапаном
- **A = труба** (дистрибутив-конфиг + лог наблюдений/доверия).
- **B = диаметр клапана:** сколько сайд-эффекта проходит БЕЗ подтверждения.
- cron-агент при **клапане=0** (только наблюдает/предлагает) — это первая запись в лог доверия;
  он МАТЕРИАЛИЗУЕТ аккредитацию, а не обходит её.
- Линия одна: **конфиг → лог доверия → cron-наблюдатель (клапан 0) → аккредитованное действие
  (клапан растёт)**. Не «B прорастает из A», а «**B — это диаметр A**». Дихотомия двух стратегий
  растворяется.
- Автономия зарабатывается **по зонам и обратимо-первой**: право действовать без спроса в зоне X —
  после N наблюдаемо-верных предложений в ней (promotion-rules для доверия); необратимое — всегда гейт.

## НЕРАЗРЕШЁННЫЕ РАЗВИЛКИ
- **F1 — Облегчение или тревога? (главный вопрос, за владельцем).** Reframer: старт снимает
  ТРЕВОГУ, а не даёт облегчение — клапан-0 («вижу, что агент сделал бы») строит доверие до
  делегирования; облегчение — награда позже. User-Advocate: «момент» = push без меня (облегчение),
  но согласен, что сначала proposal. **Что важнее владельцу — облегчение (система действует) или
  контроль (система предлагает, последнее слово за мной) — определяет скорость открытия клапана.
  Покажет первый реальный брифинг.**
- **F2 — Скептик: «маленький ≠ безопасный».** Даже на крошечном агенте: риск не в размере, а в
  автономии и отсутствии sunset. Доп. guardrails (сохранить): **gate-0** — расширение scope агента
  (второй источник данных / второй тип действия) требует явного решения, не тихого апгрейда;
  **sunset** — если за 30 дней ROI не доказан, агент удаляется (иначе зомби-фича).
- **F3 — Зачем B-lite, если A на подписке пользователя ($0)?** Ответ: контроль промпта + отсутствие
  дрейфа цели стоят ~$2/мес. Но вопрос реальный — порог ценности B-lite vs чистый конфиг.

## Экономика и ROI
- B-lite ≈ **$2/мес** (Haiku cron-инбокс). Жёсткий потолок-предохранитель **$15/мес** → стоп+аудит.
- ROI-метрика (Pragmatist): «агент закрыл 4 инбокс-задачи/нед без ручного триажа = ~2 ч/нед →
  при $25/ч ценность ≈ $200/мес при затрате $2». Окупается при одном сэкономленном часе/мес.

## Несокращаемые риски (severity H/critical)
- **Правильное выполнение НЕВЕРНОЙ инструкции, пока спишь** (Skeptic) — необратимый сайд-эффект.
  Гасится: proposal/commit-гейт + обратимость-первой.
- **Токен-взрыв** ($50–500 за ночь от зациклённого агента) — гасится бюджет-предохранителем.
- **Конкурентная запись агентов рвёт узлы** (Architect) — гасится CAS/идемпотентностью.
- **Scope-creep крошечного агента** (Skeptic) — гасится gate-0 + sunset.

## Gate-критерии провала B
1. Первый необратимый реальный сайд-эффект без human-in-the-loop (Skeptic).
2. Расширение scope агента без явного решения (gate-0).
3. Через 30 дней ROI не доказан → удалить агента (sunset).
