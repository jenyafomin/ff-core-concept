# Сырые результаты агентов

Конвенция (по просьбе владельца 2026-06-15): **каждый агент сохраняет свой результат** сюда для
более детального анализа потом — а не только в виде синтеза в чате.

## Правило для оркестратора
Запуская совет / стресс-тест / ресёрч, после возврата каждого агента сохраняй его ПОЛНЫЙ вывод в файл:

```
docs/council/raw/<дата>-<тема>/<роль>.md          # советы/стресс-тесты по ролям
docs/product/<тема>-raw.md                         # детальные пакеты по теме
```

Синтез (выжимка, развилки, ≤3 вопроса) остаётся отдельным документом (`docs/council/COUNCIL-*.md`,
`docs/product/CONCEPT-*.md`). Сырьё = для детального разбора; синтез = для решения.

## Зачем
- Ничего не теряется при компакте контекста.
- Можно вернуться к конкретным примерам/аргументам роли, не перезапуская агента.
- Видно, «кто что привнёс» (наблюдаемость вклада).

## Индекс
- `../../product/stress-test-2026-06-15-detailed.md` — детальный стресс-тест модели данных (5 кластеров,
  ~50 ячеек, матрицы вердиктов + вопросы).
