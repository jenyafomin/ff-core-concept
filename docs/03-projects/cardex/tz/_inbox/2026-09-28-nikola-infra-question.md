## Технические факты деплоя (из репозитория Forms-Sidebar)

- Инструмент = наш код (React + Apps Script `.gs`), Google = только среда исполнения. Исходники в git.
- Прод = **копии Google-таблицы + наш код, по копии на менеджера** (`.clasp copy.json`: tim, KongQiu, atlant,
  babilon, + «Migration of CDX | Mng»); механизм копий отлажен (README: «второй менеджер = копия файла + CONFIG»).
- 🔴 **Активный clasp-таргет (`.clasp.json`) = scriptId, помеченный «Migration of CDX | Mng»** → возможно
  перенос ЭТОГО инструмента уже начат. **Подтвердить у владельца** до ответа Николе.
- Apps Script: «инфраструктура» = сам Google-аккаунт. «Дубликат на новой инфре» = пересоздать копию под
  НОВЫЕ Google-аккаунты (то же, что заводим нового менеджера). Дёшево, проверено. НЕ равно уходу на свои серверы.
- Подводные камни копирования: installable-триггеры не переносятся (переустановить); Web App deploy-id
  меняется (`.deploy-id`, `webapp.access: ANYONE` — проверить, используется ли URL извне); политика нового
  Workspace-домена может блокировать OAuth; данные в копии = снимок на момент копии (дописанное на старой не переедет).
