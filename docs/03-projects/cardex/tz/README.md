## План (как договорились — черновик)

1. Получить и **тщательно проанализировать материал Павла** (кладём в `_inbox/`).
2. Переработать → поднять на уровень абстракции → **собрать концепт** будущей системы (ядро Cardex).
3. Цель концепта: **ядро для простых операций** (напр. переводы — где-то уже прорабатывали, в CRM или рядом).
4. Скоординировать с DevOps (инфра + безопасность) → полный перенос Excel-функционала на новую инфру.
5. **Анализ — многими агентами + Fable** (разные линзы), по явной команде владельца. Сейчас — рассуждаем.
