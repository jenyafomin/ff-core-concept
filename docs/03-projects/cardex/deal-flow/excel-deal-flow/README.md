# Excel Deal Flow — инструмент над Google Sheets

🧭 **Что это.** Инструмент, который бухгалтер **Павел** попросил доработать для взаимодействия
с Excel/Google-таблицами. На нём **работают менеджеры**: заполняют, ведут сделки. Код —
проект `Forms-Sidebar` (React-форма ввода сделок в модальном окне Google Sheets через Apps Script).

## Что это в коде (факт из репозитория Forms-Sidebar)

За ~1.5–2 месяца (13 авг → 23 сен 2026) построен рабочий инструмент: форма ввода сделок в 4 вкладки
(запись в листы Deals/CashFlow/Fixes), движок формул (value-binding), курсы (USDT-based), переводы
(лист Transfers), экономика (себестоимость/маржа), редизайн v2, просмотр/редактирование сделок,
фильтры списка. Развёрнуто в Google Sheets, базовый тест пройден.

⚠️ **Нюанс статуса:** значительная часть — «код готов + тесты зелёные, но НЕ задеплоено / ждёт живого
теста». «Готово по коду» ≠ «работает в проде». Это ключевой пункт для отчёта PM и ответа DevOps.
