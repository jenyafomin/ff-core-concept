🧭 **Что это.** Дом РЕАЛЬНОГО продукта, который строим/переносим — в отличие от абстрактного
идей-графа `../ideas/` (там «что за экосистема», здесь «что уже сделано и как переносим»).

## Контекст (кратко — полная версия в STATE)

Владелец — **главный программист**. Переведён из русского офиса на **дубайскую команду**.
Первая задача от Дубая — **перенести всю инфраструктуру на их кастомные серверы**. Многое уже сделано:
миграция Bitrix, сделок, клиентов (старая база русских офисов → новая дубайская, скопирована/перенесена).
