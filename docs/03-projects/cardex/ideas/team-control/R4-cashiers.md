# R4 — Кассиры (учёт счетов)

**Слой:** Команда и контроль · **Приоритет:** T1 · **Статус:** open

## Суть
Кассиры ведут учёт счетов по своей логике. Именно здесь чаще всего ломается идея «единого места», и отсюда идёт мост в бухгалтерию.

## Ключевые вопросы
- По какой логике кассиры ведут учёт?
- Где ломается «единое место»?
- Как устроен мост в бухгалтерию?

## Связи (рёбра)
- N0 → R4 — корневое противоречие касается и кассиров.
- R2 → R4 — СБ режет доступы кассиров.
- C1 → R4 — кошелёк клиента задаёт логику учёта (кошелёк → учёт).
- R4 → I2 — учёт счетов кормит бухгалтерию.
- X4 → R4 — агенты могут автозакрывать рутину кассиров.
