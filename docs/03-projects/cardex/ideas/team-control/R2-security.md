# R2 — СБ (безопасность / доступы)

**Слой:** Команда и контроль · **Приоритет:** T1 · **Статус:** open

## Суть
Служба безопасности задаёт сквозные границы поверх всех ролей: что каждой роли нельзя видеть и трогать. Плюс СБ ловит подозрительное прямо в потоке сделок.

## Ключевые вопросы
- Что каждой роли нельзя видеть / трогать (сквозные границы доступов)?
- Что СБ ловит в потоке сделок?

## Связи (рёбра)
- N0 → R2 — корневое противоречие касается и роли СБ.
- R2 → R1 / R3 / R4 / R5 — СБ режет доступы у всех остальных ролей.
- G1 → R2 — аудит и история изменений ведутся в первую очередь для СБ.
