# R3 — Операционисты

**Слой:** Команда и контроль · **Приоритет:** T3 · **Статус:** open

## Суть
Операционисты выполняют операции по сделкам. Нужно понять их набор операций, объём работы и где живут рутина и ошибки.

## Ключевые вопросы
- Какие операции они выполняют?
- Какой объём?
- Где рутина и где ошибки?

## Связи (рёбра)
- N0 → R3 — корневое противоречие касается и операционистов.
- R2 → R3 — СБ режет доступы операционистов.
- C1 → R3 — клиент порождает операции (клиент → операции).
- X4 → R3 — часть операционной рутины могут закрывать агенты (пересечение через автозакрытие).
