# Cardex — единое состояние решений (STATE)

Одна точка истины по концепту Cardex: где всё лежит, что решено, что открыто, что дальше. Обновляется каждый ход. Telegram-топик: **ff_future**.

## Картина (2 трека + реализация)

1. **Продукт — граф идей экосистемы Cardex.** Крипто-обмен: сделки, счета, клиенты, кошельки. Корень — противоречие **N0** «вести всё в одном месте vs своя логика у каждого». 23 идеи в 7 бизнес-темах.
2. **Организация моей работы (work-org).** Роль — главный программист. 4 интерфейса (PM Никола · DevOps · команда-пользователи · бухгалтер Павел), ритм Пн/Чт, ядро — мост **capture→дерево**.
3. **🆕 Реализация (deal-flow) + новое ТЗ (tz).** Переведён на дубайскую команду; переносим инфру на их серверы (Bitrix/сделки/клиенты мигрированы). Продукт **DealFlow** = 2 крыла: CRM (`crm-nest-telegram`) + Excel-инструмент (`Forms-Sidebar`, модуль Павла). Договорённость с Николой — пересобрать концепт по-новому → новое ТЗ (ядро Cardex). DevOps: **ноль уязвимостей**. См. `deal-flow/README.md` + `tz/README.md`.

## Решения (все, хронологически)

**Продукт:**
- DEC-1 — граф живёт в FF `docs/03-projects/cardex/`, схема `attention-list`, один навигатор на трек.
- DEC-2 — экосистема моделируется графом (узлы×рёбра), корень N0, не линейный список.
- DEC-3 — raids (I1) и бухгалтерия/«стены» (I2) паркуются до ответа «боль+актор».
- DEC-4/5 — узлы дорощены: сделки, отчёты, деньги (M1/P1/G2), интеграции/курсы, агенты, mini-apps, алерты, справочники, онбординг, аудит.
- DEC-6 — вьютер рендерит только `steps[]`/`paths[]`→реальные файлы; контент вынесен в `.md`, навигатор ведёт по ним; дубль-гид удалён.
- DEC-7 — идеи разложены в дерево `ideas/`: файл на идею (`<id>-<slug>.md`), растёт в свою папку; приоритет — оверлей (`Tier:` в шапке), не линейный.
- DEC-8 — 7 бизнес-тем вместо механических категорий: папка = бизнес-смысл, от абстрактного к конкретному; «паркован» — статус, не папка.

**Организация работы:**
- WDEC-1 — организация работы = отдельный трек рядом с продуктом.
- WDEC-2 — ядро: мост capture→дерево (Telegram=поток, артефакты=истина); ритм созвонов Пн+Чт.
- WDEC-3 — направление = **вариант C (гибрид)**: Telegram спереди + дерево/дашборд сзади; reuse движка кнопок `telegtam-nestjs` + wizard шлюза Движ; **Confluence не строим**, кастом растим по мере боли.
