# Промпт-хендофф: закрепить чат за концептом Cardex

Топик Telegram **ff_future** ведёт концепт Cardex (граф идей продукта + организация работы). Ниже — готовый промпт: вставь его первым сообщением в новую сессию (или закрепи за топиком), чтобы продолжить ровно с этого места, ничего не теряя.

## Промпт (копировать целиком)

```
Этот топик (ff_future) закреплён за концептом Cardex. Мы продолжаем ранее начатую работу — не с нуля.

СНАЧАЛА прочитай, чтобы поднять контекст (пути от корня FF-Personal-Managment):
1. docs/03-projects/cardex/STATE.md        — единое состояние: решения, открытые вопросы, следующие ходы
2. docs/03-projects/cardex/README.md        — мастер-индекс обоих треков
3. docs/03-projects/cardex/cardex-ecosystem.concept.json — навигатор графа продукта
4. docs/03-projects/cardex/work-org/INDEX.md — трек организации работы

О ЧЁМ РАБОТА (2 трека):
- Продукт: граф идей экосистемы Cardex (крипто-обмен). Корень — узел N0 «единое место vs своя логика».
  23 идеи в 7 бизнес-темах: core, deals-process, clients, team-control, money, experience, infra-automation.
  Каждая идея = файл ideas/<тема>/<id>-<slug>.md; растёт в свою папку; приоритет — оверлей (Tier: в шапке).
- Организация работы: роль — главный программист; 4 интерфейса (PM, DevOps, команда-пользователи, сам);
  ритм созвонов Пн/Чт; ядро — мост capture→дерево; направление — гибрид Telegram+дерево (не строим Confluence).

КАК РАБОТАЕМ (режим concept-first):
- Держим высоту: растим граф правильными вопросами, отдаём владельцу 2–4 фокусных вопроса за ход.
- Артефакты важнее чата: решения пишем в файлы (STATE.md + узлы дерева), не теряем в переписке.
- В реализацию (код) — ТОЛЬКО по явному «строй» от владельца. Иначе — концепт.

ПРАВИЛА ДЕРЕВА (иначе просмотрщик не покажет):
- Концепт-навигатор (*.concept.json) должен проходить detectConcept: (type|id) И массив steps[]/paths[],
  где steps ведут на РЕАЛЬНЫЕ файлы (не в кастомные поля). Контент — в .md, навигатор — маршрут по ним.
- После правок дерева: node tools/lint/concept-lint.mjs  и  node tools/lint/doc-tree.mjs (перегенерить карту).
- Файлы держать закоммиченными — untracked просмотрщик не индексирует.

НАЧНИ С: краткой сверки состояния из STATE.md + напомни владельцу открытые вопросы, на которые ждём ответ.
```
