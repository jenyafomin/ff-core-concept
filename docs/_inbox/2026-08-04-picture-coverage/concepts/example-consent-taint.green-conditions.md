# Green-conditions — Ц7/04 consent-taint

> ПРИМЕР заполнения (архитектор, корень). Демонстрирует ДЛИННЫЙ чек-лист семьи C
> (Суверенность-Согласие). Числа/пути — из `coverage/05-…` (глубина 0, `grep taint = 0`).

## Паспорт грани
- **Грань:** Ц7/04 `consent-taint`
- **Ценность:** Согласие
- **Семейство:** **C Суверенность-Согласие** (полный чек-лист C·P·I·G·R·A·T)
- **Обещание:** «Если данные попали в агрегат/линзу/эмбеддинг, ограничение согласия исходной единицы
  НАСЛЕДУЕТСЯ производной — согласие нельзя „отмыть" сверткой.»
- **Множество отказов:** любой путь, где агрегат/RAG/линза отдаёт то, на что нет согласия на
  исходнике; отзыв согласия на источнике не распространяется на производные.
- **Дом грани:** `docs/02-project/core/01-brain/01-overview/01-values/07-soglasie/04-*/`

## Чек-лист осей зелёного
| Ось | Требуется семьёй? | Вердикт | Доказательство / чего не хватает |
|---|---|---|---|
| **C** Цепочка | да | **red** | Нет ни акта-носителя taint, ни линзы-распространителя. `grep taint packages/engine = 0`. |
| **P** Обещание | да | **red** | Закрыт лишь прямой read (`visibility`/`use-vs-read` green), НЕ агрегатный путь — класс отказов открыт. |
| **I** Инвариант-безопасность | да | **red** | Прямая угроза I-7: агрегат/линза может отдать данные в обход `resolve()`. Пока не доказано, что не пробивает. |
| **T** Доказанность | да | **none** | Ни unit, ни product. Kernel-тест `deny-field-everywhere` не покрывает наследование через агрегат. |
| **N** Сосед-безопасность | да | **amber** | Наследование taint не должно задушить Читаемость (всё станет невидимым). Кейс не проверен. |
| **G** Гейт-как-данные | да | **red** | Требуется, чтобы агрегирующая линза проходила PEP `resolve()` с унаследованным ограничением. Нет. |
| **R** Обратимость/Согласие | да | **red** | Нужно taint-наследование + реакция на отзыв (consent-withdrawal). Не построено (revocation-tracking тоже ≈0). |
| **A** Ратификация | да | **red** | Модель наследования согласия при агрегации нигде не ратифицирована (нет decision-узла). |

## Текущая ступень
- **Ступень сейчас:** **S0 Named** — обещание и множество отказов ясны, цепочки нет (C red).
- **Обоснование:** ни одна ось выше S0 не закрыта; даже S1 требует C(на бумаге)+I(аргумент) — дизайна
  наследования пока нет.

## Что не хватает до зелёного
- [ ] **S1:** спроектировать носитель taint (поле на конверте? отдельный акт?) + линзу-распространитель; доказать рассуждением совместимость с I-7 (C, I).
- [ ] **S2:** kernel-тест «агрегат наследует ограничение согласия, обход PEP через линзу отклонён» (T=unit, G).
- [ ] **S3:** состязательный кейс «taint не задушил Читаемость» (N) + реакция на отзыв (R) + ратифицировать модель наследования decision-узлом (A).
- [ ] **S4:** E2E на реальном корпусе — согласие на источнике реально ограничивает выдачу агрегата (T=product).

## Чем доказать
- **unit:** расширить `capability.test.ts`/`invariants.test.ts` кейсом «aggregate-lens inherits consent, bypass denied».
- **product:** E2E — записать единицу с ограниченным согласием → запросить агрегат через линзу → выдача урезана; отозвать согласие → агрегат перестаёт отдавать.

## Риск соседям (ось N)
- **Соседняя ценность под угрозой:** Читаемость/Витальность (слишком агрессивный taint = всё невидимо/бесполезно).
- **Как пробивает:** консервативное наследование «любой контакт заражает» схлопывает полезную выдачу.
- **Митигация:** taint как policy-данные (степень/scope наследования настраивается), не хардкод «всё-или-ничего».
