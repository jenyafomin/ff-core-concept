# «Клиент» + n8n-тулкит

**Суть:** простые динамические единицы → гибкий тулкит над данными; гибкие настройки самой базы.

**Три прочтения термина «клиент» (не различены владельцем — сделать ПЕРЕД поиском дома):**
1. **домен-сущность** — клиент как бизнес-объект (customer node).
2. **коннектор-плагин** — клиент как адаптер к внешней системе (API-клиент).
3. **generic-слой** — клиент как универсальный интерфейс доступа (n8n-подобный конструктор нод).

**Зачем/к какой ценности:** Ц4 «дешёвое расширение / n8n» (P1) — тип=данные + sync-адаптер, заблокировано
на S7 (durable-store), который теперь ядром закрыт (2026-08-04).

**Статус проработки:** НЕ разобрано — топ-пробел #5 из critic-коррекции 08-01. Термин двусмыслен, различить
смысл перед выбором дома в дереве.
