# Policy-scope — узел с каким уровнем видимости (project/universal)

**Суть:** policy УЖЕ ратифицирована (08-01, Р1) как **особый узел** (не 5-я публичная грань) — соединяется
с актором/линзой/др., переиспользуется между проектами, задаёт области видимости («здесь начинается своя
область»), бывают глобальные policy.

**Что осталось нерешённым (хвост Р1, не закрыт):** с каким scope живёт конкретный узел policy — project vs
universal? Нужно связать с ADR-0004 (LSR-стек: reach+authority) и с уровнями `constitution.md` (Universal →
Domain → Project → Experimental scope-иерархия уже существует в глобальных правилах владельца — потенциальный
готовый прецедент для переноса в проектный канон).
