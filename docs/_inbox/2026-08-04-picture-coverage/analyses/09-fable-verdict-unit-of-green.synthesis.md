# Вердикт Fable — какова единица «зелёного»

> Точечный совет Fable на корневой развилке. Уточняет модель осей (06) и метрику карты (00).

## Вердикт (резко)
Единица «зелёного» — **ни грань, ни пара**: она **двухслойна**, и парный слой **факторизуется через
МЕХАНИЗМ** (lossy-редьюсер), а не через абстрактную «пару ценностей».
- Конфликт живёт в конкретном редьюсере, который делят две грани: dedup↔варианты (dedup-редьюсер),
  cascade↔композиция (машинерия удаления рёбер), consent-taint↔агрегация (`resolve()`/агрегат-линза).
- Две грани конфликтуют ⇔ делят механизм с противоположными множествами отказов.
- Граф конфликтов НЕ 42×42=861, а **разрежён через ~9 линз/механизмов → ~10-20 пар**.

## Оси расщепляются (двухслойность = ДА)
- **C·P·T** — внутренние свойства грани. По ним по-гранный разбор ВЕРЕН, не выбрасывать.
- **N·I·G** — свойства РАЗДЕЛЯЕМОГО механизма, не принадлежат ни одной грани.
- **S3 (Green-hardened) из модели-06 = и есть парный гейт**, он уже встроен — но считать его надо
  per-mechanism с контрподписью, а не per-grain.
- **Ошибка была в ЧТЕНИИ метрики, не в модели:** S2 = прогресс к «построено», НЕ к «зелёно».
  Зелёное = per-grain floor (S0→S2) **+** per-mechanism gate (S3).

## Как мерить честно (два числа, никогда одно)
- **Built%** — нынешние M1=19% / M2=35%. Переименовать: это честная метрика СТРОЙКИ.
- **Discharged%** — доля закрытых конфликт-пар из реестра механизмов.
- **Правило контрподписи:** N-вердикт грани ОБЯЗАН назвать контр-грань и сослаться на ОДИН общий
  состязательный тест, засчитываемый в чек-листы ОБЕИХ граней. Грань не может объявить себя S3 в
  одиночку → по-гранное враньё структурно невозможно, при этом по-гранный разбор сохраняется.

## Дизайн волн C — ГИБРИД, порядок
- **C0** (одна дешёвая волна, ДО фан-аута): построить **реестр пар per-mechanism** (~9 механизмов → пары).
  Без него фан-аут слеп. Признак генератора конфликта = **lossy-свёртка** (dedup, latest-wins, cascade,
  erasure); чисто аддитивные редьюсеры пар НЕ рождают → поверхность конфликтов перечислима заранее.
- **C1** (по граням, параллельно, как планировали): S0→S2. По-гранный дизайн ВЕРЕН — не выбрасывать.
- **C2** (по МЕХАНИЗМАМ, не по парам): один агент на механизм — состязательные кейсы всех его пар сразу
  (агент «на пару» зря дублирует контекст механизма).
- **Приоритет C2:** механизмы уже shipped (dedup в ga-rentacar) — первыми; **shipped-S2-без-S3 =
  единственная ЖИВАЯ ложь**, остальное — бумажная.

## 🔴 Решение ТОЛЬКО владельца (ни одна волна не примет)
S3 говорит «прогони состязательный тест», но молчит, **КТО выигрывает, когда тест честно провален.**
Нет ратифицированного **межценностного порядка/арбитража 7 ценностей** (constitution-clamp есть как
механизм Ц5, но не как ранжир между ценностями). Первый реальный конфликт-пара упрётся в это.
→ Нужен **конституционный ранжир/протокол разрешения** конфликтов ценностей. Кандидат в ADR.

## Дельта к модели-06 (применить)
Расщепить S3: ось N считать **per-mechanism с контрподписью**, не per-grain. Допущение №4 модели-06
(разносить N-гейт) — Fable подтвердил.
