# Направление N-G — Углубление памяти: условия «зелёного» + пересмотр путей

> Запрос владельца (голос 2026-08-04): карта покрытия дала **M1=19% / M2=35%** — «максимально слабо».
> Это ценно: теперь **корень надо тщательно обдумать в первую очередь**, учесть разные абстракции.
> Заводим это как ОТДЕЛЬНОЕ НАПРАВЛЕНИЕ, живущее в проекте; STATE о нём знает.

## Зачем (цель направления)
Превратить слабое покрытие brain из «числа» в **программу углубления**: для каждой грани ценности
определить **условия, при которых она станет «зелёной»** (разные состояния/ценности учесть), поэтапно
пройти каждую найденную проблему, и параллельно — **пересмотреть, не были ли прежние пути неправильными**.

## Две стороны медали (обе обязательны)
1. **Вглубь (deepen):** каждую найденную дыру/проблему разобрать тщательно → условия «зелёного».
2. **Назад (re-examine):** то, что мы переоценили (канон завышал статус, `cost-tree`≠Витальность,
   `agent_trace`-сирота, dedup-без-защиты-вариантов, KQ-11 память=проекция-vs-узел, KQ-1 ветка=форк-vs-проекция) —
   не признак ли это **неверного прежнего ПУТИ**, а не просто недоделки? Что переоткрыть.

## Метод
- **Корень-first.** Сначала обдумать корень (что такое «зелёное» для грани, какие условия/состояния),
  ТОЛЬКО потом фан-аут по 42 граням. Не мега-фан-аут вслепую.
- **Волнами, синхронно** (под шлюзом фон запрещён): волна → гейт (критик/co-orchestrator) → синтез.
- **ТЗ-помощник:** `prompter` (обычный) готовит технические задания; **Fable** (`fable-advisor`) —
  только на тяжёлых «правильных» вопросах корня, вопрос готовится артефактом.
- **Максимум ресурсов на brain** параллельно (это направление — про память конкретно, не про другие модули).

## Структура артефактов (этапы + перелинковка + дома)
- `analyses/` — карта покрытия, каркас, модель «условий зелёного», разбор корня.
- `concepts/` — этапные концепты углубления (по граням/группам), перелинкованы между собой и с синтезами.
- `questions/` — вопросы, поделённые на этапы (staged); закрытые → `decisions/`.
- `decisions/` — ратифицированные условия/пути.
- Созревшее → переезжает в постоянный дом (`core/01-brain/…`), STATE обновляется.

## Ворота направления (что считаем результатом)
- [ ] Корень обдуман: единая **модель «условий зелёного»** (шаблон, по которому оцениваются все грани).
- [ ] Список **подозрительных путей** (сторона 2) с решением «переоткрыть / оставить».
- [ ] Поэтапный разбор граней с их условиями зелёного (приоритет по стеку из карты покрытия).
- [ ] Всё живёт в проекте, STATE знает; дубли не плодятся.

## Корень разрешён (Fable, 2026-08-04) — см. `analyses/09-fable-verdict-unit-of-green.synthesis.md`
Единица зелёного **двухслойна**: per-grain floor (оси C·P·T, S0→S2) + per-mechanism gate (оси N·I·G, S3,
контрподпись). Конфликты факторизуются через ~9 **lossy-механизмов** → ~10-20 пар (не 42×42). Метрика =
**Built%** (19/35) + **Discharged%** (закрытые пары). 🔴 Решение владельца: **межценностный ранжир** (арбитраж
при провале состязательного теста) — кандидат в ADR.
