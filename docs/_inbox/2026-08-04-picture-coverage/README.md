# Бокс-тема: покрытие и приоритеты всей картины

> Стейджинг-бокс (`_inbox`). Сюда складываем сырьё многогранной работы: инвентарь строительных
> блоков, идеи, вопросы, анализы, решения. Созреет → распределим по постоянным домам проекта
> (или сразу, где дом очевиден). Trace/указатели — истина живёт в файлах по ссылкам.

## Зачем эта тема (запрос владельца, голос 2026-08-04)
1. **Разложить тщательно** всю картину — из чего состоит то, что мы строим.
2. **Определить % покрытия** разных вещей и **приоритеты/важности** — по всей картине, не только durable-store.
3. **Новый каркас владельца:** ценностей МНОГО (отдельные грани) → **линз МЕНЬШЕ** → **актов ЕЩЁ меньше**.
   Каждая линза/направление дополняет картину по-своему. Считать покрытие вдоль этой иерархии.

## Рубрика (каркас для карты покрытия)
```
ценности (много граней)   — что субстрат ОБЯЗАН обслуживать
        ↓ обслуживаются через
линзы (меньше)            — проекции/направления fold(journal); каждая дополняет по-своему
        ↓ сворачиваются из
акты (меньше всего)       — атомы записанной правды в ленте-журнале
```
«Покрыта» ценность = существует цепочка `акт → линза`, которая её обслуживает (определение уточняет
`analyses/02-*-frame`).

## Контейнеры бокса
- `analyses/` — инвентарь блоков, каркас, карта покрытия, приоритеты.
- `questions/` — открытые развилки (типизированные, дедуп, со ссылками на источник).
- `ideas/` — сырые идеи-кандидаты (широкие направления).
- `decisions/` — закрытые развилки (переезжают из questions/ по мере решения).
- `_shared/` — глоссарий, сквозные определения.

## Метод сессии
Волны свежих агентов (синхронно, под шлюзом фон запрещён) → гейт (критик/co-orchestrator) → синтез.
Волна 1 = грунтовка (инвентарь + сбор идей + каркас). Волна 2 = скоринг покрытия/приоритетов. Гейт → карта.
