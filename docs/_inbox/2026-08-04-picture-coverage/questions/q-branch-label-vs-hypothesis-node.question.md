# Ветка = метка-линия vs узел-hypothesis?

**Суть:** T-ACTS-AS-GIT (08-01) решил, что акты уже = git-алгебра (ADR-0008), ветка = метка-линия над ОДНИМ
логом (не второй лог); copy-vs-link = вопрос идентичности (LINK по умолчанию, COPY только при намеренном
расхождении, COPY ≠ второй источник истины). Но осталась нерешённой форма самой метки:

- **(A)** ветка — просто ЛЕЙБЛ/тег на записях (дёшево, не адресуема отдельно).
- **(B)** ветка — адресуемый узел-`hypothesis` (можно ссылаться, версионировать саму ветку, GitHub/PR-подобно).

**Что блокирует:** прогонку через 5-воротный тест не делали; приоритет поднять (владелец отметил «GitHub/PR
⇒ адресуемый узел» как аргумент за B).

**Связь:** tension-with `oq-1-branch-fork-vs-projection.question.md` — смежный, но отдельный: OQ-1 про
семантику ЛЕНТЫ (форк vs проекция), этот вопрос — про форму данных самой ветки-метки.
