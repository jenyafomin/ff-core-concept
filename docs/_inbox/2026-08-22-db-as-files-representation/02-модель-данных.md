# 02 · Модель данных: три вещи

Вся база стоит на трёх формах. Все они — реальный TypeScript в `packages/engine/src/core/types.ts`.

## 1. Акт (`Act`) — единица записи. «Что произошло»
Строка журнала. Неизменяема после записи.
[VERIFIED `types.ts:324-349`]

Поля (реальные):
- `id`, `actor` (кто заявляет запись), `actKind` (вид акта), `edges` (рёбра, которые несёт акт),
  `provenance` (происхождение / ключ проекции), `recordedAt` (время — **ставит движок**, не вызывающий).
  [VERIFIED `engine.ts:74-75` — `recordedAt` присваивается движком, immutable]
- PII (персональные данные) — **только по ссылке**: `payloadRef` + `payloadHash`, не «инлайн».
  [VERIFIED `types.ts:316-323,332-339`]

Виды актов (`ActKind`, расширяемый список): `domain_event`, `observation`, `command`, `access_event`,
`agent_trace`, `system_telemetry`, `erased`. [VERIFIED `types.ts:225-238`]

## 2. Узел (`EnvelopeNode`) — единица графа. «Что есть сейчас»
Появляется как **проекция** актов вида `domain_event`. Ровно 10 системных полей:
`id · type · state · edges · view · visibility · access · acts · policy_ref · body`.
Доменные поля живут ТОЛЬКО в `body`. [VERIFIED `types.ts:122-147`]

Важно: узел — это НЕ то, что вы пишете напрямую. Вы пишете **акт**, движок сворачивает его в узел.
[VERIFIED `projection.ts:76-123` — `foldInto`]

## 3. Ребро (`Edge`) — связь. «Как узлы связаны»
Направленная типизированная связь: `predicate` (тип связи) + `target` (куда). [VERIFIED `types.ts:32-51`]

Зарезервированные (форма есть, поведения НЕТ):
- `provenance` — какой источник заявил ребро. [VERIFIED, потребляется частично]
- `validFrom` / `validTo` — «время на ребре». **Форма есть, проекция НЕ читает (P2).**
  [VISION — `types.ts:38-41` прямо: "RESERVED … NOT folded/consumed at P1"]
- `subjectRole` / согласие на ребре — форма заморожена, enforcement за швом.
  [VISION — `types.ts:42-63`]

## Как это читается владельцем
- **Пишешь факт** → это `Act` (`domain_event`) с `provenance.source_ref` = стабильный ключ.
- **Смотришь состояние** → это `EnvelopeNode`, собранный движком из всех актов на этот ключ («свежее побеждает»).
  [VERIFIED `projection.ts:8-15,95` — freshest wins]
- **Связь между фактами** → `Edge` с предикатом; кардинальность (`one`/`many`) — данные, не хардкод.
  [VERIFIED `types.ts:99-108`; `projection.ts:113-115`]

Диаграмма потока: `Act (пишешь) → admit()/страж → журнал → project() → EnvelopeNode+Edge (читаешь линзой)`.
