# Fact-base: вся информация в одной карте

> Свод 5 переписей. Это вход для совета (Фаза 2) и «правильная документация» вместо линейного лога.

## Изначальная ценность (якорь, цитата OVERVIEW)
«Рабочий **СУБСТРАТ для ИИ-агентов** (не хранилище заметок): один граф, где живёт всё, с чем работают
агенты; гибкий продукт-память, растущий от крошечного до огромного **без миграций**.»
→ Всё ниже мерим вопросом: приближает ли это к живому субстрату, которым пользуются агенты?

## 🔴 Сквозные истины (то, ради чего собирали)
1. **Durable S7 запечатан, но им НИКТО не пользуется** — все production-модули ga-rentacar живут на
   `MemoryStore`. «Память навсегда» построена, но не подключена к жизни. (censuses 02,05)
2. **Контракт brain↔agents ПУСТ** (`core/03-contract/` = заголовки, не рос с 07-06), хотя реализация
   `balance-observer` его обогнала. Слой агентов держится на одном агенте в коде, и тот на ветке, не в main.
3. **Канон лжёт о статусе** (подтверждено кодом): `access_event`/`system_telemetry` = enum без писателей;
   explain-chain/T-7 = 0 строк; `cost-tree` = Σ токенов, не «Витальность». **Витальность = 0 кода вообще.**
4. **M2 ga-rentacar не зелёный по-настоящему:** линза обходит PEP и не читает `same-as` — построили
   зелёный модуль В ОБХОД `resolve()`. Урок жильца ядру: **PEP обязан быть дверью, не opt-in.**
5. **Пульт — это и есть «линейность», которую ты не любишь:** `STATE.md` = 517 строк append-стека RESUME;
   ветки (ga-rentacar, durable-store, picture-coverage) не заведены как состояния; `log.md` заброшен;
   `_log/` весь gitignored (вне git). Тезис фикса УЖЕ родился (см. ниже).

## Ценности × код-якорь (реальность, не доки)
Сильный: Суверенность (`resolve.ts` PEP), Реляционность (edge-index/predicates). Частичный: Доверие
(PII-часть; one-home fail-open), Тождество (dedup без потребителя), Согласие (`valveGate` есть, erase — форма).
**Слабо/нет:** Читаемость (нет паспорта), **Витальность (0 кода).**

## Strawman: ключевые направления → последовательные состояния (черновик для совета)
> НЕ финал — вход для Opus+Fable. Каждое = состояние-папка с целевой точкой, ведётся до «правильной точки».
- **S-A · Субстрат-ядро зелёный** — программа N-G (условия зелёного, конфликт-пары) + **подключить durable к жизни** (снять MemoryStore) + закрыть «канон лжёт». Целевая точка: Built% растёт честно, Discharged% стартует.
- **S-B · Жилец ga-rentacar** — M2/M3 через PEP+same-as, 4 живых риска. Точка: первая ценность «агент с памятью» на реальных данных, PEP-обязателен.
- **S-C · Агентный слой + контракт + шлюз** — наполнить контракт brain↔agents, починить 2 бага шлюза (dup/restart, egress-outbox OQ-4). Точка: >1 агента в коде, надёжная доставка.
- **S-D · Процессная организация (мета)** — конвертировать линейный пульт в **граф веток-карточек**: `STATE.md` = таблица-индекс «ветка→статус→куда», каждая ветка = state-папка с `handoff:`-ссылкой на трейс. Точка: следующая сессия стартует по индексу, не по 517-строчной хронике.
- **Сквозная развилка владельца:** межценностный **арбитраж 7 ценностей** (из вердикта Fable) → ADR.
