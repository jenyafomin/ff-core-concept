# 🔗 Ребро / связь (edge)  ← P11

## Что это / что хранит
Связь между узлами. Физически = строка в `edges`. Два класса (заложено): **thin-ref** (структурная
ссылка владельца, напр. `member-of`) и **assertion** (утверждение автора с consent, напр. `categorized-as`).
Хранит: тип ребра, направление, класс, provenance, время.

## Зачем (для кого)
«Поле связи подсказывает очень много» — рёбра = то, чем агент реально навигирует и рассуждает. Их надо
**ломать и смотреть по-разному**: что ребро представляет, как связано с доменной структурой и с модулями.

## Кейс-эталон (под стресс-тест)
**Комментарий к конкретному тексту внутри файла.** Если файл дробим на части — сослаться:
(а) дробить на отдельные ноты + ссылка нота→нота (логично, не ломает систему), ИЛИ
(б) более универсальный механизм — **якорь/span** (ссылка на диапазон внутри узла). Выбрать в потоке.

## Различение (владелец)
Инфра-связи бывают двух родов: **для продукта** (приложения продукта) vs **для создания самого продукта**
(инфра-действия разработки). Ребро должно уметь это различать. → см. таксономию инфры.
