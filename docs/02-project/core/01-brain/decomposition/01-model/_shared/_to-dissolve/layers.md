# 🧱 Слои информации  ← P9

## Что это / что хранит
Ось паспорта «чей это слой / для чего он». Владелец назвал слои:
- **пользовательский** — личное человека;
- **системный** — определения типов, сама модель данных (реестр); делится на **несколько уровней**
  (разная системная инфа для разных вещей, вплоть до саморазвития — трудно отнести к чему-то конкретному);
- **агентский** — система строится ДЛЯ агентов; данные могут принадлежать агенту (≈ системный подвид);
- **проектно-локальный / глобальный** — глобально на машине все проекты/модули; локально в модуле —
  свои прописанные возможности/видимые проекты.

## Зачем (для кого)
Чтобы явно разделять принадлежность и видимость данных; связано с erase (системное обычно не стираем,
пользовательское — да) и с ACL/consent.

## Где ляжет в канон
Новая грань паспорта рядом со `scope`/`storageLevel`; кандидат в DECISIONS-LOG после разбора.

## Открыто (главное)
- Это ОДНА ось или несколько независимых: **владелец × слой × локальность**? (риск размножить оси зря).
- Агентский слой = подвид системного или самостоятельный?
- Как «системный делится на уровни» соотносится с уровнями детализации категорий.
