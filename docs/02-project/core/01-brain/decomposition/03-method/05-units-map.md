# 🗺️ Карта единиц — 4 кубика модели

> Из `VISION-SIMPLE`: из **Вещь · Связь · Акт · Проекция** собирается практически любой паттерн знаний.
> Углубляем каждую по единому методу (`01-method.md`). Ниже — статус, тугие узлы, что уникально.

## 1 · Вещь — DONE (референс-реализация)
Тугие узлы: паспорт · policy-блок · резолвер контекста · варианты/проекции + `_critique`.
Даёт шаблон для остальных трёх. Здесь — только «углубить глубже» (5-я/6-я грань примитивов — волна из `01-node/START-HERE §🌊`).

## 2 · Связь (edge) — уникальное
Ребро — **первоклассная память, а не служебная нить** (Ц-6 Реляционность). Тугие узлы:
- **Паспорт ребра** — есть ли у связи свой owner/scope/policy, или наследует от концов?
- **Типы ребра** — `member-of` · `categorized-as` · `variant-of` · `grounds` · … (расщепление уже в DL).
- **Поток по ребру** — «ребро проводит поток» (каскад/инвалидация/freshness) — часть контракта пропагации.
- **Ребро-как-инсайт** — связь сама может быть узлом-знанием (Г16·Г17·ребро-инсайт).

## 3 · Акт (act) — черновик уже есть (unit/NEXT-STEPS §1)
Акт = **«вторая единица»** (глагол). Тугие узлы (перенести из NEXT-STEPS):
- **Паспорт акта** — actor · authority · idempotency-key · ref+hash · time.
- **Журнал** — append-only; чтение/запись = тоже акты; rebuild-from-journal.
- **Идемпотентность** — ключ (лечит дубль-баг шлюза заодно).
- **Контракт пропагации** — lineage + инвалидация + freshness (Fable: 5 решений = 1 механика).
- **Plugin-API** — плагин = актор + словарь; вся поверхность = API актов.
> Готов черновик ADR «Акт и журнал» (закрывает DEC-6, гонку D8-Q3, self-escalation, идемпотентность).

## 4 · Проекция / линза (lens) — уникальное
Одна вещь под нужным углом нужному читателю. Тугие узлы:
- **view-def** — как объявляется проекция (в данных vs система).
- **Выбор среза** — кто подбирает проекцию под состояние агента (`вещь × актор × линза × время`).
- **Цена read-time** — материализация/кэш на масштабе (~100k узлов — death-by-design кандидат из NEXT-STEPS §4).
- **Проекция-во-времени** — снапшот = проекция над журналом актов (не отдельная фича).

## Порядок углубления — РАЗВИЛКА (Q-2)
Кандидаты «первой следующей»:
- **Акт** — черновик готов, разблокирует шлюз-баг + plug-in API + пропагацию (наибольший рычаг).
- **Связь** — ближе всего к Вещи, малый прыжок, закрывает Ц-6.
- **Проекция** — держит «многомерность» и снапшоты, но упирается в цену read-time (стек-зависимо).
- **Всё сразу (скаффолд)** — завести 3 пустых дома, наполнять волнами.
> Рабочая рекомендация: **Акт первым** (рычаг + черновик), Связь второй, Проекция третьей.
