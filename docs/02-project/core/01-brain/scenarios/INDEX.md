## Карта сценарий → вскрытый концепт → ценность

| Сценарий | Вскрывает | Ценность |
|----------|-----------|----------|
| Три свидетеля одного события | event-anchor, `standpoint`, ко-референция | Тождество · Согласие |
| Отменённое решение, живые последствия | RETRACTED≠Забыть; `derived-from` vs `caused` | Реляционность |
| Реинтерпретация прошлого | interpretation-time (tritemporal), глагол «Переосмыслить» | Витальность |
| Данные под одним согласием → для другого | consent-taint (наследуемая лицензия) | Согласие |
| Милосердная ложь владельцу | custodial-override (аудируемое сокрытие) | Согласие · Доверие |
| Агент на устаревшей ячейке → катастрофа | актуальность реляционна; supersession-duty | Доверие |
| Тихая эрозия принципа | память об ОТСУТСТВИИ; детектор тишины | Витальность |
| Композиция/распад ячеек | контракт «композит: свой id или производный?» | Тождество · Реляционность |
| Смена ТИПА ячейки | протокол перевоплощения | Тождество · Читаемость |
| Память о будущем | модальность намерение≠истинность | Витальность · Доверие |
| Групповая/семейная память | политика по паре (ячейка, участник) | Согласие · Суверенность |
| Мета-память агента | класс «ephemeral/scratch» | Витальность |
| Конфликт линз ролей | арбитраж на выходе control-plane | Реляционность |
| «Право быть непонятой» | флаг «сопротивляться консолидации» | Читаемость · Согласие |
| What-if песочница | sandbox copy-on-write | Суверенность |

## Ключевые линзы (Opus)
- **Процессуальная** — «что память ДЕЛАЕТ со мной сейчас».
- **Реляционно-этическая** — «перед КЕМ обязывает» (шлейф долженствований по графу).
- **Герменевтическая** — «что ЗНАЧИТ сейчас» = недостающая механика «волны».

## Мета-вывод (Opus+Sonnet сошлись)
Модель сильна в «ячейке-в-себе», слаба в ОТНОШЕНИЯХ ячеек во времени и между акторами. Кандидат-примитив: **ячейка-операция** (память 2-го порядка).
