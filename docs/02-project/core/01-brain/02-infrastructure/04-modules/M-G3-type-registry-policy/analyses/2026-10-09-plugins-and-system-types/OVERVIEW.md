## Что это (в одной мысли)
Одна память на всё. Внутри — неизменяемое ядро типов, а плагины (баг-трекер, задачи, «кухня» шлюза)
приносят свои группы типов, связываются с остальным через рёбра. Агент, система и человек смотрят в одно.

## Зачем
Предсказуемость (один контракт для агента, софта и человека) → из неё растёт составляемость → маркетплейс.

## Что уже сделали (3 линзы: architect · abstract-thinker · critic) — сходятся
- **Направление владельца верно** (все трое): одна модель типов, системные типы, «оставить кухню в шлюзе
  навсегда» = вечный долг «двух правд».
- **Слои типов:** `core:` ядро (запечатано) → `sys:` системные пакеты → `pack:` плагины → `u:` пользователь
  → «тропы» (типы, рождённые использованием, кандидаты). «Запечатано» = версия не меняется; расширение =
  только новые необязательные поля / подтип `extends@v` / свой узел + ребро. Ломающее = новая мажор-версия.
- **Плагин = манифест** (типы, связи, `implements core:task` → чужой софт и агенты понимают сразу,
  политики, согласия, виды). Удалили плагин → его данные «остывают», не исчезают (V4/V5).
- **«Одна память» ≠ один файл.** Один реестр типов, одни id, одни рёбра; хранилище — по типу
  (журнал-файл для знаний, Postgres для массовых системных типов). Миллионы в JSONL-журнале не живут.
- **Кухня шлюза — лестница, не прыжок:** L0 описать 15 сущностей шлюза как пакет `sys:gateway` на бумаге →
  L1 зеркало только-чтение (outbox) → L2 Postgres + прямой API (не MCP) + бенч 1М → L3 двойная запись,
  7 дней без расхождений → L4 переключение по одному типу. Дедуп/lease — последними или никогда
  (нужен атомарный CAS; иначе память упала = Telegram молчит).

## Расхождение линз (сигнал)
- abstract-thinker: **первый плагин — не кухня, а задачи/баг-трекер** (дешевле доказывает «пакет+связи+софт»,
  владелец это реально читает). architect: начать с кухни как `sys:`-пакета. → Совмещается: **L0 на бумаге
  сразу для обоих** (кухня + баг-трекер) — проверка «влезает ли в модель без правок кода».

## Как ложится на 7 ценностей
V1 🟢 (виды по пакетам) · V2 🟡 (версии типов — односторонняя дверь) · V3 🟢 · V4 🟡 (кухня раздувает — нужен
`persistence_class`) · V5 🟢 (манифест несёт политику) · V6 🟢 (рёбра между пакетами — суть) · V7 🟡 (согласие
по целям — пока только форма).
