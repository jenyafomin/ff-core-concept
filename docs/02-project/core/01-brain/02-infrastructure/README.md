# 02-infrastructure — как строим

Эта ветка отвечает на вопрос **«КАК построить»** субстрат, спроектированный в `01-model`
(«ЧТО строим»). Здесь живут реализация-компоненты, движки, слои платформы и стресс-проверки
полноты.

## Цепочка деривации

```
домены (01-model: что за единицы)
   → модули (04-modules: компоненты-реализация: M-G1..G5, M-P3 + пул идей)
      → платформы (02-backend / 03-frontend: движок, доступ, слои)
         → сквозные механики (_shared: reification и т.п.)
```

## Разделы

| Раздел | Что несёт |
|---|---|
| `01-overview/` | вход-навигатор: индекс архитектуры, костяк инфры (5 опор, горизонты, ADR-кандидаты), стек, сценарии-стресс-тесты, снимок готовности БД (`db-readiness/`), карта переноса (`MIGRATION-BLUEPRINT`). Читать первым. |
| `02-backend/` | движок исполнения (Temporal-lite, CONCEPT-02) и доступ как policy-as-data (CONCEPT-03). |
| `03-frontend/` | (пока пусто) UI-слой платформы — заводится по мере надобности. |
| `04-modules/` | компоненты-реализация: 6 модулей `M-G1..G5, M-P3` (форма-фасет уже верна) + `ideas/` (пул из 16 модулей = нарезка 70 идей). |
| `_shared/` | сквозные механики, делимые между единицами (`reification.md` — ребро vs узел). |

## Underscore-бакеты

Сквозное — всегда с `_` (видно, что оно сквозное): `_shared/` (решённые сквозные механики),
`_unverified/` (выявленные-но-нерешённые механики — заводится по мере выявления), `_archived/`.

См. `GROWTH-MAP.md` — как ветка углубляется дальше.
