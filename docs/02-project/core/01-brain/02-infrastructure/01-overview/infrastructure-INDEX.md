## Несущий костяк (5 опор — по числу пересечений)

Опоры отсортированы по тому, сколько модулей и ценностей на них висит. Их проектируем и ратифицируем
**первыми** — на них держится всё остальное.

| Опора | Модуль | На ней висит | Пересечений |
|-------|--------|--------------|:-----------:|
| **Паспорт / policy-as-data шейп** | #7 | Линза (#6), Confidence (#8), PEP (#5) читают его поля; вся суверенность/согласие живёт в policy-блоке. **Это узел конституционного трения** (минимальный шейп vs per-type policy). | Ц1·Ц3·Ц4·Ц5·Ц7 |
| **canonical_id / Хребет тождества** | #1 | Bitemporal (#2), Edge Engine (#11), Провенанс (#4), Дедуп (#13), Forgetting (#9) — все проекции адресуются им. | Ц1·Ц2·Ц4·Ц6 |
| **Bitemporal / Движок времени** | #2 | Самый частый механизм (6 из 7 ценностей): версии, аудит, переосмысление, закрытие рёбер, откат схемы, забыть=закрыть tx-time. | Ц1·Ц2·Ц3·Ц4·Ц5·Ц6 |
| **Единый PEP / Порог доступа** | #5 | anti-zombie независимо всплыл в Ц-3, Ц-5, Ц-7 → сильнейший кандидат в опору. Линза, capability, use≠read, tenant, taint — всё принуждается здесь. | Ц1·Ц3·Ц5·Ц6·Ц7 |
| **Конституция / integrity-as-engine-duty** | #16 | Потолок над локальной policy: референт>владелец, hard-erase безусловен. Ограничивает Суверенность (#7/#15), исполняется движком. | Ц1·Ц3·Ц5·Ц7 |

**Связующая ткань** (не опоры, но несут много рёбер между опорами): **Провенанс/Lineage (#4)** и
**Edge Engine (#11)** — по ним ходят три механизма сразу (провенанс, consent-taint, forgetting-cascade),
см. open-question 8.

## Кандидаты на ADR (по конституции — до кода)

1. **Конституционный паспорт: минимальный шейп + policy-as-data** (#7 + #16) — центральное трение
   дивергенции («единый движок-примитив» vs «чистый per-type policy»; Суверенность Г14 ↔ дешевизна движка).
   **Решение уровня КОНСТИТУЦИИ.** Приоритет №1 по несущести.
2. **canonical_id + порядок времени** (#1 + #2, HLC/event-sourcing) — хребет тождества; заложить сейчас.
3. **Bitemporal / время-версии** (#2) — самый частый механизм; может быть частью ADR №2 или отдельным.
4. **Единый PEP / порог доступа на все каналы** (#5) — anti-zombie; безопасность/доступы.
5. **Forgetting Engine — два примитива sleep + hard-erase** (#9) — развязка FQ7; **решение владельца**.
6. **Event/Referent Anchor + протокол конфликта** (#3) — закрывает L0-пробел (Ц2) и Г20 (референт, Ц7).
7. **Edge Engine / edge-as-cell + RDF-star паспорт ребра** (#11) — В4 уже ратифицирован Opus, нужен спек-ADR.
8. **Engine Contract + key-custody** (#15) — фундамент plug-in/маркетплейса; заложить сейчас.

## Что дальше (порядок разбора по несущести)

**Паспорт/policy (#7) + Конституция (#16)** [решить трение первым] → **canonical_id + Bitemporal (#1/#2)** →
**Единый PEP (#5)** → **Event/Referent Anchor (#3)** → **Edge Engine (#11)**. Каждый перед кодом — через
`critic`, затем ADR внутри своего модуля. Складки (см. `ideas/candidates.md`) отдельных ADR не требуют.
