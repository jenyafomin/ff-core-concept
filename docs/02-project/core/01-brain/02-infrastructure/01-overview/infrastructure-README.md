> Эта папка стои́т **рядом с `values/`, не внутри**. Сюда попадает всё, что задевает **≥2 ценностей**
> (тегов Ц-1…Ц-7) — сквозные, «глобальные» примитивы, которые несут сразу несколько граней. Одна и та
> же идея приходила от 7 агентов под разными именами; здесь она **сведена в один модуль**.

## Структура папки

| Место | Что лежит |
|-------|-----------|
| `ideas/` | **Все наброски** — сырой пул кандидатов в инфра-модули. Ничего не режем. Стартовый список — `ideas/candidates.md`. |
| `analysis/` | **Пунктные последовательные разборы** отдельных модулей (analyst / architect / critic). Один файл = один модуль. Заводится по мере проработки. |
| `open-questions.md` | Открытые вопросы и напряжения, всплывшие при дивергенции (решаются с владельцем или следующим циклом). |
| **корень** (`NN-модуль/`) | **То, что уже определили.** Подтверждённый модуль забираем из `ideas/` и кладём сюда отдельной папкой. |

## Как движется модуль (по шагам)

```
ideas/ (набросок)  →  analysis/ (разбор по пунктам)  →  корень NN-модуль/ (определён)  →  ADR/Spec (перед кодом)
```

Не фильтруем «в лоб» — просто **забираем определённое из `ideas/` в корень**. Пул в `ideas/` остаётся
как история и источник сведения.

## Правило подъёма (по тегам)

Идея несёт теги — все ценности, которых касается. **1 тег** → живёт локально в своём направлении
(`../values/NN-*/`). **≥2 тега** → по определению сквозная → сюда. Папка = где работаем; теги = чему
служит. Словарь тегов: Ц-1 Читаемость · Ц-2 Тождество · Ц-3 Доверие · Ц-4 Витальность ·
Ц-5 Суверенность · Ц-6 Реляционность · Ц-7 Согласие.

## Типы модулей (буквенные метки, по смыслу FF)

**О** — несущая опора (load-bearing core) · **С** — самоописание / суверенность · **П** — предохранитель /
конституция · **В** — время / версии · **Р** — рёбра / граф · **М** — метаболизм / память ·
**З** — согласие / доступ.
