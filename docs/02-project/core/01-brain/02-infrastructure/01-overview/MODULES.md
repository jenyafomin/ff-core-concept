# 🧩 РЕЕСТР МОДУЛЕЙ (нумерованный) — seed под углубление

> «То, что уже определили и пронумеровали — в отдельный модуль-реестр; остальное = идеи (уже есть в
> `../values/*`, `../infrastructure/`).» Здесь — SEED-список. В след. сессии каждый модуль продумываем ОТДЕЛЬНО:
> `назначение · какие node-type/edge-type · какую память требует · кросс-связи · global/project · сейчас/позже`.

## 🌐 Глобальные (все проекты)
| # | Модуль | Назначение | Память (что требует) |
|---|---|---|---|
| M-G1 | **Движок памяти** | граф-субстрат: узлы/рёбра/типы/паспорт, распространение, дедуп/циклы | узлы+рёбра+реестры типов |
| M-G2 | **Оркестратор/диспетчер** | Personality→Slot→Session, control-plane, журнал-шина | подграф оркестрации |
| M-G3 | **Реестр типов + policy-as-data** | `node-type`/`edge-type`/`view-def` как данные, 3 plugin-порта | реестры-узлы |
| M-G4 | **Локальность/резиденция** | `DataResidency`, материализация live/cache/copy, scope≠storageLevel | паспорт-колонки |
| M-G5 | **Идентичность/самость** | `canonicalId`, узел-профиль, каскад политик | корневой профиль |
