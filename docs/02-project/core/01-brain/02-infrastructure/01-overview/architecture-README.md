# 🏛️ АРХИТЕКТУРА системы — ЦЕЛЬ и НАПРАВЛЕНИЕ (одно место, переносимое)

> Одна папка для **глобальной архитектуры** (система + модули). Переносима: та же модель годна для FF-brain
> и для agents-manager — держим в одном месте, потом «переносим».

## 🎯 ЦЕЛЬ (север — к чему идём)
**Готовый, гибкий продукт-память**, который:
1. соответствует **всем 7 ценностям**;
2. стоит на **ОДНОМ графе-субстрате БД** (узлы+рёбра+реестры типов, поведение-данными);
3. позволяет строить **НА ЛЕТУ** схемы, индексы и **глубокие view** (без миграций);
4. собран из **МОДУЛЕЙ** (общих и проектных), каждый продуман отдельно и переиспользуем (plug-in).

## 🧩 Недостающая абстракция — МОДУЛЬ (называем явно)
Между «БД-субстрат» и «продукт» лежит слой **МОДУЛЬ**: единица системы = набор `node-type`/`edge-type` +
policy-as-data + поведение, живущее В БД. Система = **композиция модулей**; часть **глобальны** (все проекты),
часть **проектные**; модули **кросс-связываются через БД** (единый connect связей и знаний). Это и есть та
явная абстракция, которую мы опускали. Реестр — в `MODULES.md`.

## 🔀 НАПРАВЛЕНИЕ следующей сессии
Свести **два направления** в реестр ГОТОВЫХ механизмов:
- **от ДАННЫХ** (домены: как хранится) → какие модули ложатся;
- **от МОДУЛЕЙ** (что за модуль) → какая память ему нужна.
Каждый модуль продумать **отдельно**; отметить **global vs project**; описать **кросс-связи**. Результат —
архитектура, готовая стать **ADR** и быть перенесённой (FF ↔ agents-manager).

## ✅ Что у нас ЕСТЬ (опора, готово)
Базис узел/связь (2 класса) · канон FQ1–24 решён в рамке «ОБА» · **БД = единый граф-субстрат** ·
домены заведены (`../domains/`).

## 🎯 Что нам НУЖНО (результат след. сессии)
1. Абстракция **МОДУЛЬ** принята как слой системы.
2. **Реестр модулей** (нумерованный): global / project, для каждого — какую память требует + кросс-связи (`MODULES.md`).
3. Что **глобально** (все проекты), что **под проект** — правилом или движком.
4. **Глубокий view** и «схемы/индексы на лету» — как механика над субстратом.
5. → кандидат в **ADR «Единый граф-субстрат + модульная архитектура»**.
