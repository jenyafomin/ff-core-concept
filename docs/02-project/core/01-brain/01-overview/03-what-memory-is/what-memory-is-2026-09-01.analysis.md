# Что наша память есть

## Блок 1 — Что память ЕСТЬ сегодня
*(заземлено, по коду + 30 актам)*

- **Движок живой, 148 тестов зелёные.** Модель истины:
  `лог = система-записи, граф = детерминированная проекция` (ADR-0008 approved).
- **Единый путь записи + gate против inline-PII исполняются в коде;** инвариант
  `owner=one / referent=many` заперт в ядре (подтверждён exploit-тестом).
- **На диске 30 актов:** 13 day-graph + 17 census (реальная перепись владельца) —
  реальные узлы графа, не фикстуры.
- **Слабое место — честно:** enforcement доступа / согласия / стирания = **ФОРМА,
  не машина** (V7 не подключён). Salience / затухание — пустой слот.
- **Ключевое снятие путаницы:** канон НЕ говорит «файлы = истина». Файл =
  физическое **РАЗМЕЩЕНИЕ** (ADR-0006). Поэтому «память первостепенна, проект
  показывает» = верное описание УЖЕ существующей модели: память = лог + граф
  (первична); проект = проекция + размещение.
- **Открытая односторонняя дверь (кандидат в ADR):**
  - **(A)** это переименование / признание существующего субстрата; ИЛИ
  - **(B)** новый верхний слой «GitHub-над-всем» = scope-creep.

## Блок 2 — Продуктовая аспирация
*(DRAFT, НЕ реальность — тянет за триггер / γ)*

- **Тезис** (уже ратифицирован ограниченно в ADR-0014): память держит
  состояние / топологию паттерна как **ДАННЫЕ**, не как живой движок. Мы =
  удобный **АГРЕГАТОР** чтения и контролируемой записи над разными источниками.
- **Что продаём:** единый **СЛОЙ ПАМЯТИ** над агентными системами; единица
  **ПЕРЕНОСИМА** (несёт policy + схему); «GitHub для памяти».
- **Помечено как аспирация / заморожено-γ:** многоарендность, политики доступа,
  агентские плагины, интеграции (GitHub / API), маркетплейс, приложения-внутри-
  памяти, шеринг. **Enforcement = 0.** Владелец, CLAUDE.md: «маркетплейс — позже».
