# 🧠 03-what-memory-is — «что наша память есть»

> Узел-описание: чем является память проекта. Держит ДВА чётко разделённых
> вещества — **реальность сегодня** и **продуктовую аспирацию** — и не смешивает их.

## Что внутри
- **`what-memory-is-2026-09-01.analysis.md`** — описание в двух блоках:
  - **Блок 1** — что память ЕСТЬ сегодня (заземлено на код + 30 актов, 148 тестов).
  - **Блок 2** — продуктовая аспирация (DRAFT, γ-заморожено, enforcement = 0).
- **`owner-vision-branching-2026-09-06.idea.md`** — сырое видение владельца (8 пунктов): память-первична как
  слой знаний с ветвлением/версиями/доступом по чатам-топикам-проектам, инструмент merge глубже git, разные
  паттерны данных.
- **`what-memory-is.concept.json`** — визард-МЕНЮ развилок: F1 = сама дверь A/B; F2-F6 = downstream-развилки
  видения, каждая с указателем в СВОЙ существующий дом (ветвление·паттерны·доступ·суверенность·связи). Fan-out,
  не дубль-дом.

## Почему отдельный узел
Снятие ключевой путаницы «файлы=истина» и заземление тезиса «память первостепенна,
проект показывает». Узел — потенциальная точка входа в одностороннюю дверь (кандидат
в ADR: признание существующего субстрата (A) vs новый верхний слой (B)).
