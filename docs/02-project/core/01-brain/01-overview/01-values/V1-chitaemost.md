# Ц-1 · Читаемость (Legibility)

> Родитель: [../INDEX.md](../INDEX.md) · Слой L1→L2 · draft

**Определение.** Единица отдаёт нужную грань нужному читателю по нужной цене, не вскрываясь целиком. Поглощает Прозрачность (частный случай: грань = «стоит ли брать») + Полисемию (общий случай: граней много) + температуру (cold = «читается только по запросу, не всплывает»).

**Несёт цели:** Г1 (оценить не вскрывая) · Г3 (сводка под бюджет) · Г4 (читаться человеком) · Г6 (любой зум) · Г13-режим (live/cold) · Г21 (записана по-разному) · Г23 (гибкость) · Г35 (фрактальная сборка) · Г37 (самосознание стоимости).

**Куда копать (L2 идеи):** progressive disclosure · иерархии саммари · эмбеддинги для дешёвого матча · JSON-LD `@context` · CQRS-проекции. Двойное попадание с Суверенностью (self-describing).

**Открытые вопросы / идеи:**
- FQ1: слить Прозрачность+Полисемию — да, но держать как две ГРАНИ внутри (дешёвое-одно-чтение ⟂ много-чтений).
- Механика «волны»/линзы всё ещё метафора — главный непокрытый кусок (см. Opus: герменевтическая линза).

**Затрагивающие сценарии:** смена ТИПА ячейки (Sonnet-2) · «что ЗНАЧИТ сейчас» (Opus-линза В).
**Соседние ценности:** Суверенность (self-describing), Тождество (проекции одной памяти).
