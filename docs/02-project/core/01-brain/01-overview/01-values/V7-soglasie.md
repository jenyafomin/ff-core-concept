# Ц-7 · СОГЛАСИЕ (Consent)

> Статус: draft · Родитель: [../INDEX.md](../INDEX.md) · Содержит слепой угол Г20

**Определение.** Единица знает, *кому* показать и *ЧЬЯ* она. Единственная ось «за/для кого память».

**Несёт цели:** Г18 (уметь скрыть себя) · **Г20 (референт — третье лицо)** · Г24/Г31 (роли, «свой мир», capability-шеринг) · Г38 (значимость для человека — Fable: свойство ребра).

**Идеи / куда копать (L2):** ABAC/линза-политика · row/field-level security · capability-based access · tenant-изоляция · **грань `referent` ≠ owner ≠ author** (заложить сейчас) · **hard-erase** (право на забвение, заложить сейчас) · consent-taint (наследуемая лицензия согласия, Opus #4) · custodial-override (акт сокрытия = аудируемая ячейка, Opus #5) · 4-я роль `successor/steward` (bus factor).

**Открытые вопросы:** FQ7 (референт + hard-erase СЕЙЧАС — конфликт с bitemporal «забыть≠удалить») · FQ8 (Г38 — ось узла или ребра?) · юрисдикция GDPR/152-ФЗ (DB-control/позже).

**Сценарии:** три свидетеля (совладение, Opus #1) · данные под одним согласием для другого (Opus #4) · милосердная ложь владельцу (Opus #5) · групповая/семейная память (Sonnet #4).

**Связи:** ⚠️ ограничивает Суверенность (референт над владельцем) · ↔ Доверие(авторизация) · КОНСТИТУЦИЯ (согласие референта нельзя переопределить политикой ячейки).
