# Направление 04 — Наследуемость согласия (consent-taint)

- **Status:** draft — дивергенция · **Owner:** JenyaFomin · **Date:** 2026-07-09
- **Related:** `../README.md` (ценность Ц-7) · `../V7-soglasie/ideas/IDEA-consent-taint` (исходная карта) ·
  тема B (авто-индекс / домен-как-волна) · Ц-1 Читаемость (линза-проекция) · Ц-6 Реляционность (provenance
  по рёбрам) · 07.C Конституция (арбитраж конфликта) · 07.S предвычисление

## Суть

Когда ячейка B выведена/агрегирована из ячейки(ек) A с ограниченным согласием, движок обязан **протянуть
на B самое строгое ограничение исходников автоматически** — а не по умолчанию открыть доступ. Тот же
механизм на **линзах/авто-индексах** (тема B): агрегированная «волна» не может обойти согласие референта
только потому, что формально это «просто индекс». Объект защиты — **распространение ограничения по графу
вывода**: чтобы агрегат не стал дырой в согласии.

## Границы

- **Входит:** taint при выводе/агрегации новой ячейки; тот же taint на уровне линзы/авто-индекса (фильтр
  ДО коллапса волны в грань); правило слияния (strongest-wins); глубина каскада по provenance.
- **НЕ входит:** сама политика исходника (→ 02 visibility / 03 use); отзыв, который должен каскадировать
  назад по потомкам (→ 05, но прямое пересечение); арбитраж невзаимосводимых политик (делегируется 07.C).
- **Тонкая граница с Ц-1 / темой B:** линза, проецирующая домен/авто-индекс, обязана фильтровать ПО
  согласию **до** того, как волна коллапсирует в грань, — иначе «просветит» через согласие референта.

## Развилки (веер «как», не режем)

1. **Правило слияния.** Strongest-wins (самое строгое ограничение побеждает) [+ безопасно, простое правило /
   − может «переужесточить» агрегат до бесполезности] vs явный арбитраж Конституцией [+ гибко / − нужен
   арбитр] vs отказ агрегировать при конфликте [+ честно / − ломает авто-индекс].
2. **Конфликт невзаимосводимых политик** (не разной строгости, а взаимоисключающих). Конституция-арбитр
   (→ 07.C) vs refuse-to-merge [+ безопасно / − теряем агрегат] vs пометить агрегат «спорное согласие,
   не действовать» [+ сохраняет данные / − новый статус].
3. **Где живёт taint.** Денормализован на ячейке-потомке [+ дёшево читать / − надо пересчитывать при
   отзыве] vs вычисляется линзой на лету [+ всегда свежий / − дорого] vs предвычислен (→ 07.S).
4. **Глубина каскада.** Только прямые родители [+ дёшево / − внук обходит ограничение деда] vs транзитивно
   вся цепочка `wasDerivedFrom` [+ полно, честно / − дорогой обход, нужен 07.S].
