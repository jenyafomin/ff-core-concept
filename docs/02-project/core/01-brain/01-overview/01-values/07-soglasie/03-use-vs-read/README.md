# Направление 03 — Право действовать ≠ право читать

- **Status:** draft — дивергенция · **Owner:** JenyaFomin · **Date:** 2026-07-09
- **Related:** `../README.md` (ценность Ц-7) · `../V7-soglasie/ideas/IDEA-use-vs-read-consent` (исходная
  карта) · Ц-1 Читаемость (метка, не стена) · Ц-3 Доверие (авторизация) · клапан доверия из канон-брифа
  (внешние необратимые действия) · Г38 (значимость на ребре)

## Суть

Отделить **чтение** (агент *знает* факт) от **использования** (агент вправе *ДЕЙСТВОВАТЬ* на основании —
позвонить, написать, потратить, инициировать). ИИ видит всё (Ц-1: эпистемический статус — метка, не
стена), но **use-consent** — узкое, осознанное исключение: агент может знать «Аня просила не звонить ей
вечером» и не иметь права инициировать звонок, скрыв это. Объект защиты — **авторитет действия**,
отдельный от авторитета чтения.

## Границы

- **Входит:** клапан «читать vs действовать»; уровень клапана (ячейка / класс действий / роль); дефолт;
  связка со значимостью Г38.
- **НЕ входит:** сам показ/видимость (→ 02); необратимость самого действия и деструктив (это модуль
  Безопасности агентов, другой проект); отзыв согласия (→ 05).
- **Тонкая граница с Ц-1:** это намеренная стена для ДЕЙСТВИЯ ИИ, не для ЧТЕНИЯ ИИ. Единственное узкое
  исключение из «ИИ не ограничен в видении» — не отмена принципа, а его аккуратная граница.

## Развилки (веер «как», не режем)

1. **Уровень клапана.** На каждой ячейке (`use-consent` поле) [+ точечно / − шум на 99% ячеек, где он не
   нужен] vs на классе действий (агент не звонит/не тратит без явного разрешения — общее правило)
   [+ чисто, мало правил / − грубо, не учитывает конкретную запись] vs гибрид: класс по умолчанию +
   ячейка-исключение [+ и то и то / − две системы правил].
2. **Дефолт.** Читать можно, действовать нельзя без явного use-consent [+ безопасно / − трение на каждое
   действие] vs действовать можно, кроме явно помеченного [+ гладко / − риск утечки действия].
3. **Где живёт правило.** Паспорт ячейки (`policy-as-data`) vs политика агента/роли vs Конституция (класс
   необратимых ВНЕШНИХ действий — тот самый «клапан доверия» канона: наружу и необратимо → всегда спросить).
4. **Связка с Г38 (значимость).** Влияет ли важность-на-ребре человек→единица на use? (важное для человека
   → требует явного подтверждения перед действием) [+ семантично / − смешивает значимость и согласие] —
   **открыто**, зависит от FQ8.
