# Q-ERA-01r — Парадокс свидетеля (низкоэнтропийный PII)

> Узел-вопрос с потенциалом роста. Обсуждение и советы — ВНУТРИ этой папки. Может дорасти до ADR.

## Суть (одной строкой)
Для **низкоэнтропийного** PII (телефон, email) `payloadHash` (`hash.ts:9`) одновременно —
**свидетель целостности** (Ц-3 Доверие: должен персистить, чтобы доказать, что данные не подменены)
и **оракул-подтверждения** (Ц-7 Согласие: должен исчезнуть, иначе по хешу перебором восстановят
стёртое). **Шва нет — резать нечего.** Это единственное настоящее столкновение ценностей из всей волны.

## Почему это НЕ распускается предикатом
Общий парадокс свидетеля уже распущен по энтропии (T3): высокоэнтропийный payload — хеш безопасен,
хранить. Но для НИЗКОэнтропийной ветки предиката больше нет — остаётся голый ценностный размен.

## Варианты (веер, не режем)
- **(a) Admission-refuse СЕЙЧАС** [пред-склонённый дефолт]: реальный низкоэнтропийный PII в субстрат
  не впускать вообще (R1-забор на входе — первый жилец плоскости). + честно, дёшево / − сужает, что
  субстрат может хранить о человеке.
- **(b) Соль/HMAC keyed-shred, зарезервировать в Стадии-2**: свидетель делаем стираемым (ключ уничтожается
  → хеш перестаёт быть оракулом). + сохраняет и целостность, и стирание / − нужен key-store СЕЙЧАС как
  ретрофит-невозможный шов (см. Q-ERA-07), сложнее.
- **(c) Принять письменный остаточный риск**: хранить как есть, задекларировать риск. + ничего не строим /
  − «канон лжёт» — зелёное переобещает; нарушает правило честности.

## Что бы это решило
Ценностный вердикт владельца о ранге (Доверие vs Согласие в этой точке), ИЛИ технический шов, делающий
свидетеля стираемым без потери целостности (это и есть (b)).

## Известные зацепки (за что цепляется)
- **Admission-gate / R1-забор** (Q-ERA-09) — вариант (a) = это и есть первый жилец.
- **Тайминг key-store** (Q-ERA-07) — вариант (b) требует его сейчас.
- **ADR-0007 R-G3.4** (schema admission-gate) — родственная территория.

## Вердикт Fable (2026-08-06) — РЕШЕНО, ждёт ратификации владельцем
**Трихотомия неполна. Ход (d): пер-актовая соль ВНУТРИ erasable-зоны** — `sha256(соль‖payload)`,
соль лежит в самом blob и умирает тем же shred'ом → **key-store не нужен вовсе, Q-ERA-07 расцепляется**.
Ядро: для низкоэнтропийного содержимого пост-erasure верифицируемость и оракул — ОДНА способность,
не две сцепленные; резать не между чем. **Ц-7 берёт ровно один атом** (пост-erasure подтверждаемость
содержимого); Доверию остаётся всё прочее (провенанс, монумент, tamper-evidence ДО стирания). Вариант
(b) стоял на ложной посылке (key-store), (c) конституционно запрещён. Шов солёного свидетеля
**ретрофит-невозможен** → спека ДО первого прод-payload; `hash.ts:9` («safe») — переписать.
→ `fable-witness-paradox.advisory.md`.

**Наименьшее первое решение (ратификация владельца):** одно предложение — «Ц-7 берёт атом
пост-erasure подтверждаемости содержимого; конструкция свидетеля = политика впуска: erasable →
солёный-в-blob или отказ». Из него механически следуют предикат Q-ERA-09, спека шва, расцепление Q-ERA-07.

## Статус
**РЕШЕНО Fable → ждёт ратификации владельцем** (одно предложение выше).
