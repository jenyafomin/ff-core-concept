# Q-ERA-03 — Забвение и факт-монумент

> Узел-вопрос с потенциалом роста. Обсуждение — ВНУТРИ. Юридического ранга → вероятный ADR.

## Суть
Шов делит payload на **содержимое** (→ несуществует) и **факт существования** (tombstone-монумент:
«здесь было, стёрто по требованию» — id цел, рёбра целы). Право на забвение точно дотягивается до
содержимого. **Дотягивается ли оно до самого факта-монумента?**

## Природа: дефолт вынужден ценностями, но верх — юридический
- **Дефолт (No): только содержимое.** Монумент персистит — этого требуют Ц-3 Доверие (аудит),
  Ц-6 Реляционность (нет висячих рёбер), Ц-2 Тождество.
- **Регим-B (Yes): факт тоже нельзя.** Некоторые правовые режимы могут требовать, чтобы и следа не
  осталось. **Структурно это решается ТОЛЬКО admission-gate на входе (не пропускать факт) — никогда
  post-hoc**, т.к. append-only лог факт уже зафиксировал.

## Что бы это решило
Владелец/юр-ранг: подтвердить дефолт «только содержимое», ИЛИ назвать режим-B и тогда — какие классы
референтов/фактов вообще не впускать (admission-gate).

## Зацепки
- **Г20** (Q-ERA-16) — третья сторона: если у неё право на сам факт, это регим-B.
- **Admission-gate** — единственный механизм для регим-B.
- **ADR-0007 OQ-3** (metadata-residue) — родственная территория, дом в ADR-0007.

## Вердикт Fable (2026-08-06) — РЕШЕНО (рамка сломана), ждёт ратификации + юр-развилки
**«Содержимое vs стереть-факт» — ложная ось. Правило: забвение достаёт ВСЁ ИДЕНТИФИЦИРУЮЩЕЕ — включая
ВНУТРИ монумента — и ничего неидентифицирующего. Шов РЕКУРСИВЕН: выход стирания сам обязан пройти шов.**
«Стёрто по требованию R» — свежий PII о R → монумент должен быть само-анонимизирующимся: структурный
факт остаётся («здесь была санкционированная стирка, цепь целостности цела»), а атрибуция заявителя и
идентифицирующая тип-мета — стираемое содержимое. Ц-3/Ц-6/Ц-2 нужен факт санкции, не имя заявителя
навсегда. Неснимаемый остаток — **топология рёбер** (анонимный tombstone, привязанный к кластеру Маши,
= tombstone про Машу) → дом ADR-0007 OQ-3, не дублируем. Регим-B post-hoc невозможен.
→ `fable-monument-reach.advisory.md`.

**Наименьшее первое решение:** ратифицировать «шов рекурсивен; монумент = только неидентифицирующий
структурный факт» (раздел ADR-0007, не новый ADR). Q-ERA-16 (Г20) наполовину растворяется.
**Только владелец (юр-ранг):** порог анонимности для топологии · существуют ли классы референтов регим-B ·
подпись под письменным остаточным риском.

## Статус
**РЕШЕНО Fable → ждёт ратификации + 3 юр-развилки владельцу.**
