# Ц-4 · ВИТАЛЬНОСТЬ (Metabolism)

> Статус: draft · Родитель: [../INDEX.md](../INDEX.md)

**Определение.** Единица *становится* другой во времени, не теряя Тождества: метаболизирует (консолидация/забывание), не раздувается. Память — глагол.

**Несёт цели:** Г12 (менять не теряя) · Г15 (бюджет внимания — инвариант) · salience · забывание · эмердженс (Г35-родня).

**Идеи / куда копать (L2):** salience-модель (Generative Agents × W-TinyLFU: recency+importance+use_freq с затуханием) · батч-консолидация «reflection» · bitemporal-версии · lifecycle-tiering · **эмердженс** (рождение смысла > сжатие, Fable). Бюджет salience принадлежит БАЗЕ, не ячейке (DB-control).

**Открытые вопросы:** FQ5 (эмердженс как полноценная фаза?) · FQ6 (`pending`/открытые петли — отдельная ось?) · кто крутит фазу C (садовники-агенты) · новый глагол «Переосмыслить» (Opus #3).
