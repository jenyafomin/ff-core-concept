# 🌱 GROWTH-MAP — ветка ценностей

> Как углубляется ветвь ценностей: от карточки-ценности к её декомпозиции по фасетам,
> с узлом-вопросом на каждую ценность. Карта роста, а не хранилище контента.

## 7 замкнутых ценностей
`V1 Читаемость · V2 Тождество · V3 Доверие · V4 Витальность · V5 Суверенность · V6 Реляционность · V7 Согласие`

Каждая ценность имеет две проекции в этой ветке:
- **Карточка-источник** — `V1-chitaemost.md … V7-soglasie.md` (короткая суть ценности).
- **Папка-декомпозиция** — `01-chitaemost/ … 07-soglasie/` (разбор ценности на аспекты:
  паспорт, линзы, аспекты — внутри `NN-*/README.md`).

Сводная выжимка всех карточек — `_CARDS-2026-07-08.md`.

## Как ценность углубляется (фасет-слоты)
Внутри папки-декомпозиции ценность растёт по нумерованным фасет-слотам (общий скелет ветвей brain):

`01-explain · 02-entities · 03-relations · 04-mechanics · 05-policy · 06-nuances`

плюс общие бакеты: `decisions/` (без номера), underscore-бакеты `_cross-cutting/ _archived/ _unverified/`.

> Текущее состояние папок (`NN-*/`) — предшествует этой нумерации (паспорт/линзы/аспекты).
> Приведение к единым фасет-слотам — следующий шаг углубления, по мере работы над ценностью.

## Узел-вопрос на ценность
Открытые вопросы по каждой ценности пока живут внутри её папки-декомпозиции
(`questions.md` в архивных gen1-папках, `IDEAS-CYCLE*.md`, README-разборы).
Отдельная папка `questions/` в этой ветке **не заведена** — заводить, только когда появится
сквозной набор вопросов уровня всей ветки (не привязанный к одной ценности).

## Бакеты этой ветки
- **`_cross-cutting/`** — сквозное по всем ценностям (бывш. `_wide/`: общий README + ideas).
- **`_archived/gen1/`** — первое поколение разбора ценностей (`V1-chitaemost/ … V7-soglasie/`
  с `ideas/`, `questions.md`, `competitors.md`). Сохранено целиком (LOSE-NOTHING), не активно.
