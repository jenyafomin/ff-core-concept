# Направление 02 — Полисемия и линза (волна → грань)

- **Status:** draft — дивергенция · **Owner:** JenyaFomin · **Date:** 2026-07-09
- **Related:** `../README.md` (ценность 01-chitaemost), П2+П4 в
  `../../V1-chitaemost/questions.md` (Q2), идея `IDEA-lens-as-memory-unit` в
  `../../V1-chitaemost/ideas/`, метафора «волна/частица» в `../../../L0-memory-unit.md`

## Суть

Одна и та же единица памяти — не один застывший вид, а **несколько валидных ответов** в
зависимости от того, КТО спрашивает и ЗАЧЕМ: агенту-таск-раннеру нужно одно, архивариусу при
консолидации — другое, владельцу в UI — третье. Линза — механизм, который коллапсирует эту
«волну» потенциальных граней в конкретную проекцию под конкретный вопрос. Закрывает П2
(полисемия) и П4 (линза/точка зрения) как одну пару: много-чтений + то, что выбирает ОДНО
из них здесь и сейчас.

## Границы

- **Входит:** множественность проекций одной единицы; линза как явный механизм выбора грани
  (вычисляемая функция vs сохраняемая единица); домен/индекс как результат применения линзы
  поверх дерева, а не статичное поле (тема B из L0); граница «одна вещь — много граней» vs
  «уже две разные вещи» (шов с Тождеством Ц2).
- **НЕ входит:** сама механика прогрессивного раскрытия по цене внутри уже выбранной грани
  (→ 03 progressive-disclosure — прогрессия работает ВНУТРИ грани, которую уже отдала линза);
  видимость самого ФАКТА существования единицы кому-либо (→ Ц7 Согласие — «видна ли грань» и
  «видно ли, что единица вообще есть» — разные вопросы, паспорт фильтруется линзой ДО того,
  как считается «дешёвым», см. открытое напряжение в `../../V1-chitaemost.md`).
- **Тонкая граница с 06 (fractal-stability):** 06 — читаемость на РАЗНОМ ЗУМЕ (атом/группа/
  граф) одним правилом; 02 — читаемость под РАЗНЫМ УГЛОМ (кто спрашивает) на ОДНОМ зуме.
  Оси ортогональны, но легко спутать — обе про «разные виды одной вещи».

## Развилки (веер «как», не режем)

1. **Природа линзы.** Вычисляемая функция без состояния, живёт только в момент запроса
   [+ нет лишней сущности / − нельзя переиспользовать точку зрения, каждый агент изобретает
   заново] vs линза = сохраняемая единица памяти со своим паспортом (idea lens-as-memory-unit)
   [+ переиспользуемость, «агент применил линзу вчера — другой берёт сегодня» / − линза сама
   требует читаемости, рекурсия] vs линза = именованный пресет из фиксированного enum ролей
   (task-agent/archivist/owner) [+ простой средний путь / − негибко под новые роли читателей].
2. **Где материализуется проекция.** На чтении, query-time (CQRS-проекция строится по
   запросу заново) [+ всегда свежо / − дороже на каждый запрос] vs предвычислена на запись
   под известные линзы (materialized view per lens) [+ дёшево читать / − нужно знать линзы
   заранее, негибко под новые] vs гибрид: частые линзы материализуются, редкие — на лету.
3. **Домен-как-волна (тема B).** Домен — статичное поле на узле (`domain: health`)
   [+ просто, дёшево читать / − жёстко зашито, не подстраивается под новый контекст] vs
   домен выводится линзой на лету из сырых сигналов узла [+ честно к многомерности,
   соответствует «зерно = свойство взгляда» из L0 / − каждый обзор графа требует
   вычисления, дороже читать].
4. **Граница «одна вещь vs две вещи» (шов с Ц2 Тождество).** Формальный порог: общий
   `canonical_id` ⇒ всегда одна вещь, неважно как расходятся грани [+ просто, механически
   проверяемо / − может маскировать реальный сплит, который стоило бы явно развести] vs
   агент-судья решает «разошлось ли слишком далеко» эвристически [+ чувствительнее к
   реальности / − субъективно, кто и как калибрует «слишком далеко»].
5. **Открытый список линз vs фиксированный.** Фиксированный enum ролей-читателей
   [+ предсказуемо, легко валидировать / − новая роль требует правки схемы] vs открытый
   список, каждая линза сама объявляет себя новым паспортом [+ расширяемо без правки ядра /
   − нет гарантии консистентности формата между разными линзами].

## Пул идей

| Идея | Индекс | Задевает ещё | Метка |
|---|---|---|---|
| Линза как единица памяти (переиспользуемая точка зрения) | P2 · M · высок | Ц5 суверенность (self-describing, рекурсия паспорта) | **→ infra** (из `IDEA-lens-as-memory-unit`) |
| Домен-как-волна: вывод на лету из сырых сигналов, не статичное поле | P1 · M · сред | — | новое (тема B) |
| CQRS-проекции по линзам (материализация под известные роли-читатели) | P2 · M · высок | — | заложить сейчас (архитектурный кандидат) |
| Эмбеддинги для дешёвого матча «вопрос ↔ грань» без явного enum линз | P1 · M · высок | Ц5 суверенность (грань находит себя сама, без внешней схемы ролей) | **→ infra** |
| Явный порог/агент-судья для границы «одна вещь / уже две» | P3 · M · сред | Ц2 тождество | **→ infra** |

> Теги: Ц2 (тождество — граница сплита), Ц5 (суверенность — self-describing линза и
> самонаходящаяся грань), Ц7 (согласие — фильтр видимости ДО дешевизны, см. напряжение в
> value README).
