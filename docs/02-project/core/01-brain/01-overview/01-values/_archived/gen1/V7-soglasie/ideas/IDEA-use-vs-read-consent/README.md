# IDEA · Use-consent отдельно от read-consent

**Суть:** видимость (можно ли прочитать/показать) и право действовать на основании (можно ли
агенту инициировать действие) — два разных клапана. ИИ видит всё (Ц1 Читаемость — статус как
метка, не стена), но use-consent — узкое, осознанное исключение: агент может знать факт и не
иметь права действовать на нём без явного разрешения.

**К какой под-грани:** #4 Согласие на использование (use-consent).

**Открытые вопросы:** нужен ли этот клапан на уровне каждой ячейки или достаточно правила на
уровне класса действий (Q-use-vs-read в ../../questions.md)?
