# IDEA — Ценник на паспорте (price_hint как обязательное поле)

**Суть.** Каждый паспорт несёт `price_hint`: грубую оценку стоимости чтения на каждом уровне
раскрытия (label/summary/payload) — не точные токены, а категория S/M/L/XL. Агент видит цену
ДО чтения и может бюджетировать сводку под лимит контекста без пробного чтения.

**Относится к под-грани:** П6 (самоописание цены), связано с П3 (progressive disclosure).

**Открытые вопросы:** точность оценки vs стоимость вычисления (см. Q3 в questions.md); кто
обновляет price_hint при росте payload — сама ячейка при записи или движок фоново.
