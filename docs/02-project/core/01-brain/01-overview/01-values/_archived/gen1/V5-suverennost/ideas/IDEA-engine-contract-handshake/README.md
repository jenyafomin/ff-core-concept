# IDEA — Engine-contract handshake при переносе

При переносе/импорте ячейки в новый движок происходит явное рукопожатие: ячейка предъявляет
`engine-contract-version` (набор примитивов, которые ей нужны), движок отвечает, какие из них умеет.
Несовпадение — не молчаливый сбой, а явный статус ячейки («частично функциональна», «требует
адаптер»), видимый владельцу.

**Относится к под-грани:** п.3 (engine-contract-version), п.4 (портируемость).

**Открытые вопросы:** кто пишет адаптер при несовпадении контрактов — движок, посредник-агент, или
владелец вручную? Деградирует ли ячейка частично (часть политики отключена) или блокируется целиком?
