# IDEA: Выведенные рёбра (derived edges) отдельно от заявленных

Домен-как-волна (тема B) реализуется как отдельный класс рёбер: `derived: true`, паспорт-автор =
алгоритм/движок, а не человек/агент. Явно заявленное ребро («A caused B», кто-то это утверждал) и
выведенное ребро («A и B оба часто встречаются рядом с меткой "проект X"», посчитал индексатор) —
структурно разные объекты, чтобы выведенная связь не выдавала себя за подтверждённое утверждение.

**Относится к грани:** 2 (Типизация связи) · тема B (авто-индекс/домен-как-волна).

**Открытые вопросы:**
- Один тип сущности с флагом `derived`, или структурно разные объекты? (см. RQ4)
- Может ли выведенное ребро «повыситься» до заявленного, если человек его подтвердил?
