# IDEA — Fast-lane / slow-lane для суверенности на масштабе

Тема C (масштаб-как-изюминка): большинство ячеек используют системный default-policy — они идут по
быстрому batch-пути обработки (одна общая интерпретация на миллионы записей). Ячейки с кастомной,
переопределённой политикой — редкое меньшинство — идут по медленному индивидуальному пути. Суверенность
не платит налог за всех, только за тех, кто ей реально пользуется.

**Относится к под-грани:** п.2 (policy-as-data), тема C (масштаб).

**Открытые вопросы:** как движок быстро отличает «стандартную» ячейку от «кастомной» без разбора
каждой (нужен ли отдельный дешёвый флаг `has_custom_policy: bool` в паспорте, читаемый без разворота
policy-блока)? Насколько часто в реальности владельцы будут кастомизировать политику — если часто,
идея не спасает масштаб.
