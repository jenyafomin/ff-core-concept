# IDEA: Конфликт рёбер = узел-инцидент, видимый третьей стороне

Когда два ребра утверждают несовместимое (или образуется нежелательный цикл), движок не блокирует
запись и не молчит — он создаёт узел-инцидент, который ссылается на оба конфликтующих ребра и
ждёт разрешения человеком/агентом-арбитром. Конфликт становится частью графа, а не логом ошибок в
сторону.

**Относится к грани:** 8 (Конфликт и цикл — видимы, не запрещены).
