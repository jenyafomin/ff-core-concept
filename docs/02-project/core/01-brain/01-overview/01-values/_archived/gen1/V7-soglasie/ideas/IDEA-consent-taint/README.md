# IDEA · Consent-taint — наследуемое ограничение при агрегации

**Суть:** когда ячейка B выводится/агрегируется из ячейки(ек) A с ограниченным use-consent, движок
обязан протянуть на B самое строгое ограничение исходников автоматически, а не по умолчанию
открывать доступ. Тот же механизм применяется к линзам/авто-индексам (тема B): агрегированная
«волна» не может обойти согласие референта только потому, что формально это «просто индекс».

**К какой под-грани:** #5 Наследуемость согласия (consent-taint).

**Открытые вопросы:** что делать при конфликте (не просто разной строгости, а взаимоисключающих)
политик нескольких исходников — арбитр Конституция или отказ агрегировать вовсе (Q-taint-strength)?
