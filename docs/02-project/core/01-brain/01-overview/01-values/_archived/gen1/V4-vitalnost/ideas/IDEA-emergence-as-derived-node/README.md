# IDEA · Эмердженс = узел-инсайт с явным derived_from

Садовник-агент, находя сгущение связанных активных единиц, рождает НОВУЮ единицу-инсайт со
ссылкой `derived_from: [id...]` на источники. Источники не переписываются и не удаляются — инсайт
живёт рядом как прирост, а не сжатие. Это первоклассный тип узла, не подмножество паспорта.

**Относится к под-грани:** 3 (консолидация), 5 (эмердженс).

**Открытые вопросы:** нужна ли отдельная шкала доверия для derived-узлов (VQ4); как эмердженс
соотносится с автоиндексом/доменом-как-волной (тема B, VQ1) — один механизм или два.
