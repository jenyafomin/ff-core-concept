# IDEA — Линза обязана уважать policy-блок при авто-индексации

Тема B (авто-индекс-как-волна): когда линза автоматически собирает домен/индекс «по запаху», она
обязана перед включением ячейки в волну проверить её `policy`-блок (в частности флаг участия в
авто-агрегации). Иначе автоматика становится боковым каналом, обходящим суверенность ячейки —
ячейка «видна» через индекс, даже если её политика запрещает прямой доступ.

**Относится к под-грани:** п.2 (policy-as-data), п.9 (анти-ложь ячейки о себе), тема B.

**Открытые вопросы:** это часть конституционного потолка (п.8, обязательно для всех линз) или
опциональное поведение конкретной линзы? Как проверить на практике, что линза действительно уважает
policy, а не просто заявляет об этом (симметрично проблеме «анти-ложь ячейки о себе», но применённой
к движку/линзе).
