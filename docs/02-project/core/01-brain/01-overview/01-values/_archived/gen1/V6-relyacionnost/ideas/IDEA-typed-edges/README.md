# IDEA: Типизированный набор рёбер с разной физикой каскада

Фиксированный (v1) словарь родов связи — `caused`, `derived-from`, `variant-of`, `template-of`,
`member-of`, `references` — где у каждого типа явно прописано поведение при удалении/забвении
одной из сторон (переживает / падает вместе / ветвится / наследует / распадается / не тянет
обязательств). Типизация — не ярлык для UI, а контракт движка.

**Относится к грани:** 2 (Типизация связи), 4 (Целостность при разрыве).

**Открытые вопросы:**
- Закрытый enum или открытая расширяемая схема типов? (см. RQ2)
- Кто утверждает новый тип ребра — нужен ли на это мини-ADR?
