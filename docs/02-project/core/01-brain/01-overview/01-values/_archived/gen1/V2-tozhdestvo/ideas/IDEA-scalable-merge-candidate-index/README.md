# IDEA — индексация кандидатов на слияние (масштаб с первой итерации)

**Суть.** Граница слияния (кто с кем может быть «одним и тем же») не должна
проверяться полным перебором. С первой итерации закладывается индекс кандидатов
(сигнатура/эмбеддинг/ключевые поля), сужающий пространство поиска дублей с O(n²) до
локального соседства. Это прямой ответ на тему C владельца (масштаб — изюминка,
слабая грань которой ломает продукт целиком).

**К какой под-грани относится:** п.2 Декомпозиции (Граница слияния) + тема C
(масштаб/скорость).

**Открытые вопросы:**
- Индекс кандидатов — часть движка (примитив) или отдельный агент-садовник,
  работающий асинхронно фоном?
- Насколько дорого пересчитывать индекс при каждой новой записи — нужен ли
  батчинг/дебаунс?
