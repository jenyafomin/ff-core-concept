# IDEA — Contagion threshold (порог заражения для авто-индексов)

**Суть:** Когда домены/индексы собираются автоматически "как волна" по дереву связей (тема B), записи с confidence ниже определённого порога НЕ участвуют в автоматической агрегации — не тянут за собой производные узлы. Останавливает распространение ложных данных вверх по дереву emergent-знания раньше, чем оно материализуется в инсайт.

**К какой под-грани относится:** Д4 (Защита от отравления) × тема B (авто-индекс-волна).

**Открытые вопросы:** Порог фиксированный или настраиваемый per-домен? Кто решает исключение записи из волны — движок автоматически или это видимое, объяснимое решение (см. Д8)?
