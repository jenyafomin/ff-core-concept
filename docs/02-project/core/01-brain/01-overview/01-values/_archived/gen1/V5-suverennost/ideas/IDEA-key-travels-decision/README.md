# IDEA — Решить развилку «ключ дома vs с ячейкой» через явный флаг

Не выбирать один ответ на всю систему — дать самой политике ячейки решать (`key_mode: portable |
anchored`), с дефолтом `anchored` (безопаснее по умолчанию, ключ остаётся дома). `portable` — явный
осознанный выбор владельца при создании/переносе, когда самодостаточность важнее контроля источника.

**Относится к под-грани:** п.6 (ключ дома vs с ячейкой).

**Открытые вопросы:** если ключ `anchored` и ячейка перенесена без ключа — что видит получатель:
зашифрованную заглушку, метаданные-паспорт без payload, или явную ошибку доступа? Как это сочетается
с self-describing (п.1) — сама заглушка обязана быть читаема как «здесь была ячейка, доступ закрыт».
