# IDEA · Инкрементальный метаболизм (масштаб как условие, не оптимизация)

Пересчёт salience и запуск консолидации/эмердженса затрагивает только ЗАДЕТЫЕ узлы (те, что
изменились/использовались с последнего прохода), а не весь граф целиком. Без этого Витальность —
первая ценность, которая ломается при росте базы: «живая память» деградирует в статичный архив
именно тогда, когда данных стало много (тема C).

**Относится к под-грани:** 1 (затухание), 7 (бюджет внимания как инвариант базы).

**Открытые вопросы:** как инкрементальность сочетается с батч-консолидацией (грань 3), которая по
природе смотрит на несколько единиц сразу — нужен ли отдельный «горячий список кандидатов» вместо
полного скана.
