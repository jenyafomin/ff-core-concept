# IDEA — Температура как гейт видимости, не как удаление

**Суть.** Cold-статус — явное поле поведения ячейки (policy-as-data): «не всплываю сама, но
отвечаю по прямому запросу полной ценой». Это отделяет «забытое» (реально потерянное) от
«остывшее» (читаемо, но не навязчиво) — движок обязан уважать температуру при построении
автосводок, не решать её сам.

**Относится к под-грани:** П5 (температура / видимость без вскрытия) — граница с
Витальностью (Ц4): кто МЕНЯЕТ температуру (metabolism-агент) vs кто её ЧИТАЕТ (движок
сводок) — две разные обязанности, не должны слипаться.

**Открытые вопросы:** порог автоперехода hot→cold — задаётся глобально движком или
индивидуально политикой ячейки (policy-as-data)?
