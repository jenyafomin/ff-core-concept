# IDEA · `pending` — отдельная от salience ось незакрытости

Единица может быть одновременно низкой по salience (давно не использовалась) и высокой по
pending (важный незакрытый вопрос). Поле `pending: bool` + `pending_reason` не участвует в
затухании — оно требует явного разрешения (ответ/отмена/эскалация по таймауту), а не тихо тонет
вместе с общим забыванием.

**Относится к под-грани:** 8 (открытые петли).

**Открытые вопросы:** VQ3 — можно ли эскалировать pending про третье лицо без риска утечки
внимания к чужой приватной теме; FQ6 — нужна ли эта ось вообще как первоклассная, или её можно
выразить через существующий слой задач.
