# 🌍 01-overview — область «Обзор»

> Навигатор области. Здесь живёт целостная картина системы памяти «на одном экране»
> и её ценностный фундамент. Детали ветвей — по ссылкам ниже.

## Цель области
Дать вход в модуль brain: **что** это (субстрат для ИИ-агентов), **ради чего** (ценности),
**как выглядит клетка сегодня** и **какие сценарии** её проверяют. Не заменяет канон отдельных
ветвей — сводит его в один вход.

## Что внутри
- **`OVERVIEW.md`** — полная картина на одном экране: что это, из чего состоит, как разрастается.
- **`L0-memory-unit.md`** — базовый разбор единицы памяти (L0).
- **`portrait/`** — портрет клетки «как сейчас» (`cell-portrait-now.md`).
- **`scenarios/`** — сценарии-проверки модели (`INDEX.md`, мультиструктурные виды).
- **`01-values/`** — ценностный фундамент: 7 замкнутых ценностей, их декомпозиция и карты.
  → см. `01-values/GROWTH-MAP.md`.

## Соседние области
- `02-domains/` — предметные области модели (сущности/механики). *(заполняется в переезде)*
- `analyses/` — аналитические сессии-источники (в т.ч. `2026-07-05-L1-values/`).
