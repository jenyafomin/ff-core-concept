# 🤖 Как запускать агентов — карточка + конверты

**Карточка задачи (5 пунктов, вставляется в промпт дословно):**
1. **Меняет** — какую строку/файл. Ничего не меняет → не запускать.
2. **Вход и реальность** — что читать, опоры `file:line`; без опоры = «гипотеза».
3. **Выход** — один файл, полный путь, строка «Итог:».
4. **Исполнитель и бюджет** — агент, модель явно, лимит, потолок, СТОП-условие.
5. **Проверка** — другой агент; «как задачу могли поставить неправильно?»

**Конверты (блоком, по условию):** «живой бот» (шлюз) · «builder в worktree» (FF/мозг) · «третьи лица» (роль без имени, ночные агенты в мозг не пишут).
*было:* конверт E из 10 пунктов + рецепты 2a–2d · *ночь:* 5 пунктов + 3 конверта, рецепты — в experimental.

**Р1 — подтверди три правила (спорные точки S1–S12 решает лид):**
- код живых сервисов — **только в worktree**;
- деплой и `pm2 restart` — **только ты**;
- ночные/аналитические агенты **в живой мозг не пишут**.
- **да ⭐** / поправить
