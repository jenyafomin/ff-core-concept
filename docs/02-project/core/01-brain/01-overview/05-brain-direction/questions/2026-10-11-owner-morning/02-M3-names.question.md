# М3 · 🚪 Имена людей в первую неделю

**Вопрос:** можно ли хранить в памяти имена людей из твоих дел? Запись остаётся **навсегда** — стирания пока нет.

- **A ⭐** — только свои дела, **роль вместо имени** («бухгалтер», «подрядчик»). *было: зерно 7 + протокол*
- **B** — по имени только близкие. *ночь*
- **C** — человек отдельной записью `person`, видна только тебе. *ночь*

**Почему важно:** V7 Согласие — журнал неудаляемый, сервер имена не ловит (проверено сухим прогоном). Чужое имя = навсегда.
🚪 **Дверь:** да — B/C не отменить, пока нет стирания.
