# В1 · Что проверяет неделя 1 (подтверди)

**Вопрос:** согласен, что неделя 1 мерит так?

| Видение | Неделя 1 |
|---|---|
| **Туду + захват хвостов** | ⭐ главное, меряем |
| A. Петля (агент читает прошлые ходы) | только наблюдаем |
| B. Память сама приносит (push) | по правилу дня 3 (М7) |
| D. Секретарь итогов | НЕ пишет сам; см. М5 |
| C. Кухня шлюза в память | фон, не цель |

- **да ⭐** — мерим раздельно, ничего не выбираем заранее. *ночь*
- **было:** «туду, диктуешь ты» (зерно 5) — одно видение, один счёт.

**Почему важно:** провал одной идеи не должен читаться как «память не нужна» (V4 Витальность).
🚪 нет — меняется в любой день.
