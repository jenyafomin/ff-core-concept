# М5 · Итоги и решения из разговоров — предлагать?

**Вопрос:** кроме дел-«хвостов» (они предлагаются в любом случае) — предлагать к записи ещё **итоги и решения** разговоров?

- **нет в неделю 1 ⭐** — только дела; итоги включаются порогом с дня 4. *ночь*
- **да, мягко** — предложение в чате, запись только после «да», без имён, только топик 56, с дня 4 при доле «да» ≥50%. *ночь*
- **агент пишет итог сам** как `proposed`. *было: видение D*

**Почему важно:** V7/V3 — `proposed` в журнале не стирается; отклонённая запись с именем остаётся навсегда.
🚪 **Дверь:** только для варианта «агент пишет сам».
