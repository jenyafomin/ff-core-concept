## Функция (`maps/rank.mjs`, пересчитываема)
`балл = разблокирует × код(1 если code≥0.7, иначе 0.3) × чтение(1|0.5) × руки владельца(1 не нужны | 0.7 одно «да» | 0.4 нужен вечер)`; слой N+1 = 0 (B8 целиком, линзы-как-данные, люди, retention/trust и т.п.). Узлы «против», gap, root/ring балла не имеют. Два балла: «сейчас» (мир жизнь=0, всё, что пишет в мозг, ×0.4) и «после запуска» (руки=1) — этапы 2–3 ранжируются по второму.

## Этапы (подробно — `maps/ROADMAP.md`)
- **Э0** (до 2026-10-14): читатель + фильтр секретов. Выход: да/нет владельца по 10 кандидатам; ≥5 из 10 открыто → читатель = основной корм; 3–4 → гибрид с диктовкой; <3 → назад к диктовке B1.
- **Э1** (до 2026-10-18): запуск, R1–R5, первое чтение (12 узлов, вкл. двери и пол К4). Выход: лид начал сессию с find открытых и назвал ≥1 запись, которой нет в START; R5 поднялся сам.
- **Э2** (до 2026-10-25, D+7): 10 узлов: другой читатель, ядро связей, why-walk, дела разных проектов, genealogy, прогноз. Выход: GATE-7days (прогноз проверен задачей из мозга; ≥3 ответа ≠ START; 0 утечек секретов).
- **Э3** (с 2026-10-26): 33 узла — hard_erase, граница власти, остывание, push-линза. Выход: hard_erase пройден тестом (или отложен владельцем) + 1 живой возврат остывшего.
- **Э4 заморожено** (17 узлов, слой N+1): балл 0 до закрытия Э3.
Согласовано с `questions/FORKS-REGISTER.md` (строка «Этапы» обновлена: старые Э0–Э3 ↔ этапы 0–4).

## Честно: где не «функция»
1. Состав Э0 и Э1 задан зависимостью (контур R1–R5 из 02-first-heartbeat + двери B5/inline и floor-k4 по F10/«двери до первой записи»), а не порогом; внутри этапа порядок — по баллу. Э2/Э3 — порог «после запуска ≥1.0».
2. Пол-фильтр стоит в Э0 по правилу (пароли в логе открытым текстом), его балл 1.2 сам бы его не вынес.
3. Множитель «руки» и набор «даёт чтение» — мои назначения по ветвям (regex в rank.mjs), не измерения; сдвиг одного узла ≤1 этапа. Критик не проверял.
4. B4/edge-core (3-е место) «агент сам», но без запущенного мозга чтения не даст: высокий балл ≠ срочно; он в Э2, не раньше запуска.
5. Старый объект `payload.score` у B3 заменён новым (оригинал в бэкапе).

Итог: решение — шаг СЕЙЧАС = B6/reader-over-log + пол B6/reader-secret-filter; этапы 1–4 и условия перехода зафиксированы в `maps/stages.json`/ROADMAP; критик по назначению «рук» и «чтения» — задача в плане W6.
