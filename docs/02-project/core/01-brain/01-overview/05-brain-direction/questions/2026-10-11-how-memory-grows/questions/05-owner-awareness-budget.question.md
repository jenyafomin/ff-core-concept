# Q-F5: Как держать владельца в курсе, не съедая его внимание?

Внимание владельца — самый дорогой ресурс; часть ночных материалов он уже не успевает прочесть.
Позиции: architect — `FORKS.md`-лента (🔴🟡🟢) + одна Telegram-карточка на новое 🟡/🔴 + визард для пачки ответов; critic — один OVERVIEW ≤30 секунд + ≤3 вопроса с дефолтом «ок», остальное приложение; abstract — реестр «ждёт тебя», не поток уведомлений.
Оговорка critic: «ок» по дефолту — подпись, а не голос.
Дефолт: OVERVIEW.md ≤30 с (конвенция theme-homes) + ≤3 вопроса с дефолтом; `FORKS.md` только генерируемый вид из frontmatter; визард и карточка на каждое — не делать, одна сводка на сессию.
Решают агенты; владелец вето.
Условие пересмотра: владелец просит чаще или пропускает сводки.
Предсказание: владелец отвечает на сводку за одну голосовую.
