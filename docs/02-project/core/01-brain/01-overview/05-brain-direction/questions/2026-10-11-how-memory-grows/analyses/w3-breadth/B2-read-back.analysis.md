## 1. Что код уже позволяет читать (факты)
- **find** (`brain/src/read/find.ts:22-24,106-122`): фильтры scope · type · status · text · due_before · edge{pred,to} · preset · include_cold · пагинация. Тел не отдаёт. `status` сверяется и с полем, и с `rec.status` (`find.ts:109`) — значит `status:'proposed'` (записи агентов) находится.
- **Presets** (`read/presets.ts`): morning / evening / open / scope. Данные-ведомые: берут любую запись, у которой ПОЛЕ `status` ∈ open|doing|blocked (`presets.ts:5-6,12,33`), а не тип task. Потолок дайджеста ≤12 строк / ≤4000 знаков (`presets.ts:137-138` через LIMITS, `contract.ts:137-138`). evening уже даёт «не тронуто >7 дн» (`presets.ts:159-161`).
- **read** (`read/read.ts:114-133`, `traverse.ts:25-57`): запись + рёбра + соседи, depth ≤2, `preds`-фильтр, BFS только по ИСХОДЯЩИМ рёбрам. NodeView несёт `derived_from` и `source` (`read.ts:82-83`).
- **Обратный поиск без нового кода:** `find{edge:{pred,to:X}}` (`find.ts:115-119`) = «кто ссылается на X» — это ответ на «что решило/выросло из вопроса X».
- **lens** (`read/lens.ts`): только shape `compose` (статичные слои-промпты по топику, `lens.ts:139`); вызывается лишь шлюзом `sys:gateway` (`service/runtime.ts:259-267`).
- **MCP-поверхность агента** — 4 инструмента record·find·read·link (`brain-mcp/src/server.ts:96-131`). Линзы, as-of, «ждёт тебя» агенту недоступны.

## 2. Чего нет
1. Типа `question`: неизвестный тип → `raw` + friction (`domain/validate-act.ts:420-428`; `GENESIS_TYPES` без question, `genesis.ts:143-199`). Обход: `record{type:question, fields:{status:open}}` → `find{type:raw,text:question,status:open}` (text ищет и в `declared_type`, `find.ts:46-53`). Не проверено мной запуском: принимает ли валидатор поле status вне схемы raw (`validate-act.ts:489`) — проверить до обещаний.
2. Входящих рёбер в `read`, среза во времени (`asOf` пуст, D-5), фильтров по времени/температуре/тегам.
3. Push динамического содержимого: линза не умеет «запрос»; шлюз не вклеивает результат.
4. Пинга владельцу и preset для `proposed`. Метрики «что прочитано».
5. Жизни: 0 записей, мозг не в pm2.
