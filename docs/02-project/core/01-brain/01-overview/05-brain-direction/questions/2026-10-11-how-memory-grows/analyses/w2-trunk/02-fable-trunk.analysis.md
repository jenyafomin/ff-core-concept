## 1. Корень
**«Что память должна ВЕРНУТЬ раньше всего, чтобы в неё стало выгодно писать — и какие ветви для этого обязаны ожить первыми?»**
«Отыгрывать себя» = окупаемость; окупается не запись, а чтение (w1 abstract §2). Корень задаёт рост как долг памяти перед владельцем, не как список фич.

## 2. Кольцо вокруг корня — правило роста любой ветви (свойство всех, не ветвь)

## 4. Принцип «куда сейчас»
Шаг выбирает не важность, а формула: **(сколько ветвей разблокирует) × (код есть ? 1 : 0.3) × (даёт ЧТЕНИЕ ? 1 : 0.5); гейт N+1 = 0.**
Выигрывает не ветвь, а **самый короткий замкнутый контур B1→B3→B2 — «первое сердцебиение»**: 3 реальные задачи + узел-вопрос «как должна расти память?» с 1–2 актами `derived_from` + **одно чтение** «открытые вопросы» на старте следующей сессии вместо START. Всё на существующем коде; разблокирует B4, B7, B8; доказывает корень.
**Если руки владельца не включились:** контур замерзает; честное движение — B3 в record-ready frontmatter + B5 (спека `hard_erase` в `brain`, без неё B6 и люди не оживут никогда). На карте — 🔴 «нулевая предпосылка» в корне, не ветвь.

## 5. Форма узла — в мозг 1:1
Корень и ветви = `note`; решения = `decision`; `u:question` — `type-def candidate` после пересадки (§6.3). Поля вне контракта — в payload, не в схему.

```yaml
id: q:how-memory-grows/trunk/B3     # локальный; brain_id: null → при пересадке (таблица соответствий, V2)
type: note                           # ветви=note · решения=decision
label: "B3 Позвоночник решений"       # ≤60 знаков, дешёвая грань V1
summary: "вопрос → мнения с паспортом → решение с derived_from и условием пересмотра"
status: proposed                     # proposed|accepted|superseded; ветвь proposed до «да»
temperature: hot
author: fable-5.1                    # заявление, сервер не удостоверяет (V3)
confidence: 0.7
payload: {owner_points: [16,20,23], forks: [F1,F3,F4], values: {plus: [V2,V3,V6,V4], strain: [V1]},
          readiness: {code: 0.8, paper: 1, life: 0},
          prediction: "к 2026-10-18 лид сделал ≥1 чтение «открытые вопросы» не из START", check_date: 2026-10-18}
links:
  - {predicate: part-of,      to: q:how-memory-grows/trunk/root, confidence: 1.0, note: "ветвь ствола"}
  - {predicate: about,        to: "file:START-NEXT-SESSION.md#п20", note: "мысль владельца"}
  - {predicate: derived-from, to: "file:analyses/w1-altitude/00-SYNTHESIS-w1.md", confidence: 0.8}
  - {predicate: motivated-by, to: q:how-memory-grows/trunk/B1, note: "разблокируется B1"}
  # supersedes — при переформулировке ветви; старая остаётся
source: {kind: file, ref: "<этот файл>", hash: null}
```
Новых предикатов нет (F3), но «разблокирует» через `motivated-by`+`note` — уже третий ручной повтор смысла: кандидат `predicate-def` родился честно.

## 6. Независимый голос — с чем в своде w1 не согласен
1. **Свод нашёл яйцо и не положил на него ни копейки.** §а.4: точка разрыва — ЧТЕНИЕ. Но все три карты волны 2 (§е) — про форму ЗАПИСИ. Карту 3 (чек-лист) заменить на **«первый запрос чтения»**: что лид спросит у памяти на старте следующей сессии и чем ответ отличается от START. Иначе снова шлифуем форму на пустом хранилище.
2. **F1 — ложная развилка, владелец уже ответил.** П.24 «в совокупности» + п.15 «протестировать на этом чате» = «расти сейчас». Спрашивать F1 первым — тратить внимание владельца на известное. Единственный вопрос ему — «да» на семя-узел в первых 5 записях (START §5.4).
3. **Дефолт F3 «тип после 3-го повтора» уже выполнен:** `open-question` в THREAD (N-001…N-104), `question` в леджере, 5 `.question.md` здесь. `u:question` как `type-def candidate` — не обход §6 (PATCH архитектора бил по `u:vote`). Откладывать — буква против смысла.
4. **«Суд прецедентов» тяжёл для одного «да».** На неделе 1 — один судья, 2–3 дела. В стволе B3 = одно поле `prediction+check_date`, не институт; иначе церемония (ловушка В) закладывается в корень.
5. **До абсурда — если корень неверен.** Пусть разрыв не в чтении, а в **руках владельца** (RUNBOOK не запускается). Тогда карта — сад без воды, «куда сейчас» = ни одна ветвь, а свести RUNBOOK к шагу, который лид делает сам по одному «да». Проверка дешевле любой волны: вопрос «запускал?» (уже в START §4). Два «нет» подряд — пересобирать ствол от B5, чтобы агент писал без рук владельца под стоп-листом.

Итог: предложение — корень «что память вернёт раньше всего», кольцо роста + 8 ветвей (B1 корм · B2 чтение · B3 позвоночник · B4 связи · B5 пол/власть · B6 автозахват · B7 линзы/время · B8 конструктор); «куда сейчас» = контур B1→B3→B2 на существующем коде; задачи в плане — карту 3 волны 2 заменить на «первый запрос чтения», F1 не задавать, `u:question` как type-def candidate после пересадки; отложено до запуска RUNBOOK — всё, что требует жизни (B6, B8).
