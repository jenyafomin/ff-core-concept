# Q-F8: Три двери закрываются первой записью: берём их на неделю 1 как есть?

Односторонние двери (B5 в сердцебиении §4, шаг 5а RUNBOOK):
1. Всё записанное в неделю 1 остаётся навсегда (стереть можно только ручной переписью журнала и бэкапов).
2. Из 8 запретов три держит код, три промпт, два никто (копии, свободный текст провенанса).
3. Все агенты пишут от одного имени: «кто сказал» не восстановить.
Дефолт: «ок» на все три; в неделю 1 пишем только своё, без имён, только с твоего слова; пересмотр на D+7.
Если «нет»: не пишем ничего, пока не появится стирание в коде.
Оговорка critic: «ок» по дефолту здесь = подпись, не голос; поэтому вопрос идёт в топ.
Условие пересмотра: гейт D+7.
Предсказание: ни одной записи с именем третьего лица за неделю.
