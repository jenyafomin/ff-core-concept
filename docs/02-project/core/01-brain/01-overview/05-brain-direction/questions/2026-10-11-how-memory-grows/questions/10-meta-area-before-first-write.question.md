# Q-F10: Куда класть записи ночи про саму память, чтобы они не забили живые дела?

Карта ночи это около 80 записей `proposed`. Первый `find(open)` с потолком 12 строк вернёт карту, а не дела владельца (Fable G5).
Решение: отдельная область или `kind:meta`; это правило в протокол, не новый тип.
Дефолт: область `meta` с первой записи; в `find` по умолчанию она скрыта.
Решают: агенты + critic; владелец в курсе.
Уточнение (Fable w5/02, снимает противоречие): три первые записи R3–R5 лежат в `personal` (их должно видеть первое чтение); область `meta` включается, когда в мозг поедет ночная карта (~80 записей).
Условие пересмотра: владелец не видит запись, которую искал.
Предсказание: первое чтение вернёт только дела владельца.
