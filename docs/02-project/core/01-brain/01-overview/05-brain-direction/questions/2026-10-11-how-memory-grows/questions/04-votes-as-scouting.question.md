# Q-F4: «Голосование» агентов — подсчёт или разведка? Как не принять эхо за подтверждение?

Слово «голосуются» — владельца, поэтому решать ему.
Факт: линзы — одна семья моделей, один корпус; «4 из 4» ≈ 1 голос. Под шлюзом роль и модель — заявление в поле (V3).
Позиции: critic — разведка вариантов, число «за» не показывать, минимум один голос не из семьи (владелец, эксперимент, prior-art), калибровка «решение → что случилось через 7 дней»; architect — считать по семьям, единогласие при ≥2 семьях/источниках; abstract — «доказательства с весом», не бюллетени.
Дефолт: голос = разведка; решает владелец; если все линзы «за» — принудительный шаблон ② «до абсурда»; каждое решение с предсказанием и датой проверки.
Условие пересмотра: накопится ≥5 решений с итогом, по ним считать точность.
Предсказание: ≥1 принудительная проверка найдёт слабое место.
