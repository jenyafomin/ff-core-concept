## Как считать (из корня FF)
```
cd /Users/mac16/Documents/IT/Apps/FF-Personal-Managment
p=$(node packages/brain/dist/bin/ff-brain.js export personal | jq -r .path)   # путь к файлу export (0600); в /tmp не копировать
A=$(jq -r '[.records[]|select(.type=="task" and .status=="active")|.meta.created_at]|min|.[0:10]' "$p")   # день 0 = UTC-дата первого active task
B=$(date -j -v+7d -f %Y-%m-%d "$A" +%Y-%m-%d)                                  # окно [день 0, день 7) в UTC-датах
jq --arg a "$A" --arg b "$B" '
 [.records[]|select(.type=="task" and .status=="active" and .meta.created_at>=$a and .meta.created_at<$b)] as $t
 | {S1_tasks:($t|length), S1_days:([$t[]|.meta.created_at[0:10]]|unique|length),
    S1_burst:([$t[]|.meta.created_at[0:16]]|group_by(.)|map(length)|max),
    S2_done:([$t[]|select(.fields.status=="done" and (.fields.done_at//.meta.updated_at)>=$a and (.fields.done_at//.meta.updated_at)<$b)]|length),
    src_owner:([$t[]|select(.fields.src=="owner")]|length), src_offer:([$t[]|select(.fields.src=="offer")]|length),
    src_missing:([$t[]|select(.fields.src==null)]|length),
    proposed_not_counted:([.records[]|select(.type=="task" and .status=="proposed")]|length)}' "$p"
```
- Дни в своём поясе (когда владелец назовёт смещение OFF часов, напр. PDT = -7): `jq --argjson off -7 '[.records[]|select(.type=="task" and .status=="active")|.meta.created_at|sub("\\.[0-9]+Z$";"Z")|fromdateiso8601+($off*3600)|strftime("%Y-%m-%d")]|unique|length' "$p"`.
- `stats` для гейта НЕ годится (считает и `proposed`, и `superseded`; в прогоне stats дал 4, честный счёт — 3). Только «мозг жив».
- По протоколу rev2 все записи агента — `active` (без `initiative`); `proposed_not_counted > 0` = агент нарушил протокол → разобрать.
