## Одна мысль
Память — не хранилище, а **конструктор**: из принципов рождаются паттерны, из паттернов собираются системы, а ИИ через
линзы сам подтягивает нужную структуру, контекст и интерфейс. Это не новое направление, а **имя** для видения проекта
(msg 141 + модульность/plug-in + ADR-0017). Новое — два зерна: цепочка «принципы → паттерны → переиспользование» и слой «система».

## Шесть слоёв (Fable)
1. **Принципы** — 7 ценностей + «пол» в коде (проверка имён, согласие, стирание, остывание). Вечные.
2. **Паттерны** — переиспользуемые формы-данные: тип + связи + политика по умолчанию + линза по умолчанию + роли
   (цель, задача, роль, процесс, линза, политика…). Имя паттерна — навсегда.
3. **Пакеты** — словари паттернов (`pack:`, ADR-0017; как плагин в Claude Code).
4. **Системы** — собранный экземпляр: пакеты × область × роли × цель × процесс × линзы («луп с целью», «организация»,
   «баг-трекер», «мои задачи»). Сейчас этого слоя нет; система должна быть узлом со связями — иначе не переносится (V5).
5. **Экземпляры** — живые записи.
6. **Виды/интерфейсы** — линзы рисуют картину и **собирают контекст для ИИ** (управление контекстом = линза с бюджетом).

Наш собственный Claude Code (CLAUDE.md, правила, скиллы, агенты, хуки) — **первый прототип конструктора**: правило ≈ политика,
скилл ≈ паттерн с процедурой, плагин ≈ пакет, хук ≈ пол.

## Первая система для проверки
**«Луп с целью — развивать память»** — то, что мы уже делаем в этом чате. Процесс = линза «вопросы без ответа»,
а не движок процессов. Тест: через ~5 сессий хендофф собирается линзой из памяти, а не пишется руками.

## Гардрейл (критик, компаунд-триггер 5)
Слой N+1 проектируем только после живого прогона слоя N: сначала память запущена + 5 реальных записей → паттерны из
реальных троп → система «луп-память» → только потом роли/процессы/чужие системы.

  в журнале → связи с паспортом → решение со ссылками «из чего выросло». Майнд-мап = срез журнала на момент времени.
- **Уже есть (в доках):** дерево доков (узлы-папки, `questions/ ideas/ analyses/`, LOSE-NOTHING) + граф диалога
  (`docs/base/dialogue/THREAD-2026-06-15-foundation.md`, N-001…N-104) + креатив-леджер (семя → кандидат → направление).
  Метаморфоза = это всё, **переселённое в журнал мозга**. Новое по-настоящему: **срез «на момент»** (свернуть журнал до даты)
  и **голоса**.
- **Паттерн «цикл роста»:** накидать → сгруппировать (от ~7 детей) → расширить; меньше 2 новых соседей → углубить →
  решить после критика → отвергнутое **остывает, не удаляется**. Пороги — настройки, не код.
- **«Git для смысла»:** самое ценное и дешёвое — **blame** (линза «почему это решение») и **log** (лента). Diff — позже.
- **Защита от раздувания:** сырьё агентов остаётся АДРЕСОМ (файл/транскрипт); в граф входят только синтезы; у ветки одна
  ссылка «текущее»; голос агента — метка с провенансом, решает «да» владельца.
- **Не строить:** движок процессов, сущность «метаморфоза», свою систему версий, машинку голосования, авто-кластеризацию, UI майнд-мапа.
- **Семя (курица/яйцо):** вопрос «как должна расти память?» — один цикл вручную в доках сейчас, теми же записями в мозге
