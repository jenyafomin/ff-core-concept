Потребитель: следующие сессии трека «мозг» (направления после /access и overview). Поглощает: голосовые мысли владельца 2026-10-23.

## Зёрна владельца (голос, 2026-10-23)
1. **Каждый проект живёт своей жизнью**: у проекта своя точка входа (доступ · карта · устав · готовые поиски), а с общим (ff) делится наработками.
2. **Плагины памяти**: при подключении плагинов в памяти появятся новые сущности/типы; агент должен писать то, что НУЖНО (по уставу/типам), а не то, что может.
3. **Отдельный фронтенд памяти**: показывать всю информацию, анализировать; общий граф-модуль как mind map; посмотреть готовые плагины/библиотеки для связей, но оставить возможность своего для гибкости.
4. **Монорепо**: одни общие правила памяти + сервисы/микросервисы поверх неё (канбаны, календари, виды задач) — «это всё просто данные, их надо правильно презентовать».
5. **Каждый сервис может давать агентам свой MCP** для работы с памятью через свой вид.

## Связь с уже решённым
- Совпадает с «виды = линзы над журналом» и «конструктор для ИИ» (`2026-10-11-constructor-for-ai.idea.md`): сервис = вид/линза, MCP сервиса = дверь агента в этот вид.
- Гардрейл компаунда: слой N+1 (фронтенд, сервисы) — после живого N (доступ + overview + устав на 1–2 проектах).
