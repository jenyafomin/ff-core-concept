## 3. Напряжения по ценностям (для критика)
- **V1 Читаемость:** `find` без `scope` отдаёт все области (M-18); push (M-19) растит цену дешёвого взгляда; свод ночи не должен быть дороже чтения 5 файлов.
- **V2 Тождество:** два дома `task` (пул лупа vs мозг); id/root областей необратим; дубль голосового даёт дубль записи (M-17).
- **V3 Доверие:** агент пишет от `user:owner` как факт (M-05); Q6-дефолт усиливает; S3 — самоотчёт; метка недоверия не наследуется пересказом (S4).
- **V4 Витальность:** `cold` не построен, а 49 открытых пунктов растут; S6-лимит `proposed`; ночная работа сама «раздувает».
- **V5 Суверенность:** числа слоя C в БД шлюза vs акты; траст «Всегда» живёт в localSettings Claude, не в данных; pm2 из dev-дерева (M-40).
- **V6 Реляционность:** сироты-рёбра (GAP-7); связь проекта с компанией через `part_of` пока гипотеза.
- **V7 Согласие:** enforcement выключен; имена не ловит скан; копии вне мозга (M-03); ga-rentacar PII; ночные документы про людей (Никола, Павел) — уже третьи лица.
