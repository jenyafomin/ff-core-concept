## Группы (зерно 2026-10-12) — концепт, ложится на существующий мозг
- Группа = обычная ячейка; членство = ребро `part-of` (cardinality many — `genesis.ts:218`); перелинковка = retract старого ребра + новое (история сохраняется, журнал append-only); группа в группе = следующий слой абстракции.
- Не хватает: пакетной атомарной перелинковки; обхода по входящим рёбрам; «умной группы» (членство по правилу = линза) — слой N+1.
- Хранение: истина = журнал мозга (один append-only файл); БД (Postgres) — только пересобираемый индекс, когда появятся несколько писателей; владельцу — md-виды, генерируемые из графа. (pm2 `pg` — чужой YashaBot, не наш.)
- **Двери владельцу до первых данных:** Д2 — `part-of` = «группировка» и «часть целого» — один смысл или два? · Д3 — группа = отдельный тип или РОЛЬ любой ячейки (рекомендация: роль). Д1/Д4 следуют (не сужать many→one; БД = индекс).
- Живой срез групп — после запуска мозга: читатель предлагает кандидатов → владелец одной командой собирает их в группу → md-вид группы.
