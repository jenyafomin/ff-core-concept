## 2. Патчи (по порядку)
1. **D-2 vs «заморожен рефакторинг».** Свод требует решить кодирование ref ДО записи и одновременно замораживает код. Выбрать явно: «в Э1 только ASCII-пути (конвенция), кириллица/`@`/длинные — Э2», и написать, что делать, если тест п.6 красный. Тест нацелить на РЕАЛЬНЫЙ формат ref (`repo:ключ/путь`: кириллица, длина, серии цифр в именах), а не на «20 случайных git-sha» (sha в ref больше не входит).
2. **Документ вне git.** Дефолт Q1 — блок про шлюз; одна из пяти копий живёт в `~/.claude/rules/` (не репозиторий, нет ключа в реестре, `raw/05` D2). Модель «файл в git + `repo:<ключ>`» её не покрывает. Решить до Э1: дом = блок в FF `CLAUDE.md`, либо ключ реестра для `~/.claude`.
3. **Маршрут записи Э1 п.3 не прослежен.** Агентам запрещён запуск brain-mcp/чтение `~/.ff-brain` хуками (`raw/01` шапка); «агент записывает вручную через `record`» требует флагов B5 + рестарта `agent`. Добавить в Э1 шаг «кто и откуда вызывает `record`/`find` во втором проекте (readers.json, MCP-конфиг, стоп-лист B7)». Также проверить grep'ом, что поле `placement` существует в коде (D-3 на него опирается; в `raw/01` его нет) и поставить в Э1 порядок: запись → чеканка `u_…` → вписывание `brain_id` в frontmatter (отдельный коммит, с согласия владельца): сейчас в Э1 п.1–6 этого шага нет, а D-1 его требует.
4. **Риски Э1.** Добавить B6 (дубль голоса: idem не защищает → дубль записи; основной ввод владельца голос), B2 (pm2 5.4.2 vs 7.0.3), B4/B7 «не проверено». У каждого — «если случилось → урезание до …». Оценку рук пометить «не валидирована».
5. **«Мир, где оба правы» — пометить гипотезой** + фальсификатор с датой (replay на копии журнала / contract-тест порта к 11-03). Честную формулировку владельцу см. §5.
6. **§3 разделить «есть» и «построить».** Чтение тела по `source`, сверка hash → `stale`, `_generated/shared-docs.md` — Э2/Э3 (код отсутствует). Э1 обещает ровно: конверт + путь-источник. Заодно сверить D-2 (repo-relative) с «абсолютный путь дома» в `_generated` (`raw/02` §2).
7. **Ужать Э3–Э5 до банка** (триггер + цена), без дат, пока не заполнен «Что обнаружили». Переформулировать п.1 свода: «сошлись 4 из 6 по пунктам…», а не «все шесть».
Минор: V7 — «тело в журнал не пишем» не равно «PII нет»: label/summary тоже уходят в неудаляемый журнал; в Э1 белый список путей + запрет третьих лиц в summary.

## 3. Флаги качества / дрейфа
- **unverified:** маршрут записи (Э1 п.3); существование `placement`; `replay.ts` как гарантия «без переписи»; «10 мин/день диктовки».
- **too-smooth:** «качество = швы» принято линзами легко, при том что шов 0.5 и работа по нему стоит ПОСЛЕ первой записи — владелец вправе спросить «почему не до».
- **not-decomposed:** «снять 3 привязки» — отмечено file:line (`schemas.ts:5,14,53,64`), ок; а «вынос lock/backup/repair за интерфейс» (≥8 файлов) в Э3 не разложен.
- **дрейф (г):** нового навигатора не плодим (поглощение описано, не исполнено — нужен «строй») ✓. Код до «строй» не тронут ✓. Дрейф-риск: волна анализа (6 линз + свод + критик + помощник) уже съела бюджет, а запрет новых волн действует только с 10-27 — приемка должна идти в ТОТ ЖЕ ход, не новой волной.
- **reuse:** ✓ ADR-0006/0016/0017, `00-states/03`, launch-kit; дубль-дом не создан.

## 4. Ценностные напряжения (д)
- **V2 Тождество — укрепляет** (`brain_id` в frontmatter; путь ≠ id). Напряжение: файлы без frontmatter (CLAUDE.md, rules) и вне git; вписывание id = единственная запись мозга в файл (нужен консент).
- **V3 Доверие — напрягает.** `stale` по hash не реализован (патч 6); до Э2 агент может прочитать устаревший конверт без пометки. Ставить A5 честно в Э2.
- **V5 Суверенность — укрепляет** (ref по ключу реестра, не абсолютный путь). Мелкая нестыковка с `_generated` (патч 6).
- **V7 Согласие — напрягает** (нет hard_erase; summary/label неудаляемы). Смягчено белым списком — формально.

## 5. Детектор расхождения (е) — «владелец: PG/Nest ради качества» vs «линзы: по триггеру»
- **Счёт 3/3?** Изолят: да (владелец один против 6). Высокая уверенность: **нет** — формулировка условная («если правильнее»; `BRIEF.md:15`), это не позиция, а вопрос. Несущая развилка: да (поднимает T1 в E0, `raw/03` §4). Итог: **2/3 — не детектор в строгом смысле, но развилка с владельцем несущая; считать как сигнал.**
- **Рамка:** спор на деле про ОПРЕДЕЛЕНИЕ «качества». Шаблон ③ («при каком мире оба правы») свод уже применил. Добавить **④ «смена валюты»**: что дешевле опровергнуть — аргумент или факт? Прогнать replay журнала на копию/контракт-тест порта и ПОКАЗАТЬ. Зерно CL-041.
- **Как подать владельцу честно (5 тезисов):**
  1. Ты прав в главном: решения, которые нельзя откатить, делаем на уровне продакшена сейчас (двери §6).
  2. «PG позже» ≠ «не качественно»: качество = переезд на PG ничего не переписывает.
  3. Честно: эта гарантия ПОКА не доказана — шов готов наполовину (порт синхронный, ~8 файлов знают, что журнал = файл). Мы утверждаем, а не доказали.
  4. PG сейчас стоит 3–5 дней и сдвигает первую запись на 1–2 недели — тот самый паттерн «готовим фундамент». Nest не добавляет ни одной ценности V1–V7 (второго потребителя HTTP нет).
  5. Выбор: (а) по триггерам, доказательство шва к 11-03 · (а+) то же, но contract-тест порта идёт ПАРАЛЛЕЛЬНО Э1 силами агентов (твоих минут 0; ограничение — не трогать код вне теста). Рекомендую (а+), если владелец хочет «чувствовать опору» на этой неделе.
- Не подавать как «линзы единогласны» (одна семья моделей, `raw/03` критерий 7: согласие не доказательство).
