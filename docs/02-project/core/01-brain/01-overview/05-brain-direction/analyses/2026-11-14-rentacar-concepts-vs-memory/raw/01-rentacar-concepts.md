## 3. «Таблица» — что имеется в виду
Прямых слов «таблица, о которой…» в 144–164 нет; в сырых голосах «таблица» встречается 5 раз, всегда как слой данных:
1. **Самое вероятное — таблица БД CRM как слой описания вещи.** Г.144: «группа данных… можно посмотреть всю таблицу, сами поля по группам… или по всей таблице». Г.145: «документация… описывая как раз сами таблицы/данные, связи, процессы» (оговорка «я не про реальные данные CRM, которые выгружаем»). Г.152: «данные — как минимум сама таблица, сами поля, у каждого поля кто читает, кто пишет». Доказательства в корпусе: `S/docs/spec/business-process/data/tables/TBL-*.md` — 54 файла, сгенерированы из кода (`scripts/gen-data-layer.ts`), поля с типом и ссылкой на entity; 704 поля (CONCEPT-v2 §3). Спуск CONCEPT-v2 §2: «данные: таблица → группы → поля». У Заказа таблица — одно из 4–5 мест (HANDOFF-160 §1.2: обзор `/v/ORD`, группа `DG-ORD`, вещь `/m/order`, таблица `TBL-orders`).
2. **Вид «таблица полей»** (способ показа, не сущность): D118 «свои виды (граф, матрица, таблица)», CONCEPT-v2 §2 «таблица полей / матрица поле × кто читает и пишет». Г.159: матрица «лишь пример».
3. **Ячейка ≠ таблица**: владелец сам развёл (г.145) «не про таблицы, а про ячейки/типы-данных»; ячейка = сущность (D117). Для ff-brain это важно: «таблица» у него — физическое хранение, «ячейка/вещь» — единица смысла.
4. Менее вероятно: Google Sheets (`S/spreadsheets.md` — источники импорта старой CRM: Orders, Transactions, FINES…); `expect.tsv` (карта ожиданий, 259 строк) — рабочий артефакт агентов, владелец его таблицей не называет; «127 новых таблиц» WIDE-99 — гипотеза.
Контекст «таблицы нужны» вне окна: г.100–102 («закупка запчастей — своя таблица», «план работ — своя таблица»). Если владелец сказал «таблица» вчера/сегодня — спросить: слой БД, вид показа или «вещь».
