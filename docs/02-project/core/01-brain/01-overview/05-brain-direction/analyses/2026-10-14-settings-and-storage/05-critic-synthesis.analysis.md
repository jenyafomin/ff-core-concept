- Владелец: «интересно мнение лида» — в своде не было. Добавлено.

## 2. Подавлена ли позиция владельца?
Нет. Владелец сам держит правило «N+1 только после живого N», и PG-проекция в дефолтах есть (позиция Fable). «Accepted частично» по c04 честно, ценность (V5, V2) названа. Но: «третий ход» подан как сходимость, а это уступка Fable; и дефолт «PG при запуске» конфликтует с §4 (тест может сказать «не нужно»). Патч внесён: проекция после теста и В1. Расхождение, строго по детектору 3 из 3, — изолят Fable при высокой уверенности и несущей развилке; «хитрая проверка» (шаблон ③) применена верно, ось — читатель vs писатель.
