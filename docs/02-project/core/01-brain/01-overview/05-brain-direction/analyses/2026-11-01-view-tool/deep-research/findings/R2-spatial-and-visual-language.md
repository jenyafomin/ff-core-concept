## Находки

1. **Semantic zoom = уровень детализации, а не масштаб (Pad++).** Объект рисуется по-разному в зависимости от размера: при отдалении упрощённая форма, при приближении детали. [П] [Bederson, Pad++](https://static.usenix.org/publications/library/proceedings/tcl95/full_papers/bederson.txt). Идея: зум переключает грань. FF: label→summary→тело уже есть как поля, нужен только порог «размер на экране → грань». Толкает: много.

2. **Heptabase: при зуме <30% остаются только заголовки, секции видны всегда.** [П] [wiki.heptabase.com/section](https://wiki.heptabase.com/section). Идея: пороговая лестница + «якорные» контейнеры. FF: scope/область = секция, label = заголовок. Толкает: средне.

3. **LLM-канвасы с семантическим зумом: Sensecape (UIST'23), CanvasConvo (4 уровня: Cluster/Minimal/Compact/Full), MindTrellis, ScholarMate, VisCanvas.** [П] [Sensecape](https://arxiv.org/pdf/2305.11483); остальные только по сниппету [Сл], [поиск](https://arxiv.org/pdf/2605.15848). Идея: 4 дискретных уровня + переключатель «холст/иерархия». FF: четыре уровня = кластер → label → summary → тело; иерархия = дерево scope. Толкает: средне.

4. **Degree-of-Interest (Furnas 1986, Card&Nation 2002): показывать то, у чего интерес выше порога, остальное сжимать.** [П] [сниппет](https://homes.cs.washington.edu/~jheer/files/2003-InterestEstimation-CHI.pdf). Идея: видимость = функция (близость к фокусу + априорная важность). FF: априорная важность = status/confidence/stale; фокус = текущий запрос агента или человека. Решает «1350 узлов не влезают». Толкает: много.

5. **Value-Suppressing Uncertainty Palettes (CHI'18): при высокой неопределённости цвету отдаётся меньше диапазона (блёкнет), при низкой — больше.** [П] [Tableau Research](https://www.tableau.com/research/publications/value-suppressing-uncertainty-palettes). Идея: confidence управляет насыщенностью/бюджетом канала, не отдельным значком. FF: confidence/stale → насыщенность и резкость. Толкает: много.

6. **Stale data в картах-рабочих пространствах: визуально выдавать устаревшее и срок годности.** [П, оборонные работы; сниппет](https://www.dst.defence.gov.au/publication/visualising-uncertainty-decision-support). Аналогия fog of war: неизвестное/старое затуманено, а не скрыто. FF: `cold`/`stale` = туман, запись остаётся на карте. Толкает: средне.

7. **Sparklines Тафти: «слово-размерная» графика, без осей и легенд, вставляется в текст/таблицу.** [П] [edwardtufte.com](https://www.edwardtufte.com/notebook/sparkline-theory-and-practice-edward-tufte/). FF: микро-график «жизни» записи (правки/обращения за время) в строке label. Нужны данные истории; сколько их у ff-brain — не проверено. Толкает: средне.

8. **Grafana Node Graph: у узла кольцо-дуга из секторов (доли суммируются в 1), цвет и граница настраиваются полями.** [П] [docs](https://grafana.com/docs/grafana/latest/panels-visualizations/visualizations/node-graph/). Идея: узел = диаграмма-«циферблат» по полям. FF: кольцо = доли рёбер (подтверждающие/противоречащие/устаревшие). Толкает: средне.

Не проверял: Factorio/Civ tech tree, Kinopio/Muse, Dynamicland, GDC — остаются за пределами этой миссии [Сл].

## Два ИННОВАЦИОННЫХ хода для FF

**Ход 1. «Грамматика состояния как данные».** Одна таблица-правило (запись типа `view-style`, хранится в памяти): поле → визуальный канал. `status` → форма/заполнение (open пусто, active полно, done галочка-тень, cold ледяной контур); `stale` → туман (размытие); `confidence` → насыщенность по VSUP; противоречие → разрыв/красная дуга на ребре; свежесть → пульс-ореол. Рендерер читает правило и применяет, не зная смысла полей. Меняют правило человек или агент (гибкость в данных), а набор каналов фиксирован в коде и проверен на читаемость (безопасность в коде). За 5 секунд: пятно ярких узлов = живое, блёклое = остыло, красные дуги = конфликт.

**Ход 2. «Зум по интересу, а не по масштабу».** Объединить 1 и 4: грань записи определяется не размером на экране, а DOI = близость к фокусу × важность (status/confidence/свежесть). Рядом с фокусом (запросом агента, текущей задачей) раскрыто тело, у периферии summary, у далёких label, у остывших — только туман-точка. Одна и та же карта для человека и ИИ: агент задаёт фокус через MCP, и ответ — тот же вид, что видит владелец. Правило порогов тоже запись.

## Что не брать
- Силовые «hairball»-раскладки на все 2650 рёбер сразу. Гравитационная раскладка без DOI превращает карту в клубок [Сл].
- Баллы/бейджи/уровни (геймификация). Берём только визуальную грамматику.
- Свободный холст в стиле Muse/Heptabase как первичный вид: ручная расстановка не масштабируется до ~1350 адресов и расходится с генерацией [Сл].
- Шкалы ценности «хорошо/плохо» по цвету: цвет несёт статус, не оценку.
