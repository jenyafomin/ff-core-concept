## Разбор по системам (механизм / провал / наш маппинг)
| Система | Брать | Избегать | У нас |
|---|---|---|---|
| Tana supertags + live search | тег = тип с полями; живой поиск = сохранённая линза | тег-взрыв, у каждого свой | тег = узел + ребро; линза = узел `lens:` (п.4, 14) |
| Roam/Logseq | дневной журнал как хребет, блок-ref по id | ref ломается при правке блока; один файл = все блоки | журнал актов = хребет; адрес = id, не копия (Q1) |
| Obsidian/Dataview/Bases | вид = запрос над фронтматтером | вид становится «вторым домом» правды | линза читает, не пишет |
| Notion relations/rollups | двусторонняя связь + агрегат поверх | rollup по тяжёлым базам тормозит; схема жёсткая | рёбра M:N, свёртка = линза |
| Capacities | типы объектов, лёгкие и человеческие | тип на каждый чих | `sys:`/`pack:` типы, новое только `note`+ребро |
| Palantir Foundry | objects/links/actions + права на уровне свойств; действие = единственный путь записи | тяжёлая онтология до данных | акт = action; policy-as-data |
| Clay/Dex (люди) | человек = первоклассная сущность, контекст последнего касания | скрейпинг контактов без согласия | слой «люди» (п.8): узел `person` с ролью, V7 |
| Mem.ai | авто-линковка/подсказки | молчаливые ложные связи | авто-связь только как `confidence`-ребро с `source` (V3) |
| Rewind/Limitless | захват всего = ценность поиска | privacy-провалы: третьи лица, нет забвения, подписанное «всё» | захват только после `hard_erase`; адрес, не текст |
| Gmail/Slack/Vault | retention по категории/источнику + legal hold как переопределение | молчаливое вечное хранение; hold без владельца | п.9: retention-policy как данные + «hold» флаг |
| Zettelkasten | атомарная единица + связь с «почему» | заметки-свалка без связей | итог хода 1–3 строки (Q3), ребро с причиной |
| Datomic/event sourcing | журнал неизменен, состояние = вид; as-of запросы | реплей-долг, схемные миграции | уже наше ядро; виды перестраиваемы |
| Zep/Graphiti | рёбра с valid_at/invalid_at: факт не удаляется, а «закрывается» | LLM-экстракция сущностей шумит и дублирует | V4: остывание/supersede ребром, не delete |
| Letta/MemGPT | иерархия памяти: ядро / архив, агент сам правит | агент сам решает забыть — без аудита | сам пишет только через акт, садовник сводит (Q9) |

## Топ-7 заимствований (ценность/цена)
1. **Журнал = хребет, виды = запросы** (Roam+Datomic+Dataview). V1,V2,V6. Цена мало: уже есть. Лента дня = первая линза.
2. **Темпоральные рёбра valid/invalid** (Graphiti). V3,V4,V6. Цена средне: поля на ребре; замена delete.
3. **Тег как узел, живой поиск как узел-линза** (Tana). V1,V5,V6, п.4/11/14. Цена мало.
4. **Адрес+подпись, не копия** (Rewind-антипример). V7,V1. Цена мало: Q1.
5. **Retention-политика по источнику + hold** (Vault). V4,V7, п.9. Цена средне: политика-данные в области.
6. **Единственный путь записи = акт** (Foundry actions). V3,V7,V5. Цена мало: хук пишет акт «был ход».
7. **Человек как узел с ролью и «последним касанием»** (Clay). V2,V6,V7, п.8. Цена средне; после `hard_erase`.

## 3 анти-паттерна
- **«Захватить всё сначала, разобраться потом»** (Rewind): третьи лица в неудаляемом журнале; нарушает порядок Q5.
- **Авто-экстракция сущностей LLM без провенанса** (Graphiti/Mem шум): дубли людей/тем ломают V2; всё с `source`+`confidence`, дубли сводит садовник.
- **Вид как второй дом истины / тег-онтология вперёд данных** (Obsidian/Foundry): линзы не пишут; типы растим из реальных ходов.

Итог: решение-кандидат — взять пп.1,3,4,6 в первую волну (дёшево, ложатся на ядро), пп.2,5,7 — после `hard_erase`; три анти-паттерна внести как критерии для critic.
