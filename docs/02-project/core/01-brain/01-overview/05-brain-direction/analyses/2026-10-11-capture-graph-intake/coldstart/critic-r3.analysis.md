## 4. Блеф-пробы (3 звучащих пусто утверждения против реальности)
1. «Машина сейчас в −7; без пояса гейт не стартует» — **проверено**: GATE стр. 15 («PDT = -0700… без ответа гейт не стартует»), `date +%z` = −0700. Не блеф.
2. «Фикс дубля закоммичен в отдельном worktree, не влит, к запуску не нужен» — идёт из START §1 (`c60dad5`, 40 позади), честно помечено «со слов»; r3 сам заявляет, что не перепроверял. Не блеф, но это пересказ, не наблюдение.
3. «Заведу узел-папку Б только по “строй”» — совпадает с doc-tree («на диск — только по строй») и START §5.3; r3 сам сомневается и обещает спросить. Не блеф — калиброванная неуверенность. Единственное отклонение: START говорит «лид + 1 волна», r3 планирует волну 0 + волну 1 + помощник (6–7 агентов); обосновано законом 7, но рискует той самой «анализ как избегание». Это CONCERN про экономику, не про понимание.
Признаков блефа нет: раздел E r3 называет собственные слабые места (не читал сиды, длина сообщения, лишние агенты).

## 5. Остаточный разрыв приемлем?
**Да, для старта сессии.** Что осталось: п.9, 10, 11, 13, 18 — только номера; п.8/14 — частично; 5 решений 10-10 не упомянуты. Все они (а) уже вынесены START в явный список «не тронуто, ждёт слоя N+1» и в обязанность хендоффа, (б) по гардрейлу «N+1 только после живого N» не нужны для открытия, (в) лид может прочитать сид по требованию (START §2 прямо велит «перед работой прочитать оригиналы»). Остаточный риск: холодный лид, не открыв сид, на шаге «расширить» подаст в цикл только номера 9/10/11/13/18 без смысла, и «расширить» получится по ярлыкам. Это ловится критиком на постановку (закон 7), поэтому не блокер.

**Патчи — не load-bearing, не требуются.** Если делать (по желанию, ~2 строки, дёшево): в §2 «Что легко потерять» п.8 добавить явную фразу «К4 про имена — это пол, а не отказ хранить слой людей»; и в обязанность лида: «перед шагом “расширить” открыть сид п.9/10/11/13/14/18 в оригинале, не работать по номерам».
