# 🧠 KQ-11 — память: проекция или узел? (синтез совета 2026-07-25)

## 1 · Вопрос
Step-6 «память» = чистая **проекция** (ноль узлов, recall = query) ИЛИ первоклассный `type:memory`
узел? Формулируется как выбор `domain_event` vs `observation`.

## 2 · Консенсус совета
- **Контент памяти — это проекция (волна).** Само «воспоминание» не хранится как отдельная сущность.
- **Хранится АКТ запоминания/курации = `observation`-акт.** Никогда `domain_event` — вспомнить ≠
  изменить задачу; запоминание не меняет мир, только фиксирует наблюдение.
- **Сырой recall = query, даже не акт.**
- **Первоклассная АДРЕСУЕМАЯ вещь нужна только**, когда вспомненное убеждение должно иметь **свой ACL**
  или быть **целью отношения** (`contradicts→` / `verifies→`). И тогда правильная единица — не
  `type:memory` узел, а **insight/assertion EDGE с тонким паспортом**:
  `confidence · provenance(wasDerivedFrom) · valid-time · epistemic`.

## 3 · Реконсиляция (это = решения владельца в L0)
Совет пришёл к тому же, что уже приземлено в `../L0-memory-unit.md`:
- **В4** — thin-passport insight EDGE (адресуемое убеждение = ребро с паспортом, не узел);
- **В2** — битемпоральное версионирование;
- **Forget ≠ Rework**.

→ **Дубль-тему свести в один дом** (закон #2): L0 остаётся истиной единицы памяти, этот синтез
проецирует и добавляет scope-clauses ниже. **L0 не переписывать** — линковать явно.

## 4 · Требуемые scope-clauses (иначе — мины)
- **I-4 (иммутабельность) применяется ТОЛЬКО к `domain_event`** — иначе «policy-prunable observation»
  из act-kinds конфликтует с иммутабельностью.
- **I-5 нужен явный carve-out**: ранжированный/salient recall **недетерминирован** → это
  **версионируемая проекция**, а не строгий детерминированный fold.
- **«Forget» = флаг видимости**, не редактирование лога.

## 5 · Реально оставшийся вопрос владельцу — РЕФЛЕКСИВНОСТЬ
Питает ли `observation`-акт запоминания обратно вход будущего recall (память-о-запоминании; L0 **Г2**
«запах/резонанс»-подталкивание) — или это инертный audit-trail? Это и есть развилка, которую совет
оставляет владельцу.
