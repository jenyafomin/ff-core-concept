# 02-domains · Домены-ДАННЫХ

> Область под-обзора brain: **какие домены-модели данных рождаются из ценностей** проекта.
> Не «как строим» (это `02-infrastructure/`), а **что за сущности живут в графе-субстрате** и как
> каждый домен собой представляет свой кусок мира.

## Что здесь
Каждый домен-модель — это **единица**, разложенная по фиксированному фасет-шаблону (аспект 11):

| Слот | Что несёт |
|---|---|
| `01-explain/` | что это за домен (вход-объяснение, рост) |
| `02-entities/` | сущности/типы узлов домена |
| `03-relations/` | связи/типы рёбер домена |
| `04-mechanics/` | механики домена (domain-local), сессионные разборы |
| `05-policy/` | политики/доступ домена |
| `06-nuances/` | уникальные нюансы (по мере появления) |
| `questions/` | узел-вопрос домена: открытые развилки прямо у дома единицы |
| `decisions/` | со-локейт решений домена (общий бакет, линкуется в `decisions.INDEX`) |
| `_archived/` | мёртвое/уехавшее (underscore, вне хребта) |

## Домены (единицы)
- **`01-knowledge-graph/`** — базовый домен: граф узлов-и-рёбер, паспорт, слои, линзы, акты, категории/теги.
  КАНОН модели данных. См. `01-knowledge-graph/knowledge-graph.concept.json`.
- Остальные домены-модели — заготовки в `GROWTH-MAP.md` (заводятся по мере деривации из ценностей).

## Навигаторы
- `domains.concept.json` — граф-снимок области доменов.
- `README-old-domains.md` — прежний индекс области (сохранён как источник, до-фасетный).
- `GROWTH-MAP.md` — как ветка доменов углубляется.

## Границы
- Это **домены-ДАННЫХ** (BR-1 решён): агенты-оркестрация уехали в `02-agents/` — тут только редиректы в `_archived/`.
- Как эти домены **реализуются** (backend/db/api) — в `02-infrastructure/`, зеркалом тех же NN.
