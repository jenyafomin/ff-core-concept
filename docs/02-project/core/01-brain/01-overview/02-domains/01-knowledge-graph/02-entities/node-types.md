# Реестр node-type — домен 01

> Каждый node-type = строка реестра, не таблица. Общий паспорт для всех: `canonicalId, node-type, scope,
> storageLevel, ownerId/tenantId, committed, localOnly, provenance, created/updated`. Ниже — смысл, ключевые
> поля паспорта сверх общих, форма payload.

## Поля паспорта (ратифицировано 2026-07-12, см. architecture/2026-07-12-COMPLETENESS-and-model.md §4)
Добавляются в общий паспорт всех узлов (что каждое настраивает):
- `status` — жизненный цикл узла (draft/active/…); «черновик» ≠ `committed`.
- `epistemic` — эпистемический статус узла (метка доверия, не стена).
- `derived` (bool) — маркер «производное»; включает правило «проекция-первой».
- `validFrom / validUntil` (bitemporal) — интервал действительности факта (Ц-2).
- `confidence` (калибруемый) — степень уверенности (требует Ц-3 Доверие).
- `language/locale` — язык/локаль содержимого (Ц-1 читаемость).
- `timezone` — таймзона привязки времени узла.
- `retention/TTL` — настраиваемый срок хранения/забывания (Ц-4).
- `consent` — согласие НА УЗЛЕ (не только на ребре); согласие часто про сам узел.
- `acl-to-agents` — каким агентам доступен узел (отделено от `scope` «кому из людей»).
- **`scope` дефолт = `private` при создании узла** — без явного значения видимость закрыта (анти-утечка).

## cell (memory-unit)
Базовая единица памяти — атом графа. Смысл: «что-то, что можно вспомнить/сослаться». Паспорт: обычный
+ `salience` (для витальности). Payload: свободная форма (текст/структура), не типизирован жёстко.

## document
Файл = узел (msg 141), НЕ отдельная БД и не центр. Смысл: контент как payload, метаданные как паспорт.
Паспорт: + `mime`, `sourcePath`. Payload: содержимое файла или ссылка на blob-хранилище. Связи: `member-of`
(категория), `provenance`, `variant-of`.

## container (папка-грань)
Узел-контейнер (совет Fable: «папка = узел особого типа», не новый примитив). Смысл: группировка/иерархия.
Паспорт: + `containerKind` (folder/category/pool). Payload: обычно пуст или policy-конфиг контейнера.
Дети — через `member-of` (thin-ref).

## concept
Узел-идея/понятие, 1:1 с `Concept` агентов (рекурсия/type/scope — маппинг открыт как Н-2). Смысл: смысловая
единица выше «сырой» ячейки. Паспорт: + `conceptKind`. Payload: определение/описание.

## event
Эпизод во времени (встреча, действие, наблюдение). Смысл: якорь эпизодической памяти. Паспорт: + `occurredAt`
(bitemporal — В2). Payload: детали события. Часто источник `assertion-edge` (caused, derived-from).
Пометка: `validFrom` в будущем → **будущие события / календарь** (расписание — ядро агрегатора, §5).

## profile-ref
Ссылка на человека/сущность вне графа (или корневой профиль — FQ18 «мета-узел Самости», корневой экземпляр
профиля со стабильным id). Смысл: «о ком/для кого». Паспорт: + `refKind` (person/self/org). Payload: минимален,
детали живут в domain 02 или внешней системе.

## policy-node
policy-as-data узел — одна ценность/правило, НЕ единый гигант (см. `policy.md`). Паспорт: + `authority`
(`constitutional | cell`, FQ03), `appliesTo` (node-type/edge-type паттерн). Payload: правило в декларативной
форме (условие → действие движка).

## view-def / flow-def
Декларативный рецепт обхода графа (вид/поток), НЕ хранит данные — производное всегда вид, не поле (R-B).
Паспорт: + `viewKind`. Payload: параметры обхода (фильтр, глубина, направление рёбер).

## VariantGroup
Узел группы вариантов, `mode: xor|or|and` (R-A). Смысл: держит «оба варианта» живыми одновременно; выбор —
ребро `chosen-in`, не удаление. Паспорт: + `mode`. Payload: пуст — вся семантика в рёбрах-членах.

## journal-entry (Observation/WorkLog)
Запись в append-only журнале — общий позвоночник (агенты, telegram, память, петли пишут сюда же). Смысл:
метаданные/операции вечны, payload заменяем (tombstone), bitemporal `as-of` бесплатно (R-C). Паспорт: +
`entryKind`, `actor`. Payload: содержимое наблюдения/лога.

## SEED-кандидаты node-type (§5, ждут ратификации владельца)
- **person-relationship** — отношение между людьми (семья/друг/коллега), CRM-грань жизни; класс сейчас отсутствует.
- **open-loop / pending** — открытая петля / незакрытое дело (Status-кандидат).
