# 🟦 Узел (node)  ← P4

## Что это / что хранит
Базовая единица субстрата. Физически = строка в `nodes`. Хранит **тонкий паспорт** (дёшево сканируется:
`canonicalId`, `node_type`, `scope`, `status`, время, provenance, derived, +поля DL-12) и **payload**
(вскрывается редко: сам контент/JSON). Тип — ОДИН на узел (`node_type`), не мульти-тип.

## Зачем (для кого)
Владелец назвал **три аудитории**, ради которых узел существует и которые надо явно разделять:
- **агент** — субстрат для работы ИИ (читает/пишет);
- **пользователь(и)** — возможно НЕ один человек (отдельная грань — мульти-user);
- **понимание** — узел должен быть читаем/само-описателен, чтобы БД «знала», что это.
