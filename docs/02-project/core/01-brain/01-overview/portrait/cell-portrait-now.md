## 1. Что ячейка ЕСТЬ сейчас (одно определение)

**Единица памяти — не тип узла, а РОЛЬ узла (или ребра): маленький суверенный АКТОР, который несёт данные + декларацию о том, как с ним обращаться, и продаётся с «контрактом повторного входа» — гарантией, что будущий читатель (часто ты сам как незнакомец) сможет её НАЙТИ, ОЦЕНИТЬ не вскрывая, ДОВЕРИТЬСЯ в меру, ВПИСАТЬ под своим углом — и что след использования вернётся в неё саму.**

Три несущих утверждения в этом определении:

- **Роль узла/ребра, не отдельная сущность.** На уровне данных память = обычные узлы (0 новых обязательных полей — ADR-0002 уже даёт контракт). Своя природа памяти живёт **не в узле, а в ЦИКЛЕ** над узлами. Инсайт «A→B» по природе — ребро; ребро-утверждение повышено до гражданина 1-го класса (свой тонкий паспорт).
- **Контракт повторного входа.** Память замыкается на использование: без обратной петли (след → confidence) это каталог, а не память. «Память — глагол, не существительное»; «письмо незнакомцу, которым окажешься ты сам» (компакт-тревога — ровно это). Уточнение Fable: не письмо, а **ТРЕД** — каждое использование = реплика в разговоре единицы с будущими собой.
- **Актор со своей политикой.** Единица носит СВОЮ политику жизни (policy-as-data): salience, видимость, TTL, рецепт доступа. Движок не командует памятью — он **оказывает ей услуги**, которые она запрашивает своей политикой. Но актор суверенен НЕ абсолютно: над политикой ячейки стоит **КОНСТИТУЦИЯ** — набор инвариантов (напр. «согласие референта нельзя переопределить политикой владельца»; «единый порог доступа против зомби-памяти»).

Формула-ядро (через информацию, не ценности): *информация рождается многомерной, а каждый акт записи и чтения — одномерен.* Единица существует, чтобы **одна запись обслуживала много будущих вопросов, под которые не писалась.** Волна/частица: частица = что хранится (паспорт+payload, честный коллапс одной проекции); волна = чем узел ЯВЛЯЕТСЯ через рёбра (зерно — свойство ВЗГЛЯДА, не вещи); измерение = агент втягивает узел, волна коллапсирует в грань под вопрос.

## 2. Параметры / грани — что несёт единица

Читается без вскрытия payload. Ратифицированное ядро — из ADR-0002 (9 обяз. + 2 опц.); salience/policy/referent/bitemporal — проектируемые надстройки (statuses указаны). «Обяз.» = обязательность на своём уровне.

### Паспорт узла (ратифицирован, ADR-0002)

| Грань | Что задаёт | Обяз./опц. |
|---|---|---|
| `id` (ULID) | стабильный ключ связей (операция «сослаться»); ≠ имя файла/title | **обязательна** |
| `type` (string) | как разместить/вскрыть; открытый реестр, правила → узел-ТИП | **обязательна** |
| `schema` (`type@version`) | какой валидатор; миграции | **обязательна** |
| `created` / `updated` (iso) | датировать; `stale` выводит движок из `updated` | **обязательны** |
| `epistemic` (enum) | доверие к содержимому: `draft\|proposal\|hypothesis\|fact\|archived` | **обязательна** |
| `sensitivity` (enum) | приватность/ACL — ИИ знает без вскрытия payload | **обязательна** |
| `source` (enum) | `human\|agent\|system\|import` — происхождение | **обязательна** |
| `principal` (id) | арендатор; multi-tenant/маркетплейс заблокированы без него | **обязательна** |
| `level?` (enum) | `why\|what\|how\|data`; тег-подсказка, движок выводит дефолт-от-типа; линза побеждает при конфликте (приор, не контракт) | опциональна |
| `canonical_id?` (id) | дедуп + инвариант «та же память» во всех проекциях; движок проставляет | опциональна |

### Паспорт ребра

| Грань | Что задаёт | Обяз./опц. |
|---|---|---|
| `to` (id\|url) | цель связи (url → внешняя, `href:true`) | **обязательна** |
| `rel` (string) | тип связи: `child-of\|involves\|supersedes\|variant-of\|facet-of\|…` | **обязательна** |
| `home` (bool) | ровно одно `true` на ноду; спина каскада контекста | обязательна на рёбрах принадлежности |
| `provenance` (enum) | `manual\|auto\|inferred` — manual=файл-истина | **обязательна** |
| `priority` (number) | важность В КОНТЕКСТЕ этого родителя (N-041), дефолт 0; ≠ confidence; семантику задаёт линза-сортировщик | опциональна |
| `sort` / `cascade` / `cascade_order` / `derived` | вторичная сортировка; участие в наследовании; порядок слияния; вывел ли ребро движок | опциональны |

### Паспорт ребра-утверждения (В4, повышение до 1-го класса — проектируется)

| Грань | Что задаёт | Обяз./опц. |
|---|---|---|
| `confidence` | насколько инсайт «A→B» правда (≠ priority) | обяз. для рёбер-утверждений |
| `provenance (wasDerivedWith)` | из чего выведено (RDF-star-стиль, метаданные НА связи) | обяз. |
| `valid-time` + `epistemic` | когда верно / статус доверия | обяз. |
| — структурные рёбра (home, facet-of) паспорт НЕ несут | | — |

### Salience / метаболизм (проектируется, В1)

| Грань | Что задаёт | Обяз./опц. |
|---|---|---|
| salience-параметры | вес всплытия (push/«запах»); параметры В ЯЧЕЙКЕ, формулу считает движок; бюджет внимания — инвариант (Г15) | опциональны (класс-зависимы) |
| волатильность / время-истинности | как быстро протухает → запускает Забыть (Г8) | опциональны |
| ставки / цена ошибки | глубина «Оценить»; управляет верификацией | опциональны |
| фаза видимости / грань фокуса | плавная потеря фокуса (не бинарно видно/нет); ячейка сама настраивает 2+ фазы | опциональны |
| класс температуры | live (метаболизируется) vs cold (фильтруется, не забывается) — разные правила | опциональна |

### Policy / доступ / referent / bitemporal (проектируется)

| Грань | Что задаёт | Обяз./опц. |
|---|---|---|
| policy (policy-as-data) | видимость, TTL, рецепт доступа, материализация — носится в ячейке | опциональна (дефолт от класса) |
| линза-политика (hard-ABAC/soft) | кому какую грань раскрыть (id/title/payload); enforce-point `promotion\|valve\|disclosure` | control-plane узел |
| `referent` (Fable, зарезервировать СЕЙЧАС) | о ком/о чём единица — отдельно от `owner`/`author`; пусто = о мире/себе (99%), непусто = третье лицо | опциональна, но заложить с 1-й итерации |
| bitemporal (`valid-time` + `transaction-time`, В2) | `canonical_id` стабилен; изменение = новая версия; читается «as-of T» (аудит Г9); Забыть = закрыть transaction-time | механика метаболизма |
| `pending` / открытая петля (Fable, кандидат) | ждёт ли единица завершения (≠ confidence, ≠ salience) | кандидат-статус, не решён |

## 3. Способности — что единица УМЕЕТ

**Цикл — 6 глаголов в 3 фазах** (это и есть «своя природа», живущая в цикле, а не в узле):

- **Фаза A — Вход:** 1. **Записать** — честный коллапс многомерного в одну проекцию + декларация проекции в паспорте.
- **Фаза B — Доступ:** 2. **Найти** — двумя путями: pull (по запросу) и push (по резонансу/«запаху»). 3. **Оценить** — послойно, не вскрывая целиком: паспорт → title/description → payload; глубину задают ставки. 4. **Действовать·Подтвердить** — агент применил узел → результат вернулся как confidence-сигнал (Act без следа = просто чтение).
- **Фаза C — Метаболизм:** 5. **Переработать** — консолидация/дедуп/реконсолидация (меняет СОДЕРЖИМОЕ, риск искажения; откат = версия/форк). 6. **Забыть** — меняет ДОСТУПНОСТЬ, не содержимое (откат = восстановление доступа + гарантия невлияния). Забыть отделено от Переработать намеренно — разные контракты отката. Фаза C — то, что отличает память от лога и лечит компакт-тревогу.

**Прочие способности единицы:**

- **Читаться на любом зуме одним правилом (Г6, самоподобие):** снаружи дёшево (паспорт), внутри дорого (payload); группа/атом/ребро — один контракт. Оценка паспорта без вскрытия = частичное измерение почти бесплатно → «память — то, что можно оценить до покупки».
- **Всплывать по salience (волна/«запах»):** частица пахнет по осям; когда контекст резонирует — всплывает сама (ассоциативный push-триггер).
- **Нести свою политику жизни:** видимость, распад, всплытие, TTL, рецепт доступа — автономия без внешней схемы (policy-as-data).
- **Быть вариантом/веткой (Г28):** веер от якоря, переключаемая ветка планирования; каждый вариант = независимая ячейка (`variant-of`), возможно не связанная с другими вариантами. Форк — только для намеренных вариантов, НЕ для эволюции (эволюция = bitemporal).
- **Быть прокси на внешний источник (Г29/Г33/Г34):** паспорт локально, payload по API + кэш с жёстким удалением; хранит инструкцию КАК себя достать; материализуема на выбор (live/кэш/копия по политике).
- **Быть ребром-инсайтом как памятью (В4):** связь «A→B» — полноценная единица со своим паспортом; глаголы Подтвердить и Забыть применимы к рёбрам (устаревший инсайт опровергается и забывается).
- **Показывать себя по-разному разным ролям (Г31):** field/row-level, «свой мир» проекта, capability-шеринг.
- **Наследоваться/переиспользоваться (Г32):** шаблон → экземпляр.
- **Коллапсировать под ЛИНЗУ:** линза (control-plane) проецирует подграф в грань под вопрос/наблюдателя — уровень абстракции вычисляется из топологии, а не из поля. (Fable усиливает: линза сама должна быть сохранимой единицей памяти — см. §5.)

## 4. Семь ценностей (ревизия Fable — актуальный набор)

Каждая проходит тест несводимости: убери любую — теряется класс целей, невыразимый остальными.

- **Ц-1 · Читаемость (Legibility)** — единица отдаёт нужную грань нужному читателю по нужной цене, не вскрываясь целиком (поглощает Прозрачность + Полисемию + температуру).
- **Ц-2 · Тождество (Identity)** — граница «та же память / другая»; условие осмысленности метаболизма и слияния конфликтов (новое у Fable; закрывает выпавший конфликт-протокол).
- **Ц-3 · Доверие (Trust)** — насколько это правда: калибруется использованием, несёт провенанс, защищено от отравления.
- **Ц-4 · Витальность (Metabolism)** — единица становится другой во времени, не теряя Тождества (очищена: температура вынесена в Читаемость).
- **Ц-5 · Суверенность (Sovereignty)** — носит СВОЮ политику/рецепт доступа → живёт и переносится в любой движок.
- **Ц-6 · Реляционность (Relationality)** — связь/вариант/наследование сами память, а не служебная нить.
- **Ц-7 · Согласие (Consent)** — кому показать и ЧЬЯ она; единственная ось «за/для кого» (сюда ушёл референт и Г20).

> Отличие от набора Opus: Прозрачность+Полисемия → слиты в Читаемость; введено Тождество; Витальность очищена; «Значимость-для-человека» (Г38) отклонена как ценность узла — переопределена как свойство РЕБРА человек→единица.

## 5. ОГРАНИЧЕНИЯ и открытые места (честно)

Что НЕ решено / не покрыто на сегодня. Часть — реальные death-by-design.

| Ограничение | Почему открыто | Когда решать |
|---|---|---|
| **Конфликт-протокол Тождества** — как разрешаются две частицы об одном факте с разными значениями | В L0 прямо помечено «не покрыто»; Fable выделил Тождество (Ц-2) именно чтобы этот протокол перестал выпадать, но сам протокол не спроектирован | L2, сразу после ратификации Ц-2 |
| **Зомби-память** — техническая гарантия, что «забытая» единица не всплывает по эмбеддингам/копиям/др. каналу | Забыть меняет доступность, не содержимое; нет механизма единого порога доступа для ВСЕХ каналов извлечения | L2; кандидат в конституционный инвариант |
| **bitemporal ↔ право на забвение (death-by-design)** | В2 задал bitemporal «забыть ≠ удалить»; но право референта на забвение требует НАСТОЯЩЕГО удаления. Прямой конфликт, замечен только ревизией Fable | заложить hard-erase-примитив СЕЙЧАС; механизм — к маркетплейсу |
| **Кто крутит фазу C (метаболизм)** — агент-садовник vs фоновый движок | L0 «не покрыто»; Fable развёл: движок синхронный/глупый (4 примитива), консолидация/забывание — асинхронные «агенты-садовники». Разделение предложено, не ратифицировано | engine-spec / L2 |
| **Материализация проекций** — на лету vs предвычисление (CQRS-read) | L0 «не покрыто»; влияет на стоимость Полисемии/Читаемости | engine-spec |
| **Слепой угол референта (Г20)** — «чья память, когда предмет — третье лицо» | ось субъектности ортогональна всему; prior-art не дал механизма; взрывоопасно в момент маркетплейса/plug-in | грань `referent` + hard-erase заложить СЕЙЧАС (ретрофит невозможен); механизм согласия — позже |
| **Механика «волны» / линзы** — волна осталась метафорой без механизма | всё спроектированное (паспорт, salience, bitemporal) — про частицу; волна («зерно = свойство взгляда») не получила ни одного механизма; Fable: волна живёт в ЛИНЗЕ, линза должна стать сохранимой единицей — не решено | L2 (главный оригинальный кусок) |
| **Эмердженс (рождение смысла)** — модель знает распад, но не порождение | весь метаболизм термодинамика вниз; reflection взят как «сжатие», не как «возникновение»; выведенное знание пока второсортно, Fable предлагает перевернуть | L2; философский приоритет открыт |
| **`pending` / открытые петли** — статус «единица ждёт завершения» | компакт-тревога про незакрытые дела, не только про потерянные записки; ≠ confidence, ≠ salience; кандидат-сущность, риск переусложнения | решить на ратификации ценностей (FQ6) |
| **Конституция над политикой ячейки** — уровень инвариантов против лжи ячейки о себе и конфликта политик | Fable ввёл трёхуровневый хребет (конституция > политика ячейки > примитивы движка); принят как направление, не оформлен (возможен ADR «Конституция памяти») | L2 / ADR |
| **FQ1-FQ8 Fable + VQ1-VQ4 Opus без ответа владельца** | набор 7 ценностей, хребет, линза, эмердженс, pending, референт+hard-erase, Г38 — ждут суждения владельца | следующий раунд диалога |

> **死by-design (приоритет):** (1) bitemporal ↔ право на забвение; (2) зомби-память без единого порога; (3) референт заложить сейчас (ретрофит невозможен). Остальное — проектная работа L2, не мины.
