# 💎 Rejected gems (preserved — LOSE-NOTHING)

> **status: preserved — зёрна, которые рассматривались, но НЕ выбраны на этой арке. Сохраняем, чтобы не

## 1. Предрассаженные red/blue адверсариальные роли
Идея: держать в оркестрации ПОСТОЯННЫЕ роли «красный» (атакует) и «синий» (защищает) как заранее
посаженных агентов на каждую развилку. **Не выбрано:** метод уже несёт адверсариал через `critic` +
детектор расхождения линз (закон 8) по требованию; постоянные предрассаженные роли = плодить агентов ради
агентов (против multi-lens-verification §границы). Сохранено как возможный паттерн для тяжёлых развилок.

## 2. «Биржа идей» — леджер сам генерирует следующий вопрос
Идея: creative-ledger не просто копит зёрна, а САМ порождает свой следующий вопрос (self-generating idea
exchange): периодический синтез-проход рождает новую развилку автоматически. **Не выбрано сейчас:** метод
(закон 8в) велит РОУТИТЬ зёрна в существующий каталог направлений, не плодить параллельный
само-генерящий механизм. Идея сохранена — созвучна «перевариванию» леджера (`seed → candidate → direction`),
может вырасти позже, но не мичим отдельный движок.

## 3. Пять творческих образов линзы — непроверенный брейншторм
Из `DRAFT-creative-scan.md §3`: (1) живой пере-крой единицы на лету; (2) один паттерн → N визуализаций;
(3) обыгрывание ограничения как визуальной грамматики (`cold` мельче/бледнее, scope рамкой, пустая грань
как «gap»-плитка); (4) линза-как-единица / маркетплейс видов; (5) агент лепит одноразовый вид под запрос.
**Статус:** помечены как brainstorm/НЕПРОВЕРЕНО. Несущее зерно (линза=данные) вынесено в
`./lens-as-data-candidate.idea.md`; остальные образы сохранены здесь как сырьё, НЕ как обещания —
проверяются только прибором на реальных данных.

## 4. Гипотеза rental-chat как стресс-тест гибкости
Из `DRAFT-creative-scan.md §6`: глубокая аналитика Telegram-чата аренды (сообщение/договор/машина/клиент/
платёж/инцидент вперемешку) — готовый стресс-тест гибкой модели на реальном шуме. **Не выбрано как ход
сейчас:** данные ещё не пришли (F-D gated), строить под неё заранее нельзя. Сохранено как первый кандидат
на проверку прибором, когда владелец даст путь к данным.
