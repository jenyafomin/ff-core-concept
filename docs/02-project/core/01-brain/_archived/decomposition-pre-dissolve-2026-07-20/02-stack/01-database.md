# 🗄️ База данных  ← P6

## Что это / решаем
Физическое хранилище субстрата (`nodes`/`edges` + журнал). DL-15 переоткрыт.

## Критерий владельца (сменился)
**Не идеологический, а инженерный:** «не принципиально, какая». Главное — **поднимается на Docker** +
хорошее **переносимое** решение. Лично использовал **Mongo** и **Postgres**. Графовая БД — тоже кандидат.

## Важно: порядок
Выбор БД — **ПОСЛЕ** того, как форма модели (группа 01-model) пережила критику. Модель диктует БД, не
наоборот. Вход в этот поток = готовые карточки узел/ребро/слои/policy/категории.

## Открыто
- Postgres (+ расширения) vs документная (Mongo) vs нативно-графовая — под наши цикличные многоуровневые связи.
- Переносимость модели/типов **FF ↔ agents-manager** (R7): драйвер под TS/Node без дублирования.
- Erase-реализуемость (crypto-shredding в payload) на выбранной БД.
