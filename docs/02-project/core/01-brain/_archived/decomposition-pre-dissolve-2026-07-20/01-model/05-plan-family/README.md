# 📋 05-plan-family — generic СЕМЬЯ plan (база)

> **Переехало 2026-07-19** из `01-model/plan/README.md` (generic-материал плана). Это **базовый тип
> `plan` как СЕМЕЙСТВО**: один базовый узел + механизм **вариаций / подтипов / апгрейд-линз**. Конкретные
> plan-kinds оркестрации (спец-план под state) наследуют отсюда и живут в модуле
> `02-agents/01-orchestration/02-plan/`. ⚠️ **`loop` НЕ входит в семью plan** — это свой `node_type`,
> который *композирует* план (has-a через переиспользуемые рёбра), а не наследует его (см. ADR разв.3).
> Планы и задачи — тоже дерево, раскладывается в себя. Контекст указывается на любом уровне.
> Цель слоя: держать «что нужно сделать, поэтапно» так, чтобы агент шёл по шагам, а не искал.

## Механизм вариаций (база семьи)
- **Базовый тип** `plan` — узел с полями (`status · topic · target_state · parent_plan · owner · date`, R4).
- **Вариация / подтип** — специализация базы под задачу (напр. `state-plan`). ⚠️ `loop` — **НЕ** вариация
  этой семьи: свой `node_type`, композирует план (см. `../../../../02-agents/01-orchestration/decisions/` ADR разв.3).
- **Апгрейд-линза** — проекция, добавляющая грани поверх базового плана без форка типа.
- Конкретные грани над этой семьёй → модуль `../../../../02-agents/01-orchestration/02-plan/`.

## Уровни (дерево раскладывается в себя)
```
GLOBAL (ключевые планы на проект)
└── MODULE-план (у каждого примитива/механизма — свой, в его папке: <дом>/plan/ или в GLOBAL)
    └── ЗАДАЧА (плановый пункт)
        └── ПОД-ЗАДАЧА / чек-лист
            └── (контекст: ссылки на узлы/файлы, которые смотреть)
```
- Узел дерева = **план** ИЛИ **задача** (одно перетекает в другое по мере детализации).
- На каждом узле можно указать **контекст** (что читать) и **статус**.
- Ключевые планы на проект живут ГЛОБАЛЬНО (`GLOBAL.md`); детальные — в доме своего модуля.

## Процесс качества (как взаимодействуем, чтобы уровень держать)
Не «написал и всё» — цикл: **перепроверка · дополнительные взгляды (критик/совет) · доработка
документации деталями · подготовка к ТЗ (техзаданию) · придумывание инфра-механизмов**. Дорогие
развилки — через `fable-advisor`/`ask-council`; глубина масштабируется под сложность.
