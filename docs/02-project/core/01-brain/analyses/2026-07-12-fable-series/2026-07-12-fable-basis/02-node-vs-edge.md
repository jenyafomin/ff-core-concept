# К-2 · Связь — отдельная сущность или поле узла?

**Вопрос (центр сессии):** узел и связь похожи; связь — отдельная хранимая сущность или поле на узле?

**Вывод Fable — критерий = АДРЕСУЕМОСТЬ.** Нужно ли когда-либо указать НА само отношение (оспорить,
забыть, дать/отозвать согласие, спросить «кто утверждает?»)?
- **Да → `assertion-edge`**: сущность + `id` + узкий паспорт + тип. Пример: инсайт «A caused B» (свой автор,
  провенанс, жизнь; forgetting стирает ЕГО, не трогая A/B; consent-taint течёт через него).
- **Нет → `thin-ref`**: поле узла, без паспорта, судьба = судьба узла. Пример: `home`, `facet-of`.

**Одна концепция «связь», два класса хранения** (это доведение В4 до правила).
