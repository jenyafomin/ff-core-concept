# Р-3 · Карта граней ребра: NOW vs LATER — ✅ решено по каждой

**Вопрос:** для 5 граней ребра — закладывать в контракт СЕЙЧАС или отложить? Линейка — retrofit-cost
(раздел «Заложить СЕЙЧАС» в `../INDEX.md`), НЕ FQ23.

| Грань | Вердикт | Обоснование (retrofit-cost / гибкость) |
|---|---|---|
| **Типизированное ребро** | 🔴 **NOW** — обязательное поле, открытый реестр, малый seed | Нетипизированные рёбра, накопленные за месяцы, ретрофитить = ручная разметка всего графа. Открытый реестр (не enum) — вся гибкость типов бесплатно. |
| **Ребро→поток** | 🟢 **LATER** | Поток = проекция обхода по типу ребра. Раз тип заложен NOW — поток строится в любой момент, хранить нечего, ретрофит ~0. |
| **Реактивный триггер** | 🟡 **слот NOW, механика LATER** | В контракте — зарезервированное nullable-поле `trigger` в паспорте assertion-edge (имя + смысл, без исполнения). Резервирование бесплатно; механика — read-time дефолт по SYNTHESIS-2026-07-07, push — не сейчас. |
| **Кросс-узловая семантика** | ✅ **уже NOW** (это В4) | Класс `assertion-edge` и ЕСТЬ носитель того, чего одна нода знать не может. Ничего добавлять не надо — грань закрыта самим базисом. |
| **Рёбра-над-папками** | 🟡 **адресуемость NOW, механика LATER** | Закладываем не фичу, а инвариант: папка = узел типа `container` с `canonicalId` → любое ребро УЖЕ может указывать на неё без спец-кейса «endpoint-папка». Если этого не заложить, потом появится второй вид endpoint'а — дорогой ретрофит. Сама механика (member-of, оркестрация) — позже. |
| **Flow-gated lifecycle** (auto-close через поток) | 🟢 **LATER** | Это policy-as-data грань паспорта; паспорт расширяем по построению → ретрофит дёшев. Плюс auto-close обходит согласие (Ц-7) — рано. Когда придёт: включать ТОЛЬКО для error-prone источников (агент/импорт), не для человека. |

**Итог NOW-контракта ребра (минимум):** `id` (для assertion-edge) · `type` (реестр) · `from`/`to` =
`canonicalId` (узел ИЛИ container-узел) · класс (`assertion`/`thin-ref`) · паспорт В4 (+слот `trigger`) ·
DAG-check на derived-типах.

**Статус:** ✅ решено.
