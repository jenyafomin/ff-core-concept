# 🧩 ПОЛНОТА + ЕДИНАЯ МОДЕЛЬ (2026-07-12) — тип/категория/тег/проекция + что упущено

> Свод: резкий разрез Fable по несущему узлу + 3 линзы «что не хватает». Не пересказ — стыковка к решениям.

## 1. Единая модель (Fable) — 0 новых примитивов
| Понятие | Чем является | Правило «почему» |
|---|---|---|
| **Тип** | паспорт-поле `node_type` (реестр M-G3, гейт) | неизменно без изменения самой вещи → тип |
| **Категория** | узел `container` + ребро членства | чей-то АКТ отнесения |
| **Тег** | та же категория с ослабленной policy | НЕ третий механизм |
| **Проекция** | `view-def` (вычислимое членство, не материализуется) | вычислимо → вид, не поле |
| **Роль со своим состоянием** | `aspect`-узел + ребро `facet-of` | есть собственное состояние → отдельный узел-грань |

**🔴 Жёсткое правило: у ячейки ОДИН `node_type`. Мульти-`node_type` запрещён** — самая дорогая ошибка развилки.
«Много граней» достигается членством/аспектами/видами, НЕ несколькими типами на одном узле.

## 2. Вердикт по домену 03 (Fable): НЕ домен
Категории = **грань домена 01** + policy-группа «taxonomy» в M-G3. У категорий нет собственного читателя →
«домен без читателя = папка с амбициями». **M-P5 остаётся модулем-view.** Закрывает форк домена 03.

## 3. Самое острое упущение (Fable) — «кто навесил»
`member-of` помечен thin-ref, но агентская категоризация — **оспоримый акт с автором** → дыра в Ц-7 (Согласие).
**Расщепить ребро:** `member-of` (thin-ref, ставит владелец) vs **`categorized-as`** (assertion + автор + confirms-петля FQ19).
Это же чинит G3-находку «нет `actor`/consent на членстве».
