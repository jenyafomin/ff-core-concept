## Правила
- Один снапшот = папка `YYYY-MM-DD-<короткое-имя>/` (файлы + подпапки как есть).
- Аналитика **иммутабельна по факту** — не переписываем задним числом; новый разбор = новая дата.
- На снапшоты **ссылаются из overview** (как на обоснование), контент в overview не дублируем.
