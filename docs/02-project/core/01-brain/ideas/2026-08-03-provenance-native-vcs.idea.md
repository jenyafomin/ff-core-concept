# Provenance-native VCS — «гит для агентов» внутри brain (хранить ПОЧЕМУ, а не только ЧТО)

> **Статус: идея-ДОПОЛНЕНИЕ.** НЕ входит в печать корня. Заведена, чтобы не потерялась. (Владелец, 2026-08-03.)

## Идея владельца (сырьё)
- В БД в дальнейшем будем хранить и **сам код** — возможно, разбивая его на части/механизмы/функции как узлы.
- **Ключевая цель:** видеть **последовательные размышления/решения**, которые были ПРИЧИНОЙ изменений.
- **Наблюдение:** git создавался **для людей** — это список диффов в коммите. Систему теперь строят **агенты**;
  им нужен не «список изменений», а связь `изменение ← вызвано → решение/анализ`. Тогда «гит» теоретически
  становится полноценной **моделью** (граф причин), а не журналом диффов.
- **Прикол:** в нашей БД мы можем сами дополнить это «гит-системой», где всё описано и живёт в своём месте.

## Почему это НЕ новая машина, а родная форма brain
Субстрат brain уже имеет ровно те кубики, из которых это собирается:
- **код = ещё один тип узла** (Вещь/unit), делимый на под-узлы (механизм/функция) — как любой контент.
- **изменение = акт** в append-only журнале (у нас он и так append-only-forward — см. печать корня, Дыра 3a).
- **решение/анализ = узел**, связанный с актом ребром-причиной (`caused-by` / `grounds`).
- **«последовательные размышления» = цепочка актов+рёбер** — это буквально то, что субстрат хранит по природе.

Вывод: интуиция владельца снова совпала с дизайном — **brain по своей природе есть «гит, хранящий ПОЧЕМУ».**
Обычный git — проекция (линза) «только ЧТО» поверх того же журнала.

## Связь с печатью корня (важно — это делает идею возможной)
Провенанс-слой садится ПОВЕРХ того же журнала, что мы сейчас печатаем. Значит правильная печать = предпосылка:
- **append-only-forward** (Дыра 3a) — без него история причин переписывается → провенанс лжёт.
- **split мета/payload** (риск V7) — код/решение стираемы, а факт-акт «было изменение» неизменяем.
- **one-home** (Дыра 3c) — у каждого изменения один дом-акт, иначе двойной учёт причин.
Т.е. чинить фундамент надо всё равно — а эта идея растёт из него бесплатно, позже.
