# Р-6 · Как двигаться дальше — ✅ вариант (A) + микро-(B) на ревью

**Вопрос:** (A) исполнить направления дешёвыми агентами · (B) точечный до-заход Fable · (C) полный
консилиум Fable?

**Вердикт: (A) — волну 1 исполняют дешёвые агенты; Fable оставить ОДИН микро-заход (B) на ревью
результата.** Полный консилиум (C) — НЕТ: базис сошёлся, спорных развилок не осталось, консилиум жёг бы
бюджет на подтверждение уже решённого.

**Раздача волны 1 (параллельно):**
| Направление | Агент | Артефакт |
|---|---|---|
| Н-1 контракт ребра v1 (+ правило промоции из Р-1, + NOW-минимум из Р-3) | system-architect (opus) | кандидат ADR-Edge |
| Н-4 спека `canonicalId` (формат · ref vs path · rename · container-узлы) | analyst (sonnet) | addendum к scopes-and-identity |
| Н-6 гейт retrofit-cost как 3 теста | critic (sonnet) | мини-правило |

Затем **микро-(B):** Fable читает ТОЛЬКО кандидат ADR-Edge (один файл) и даёт вердикт годен/правки —
это самая дорогая точка ошибки, ревью сильнейшей моделью окупается. Волна 2 (Н-2, Н-3) — после,
обычными агентами, Fable не нужен.

**Обоснование:** решения этой сессии закрыли все развилки уровня «архитектура»; осталась работа уровня
«спецификация» — она по определению для дешёвых моделей. Гибкость процесса = держать Fable на
развилках, не на прописях.

**Статус:** ✅ решено.
