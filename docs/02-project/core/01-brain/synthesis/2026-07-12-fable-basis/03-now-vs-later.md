# К-3 · Что заложить СЕЙЧАС vs позже (грани ребра)

**Вопрос:** какие грани ребра — ретрофит невозможен (закладываем сейчас), какие можно отложить?

| Грань | Вердикт |
|---|---|
| **Тип ребра** (открытый реестр, малый seed) | 🔴 СЕЙЧАС |
| **Endpoint = `canonicalId`, НИКОГДА путь** | 🔴 СЕЙЧАС |
| **DAG-инвариант** на derived/cascade-рёбрах | 🔴 СЕЙЧАС |
| Кросс-узловая семантика (паспорт assertion-edge) | ✅ уже В4 |
| Реактивный триггер | 🟡 слот-поле сейчас, механика позже (read-time) |
| Поток / flow-gated auto-close | 🟢 ПОЗЖЕ (проекция; auto-close обходит согласие Ц-7) |
| Папка-как-узел | 🟢 ПОЗЖЕ, дёшево |

**Папка-оркестрация = узел особого типа** (не слой scope, не отдельная инфра-сущность).
