# К-1 · Из скольких примитивов состоит базис памяти?

**Вопрос:** нода → +связь → есть ли третье измерение (папка-грань / оркестрация / поток)?

**Вывод Fable:** базис = **2 хранимых примитива (узел + связь) + 1 интерпретатор**. Третьего примитива НЕТ.
- **Папка-грань** = узел особого типа (`container`) + рёбра `member-of` → «рёбра-над-папками» схлопываются
  в обычные рёбра. Совпадает 1:1 с сущностью `Concept` у агентов.
- **Оркестрация · поток · реактивность · память-как-процесс** = слой-интерпретатор над теми же 2 таблицами.
- «Следующее измерение» = **время/процесс**, уже заложено (bitemporal В2 + движок). Модель: точка → линия → обход.

**Статус:** 💬 на проверку владельцу. Пересмотр — только если найдётся «вещь, на которую надо сослаться,
но которая не выражается ни узлом, ни ребром» (см. эпизод «ребро над папками», карточка К-6).
