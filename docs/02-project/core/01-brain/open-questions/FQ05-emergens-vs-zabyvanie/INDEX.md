# FQ5 — Эмердженс в цикле метаболизма (не «важнее» забывания)

> Родитель: [../INDEX.md](../INDEX.md) · Слой L0 · ⚠️ уточняется

## 1. Вопрос

Исходная формулировка ставила ложную дихотомию («эмердженс важнее забывания»). Реальных вопроса
два, слитых в один:
**(а)** эмердженс и забывание в оппозиции, где один «важнее» другого? — нет, снимается явно ниже;
**(б)** сделать эмердженс (рождение новых узлов/рёбер-инсайтов из связей) полноценной фазой цикла
метаболизма — как отдельный глагол наравне с «Переработать»/«Забыть», или подвид «Переработать»?

## 2. Рекомендация

**Да по (б)**, при снятом (а): в `L0-memory-unit.md` (фаза C «Метаболизм», строка 49) забывание и
переработка уже сосуществуют как равноправные глаголы одной фазы — конкуренции за «более важный»
статус там нет и не нужно для ответа на (б). Эмердженс заслуживает явного места в цикле, но как
**равноправный** глагол/подвид, не иерархически более важный. Термин «эмердженс» сейчас не назван
среди 6 канонических глаголов L0 — значит формализация фазы — это НОВОЕ архитектурное решение
(7-й глагол? подвид «Переработать»?), не фиксация уже существующего механизма.

## 3. Выбор / что делаем

⚠️ **Не закрывать статусом «✅ очевидно-да» до выполнения плана:**
1. Дописать правило наследования `hard-erase` эмерджентными узлами/рёбрами: если эмерджентный
   узел/ребро выведен из данных о третьем лице (referent, FQ7) и источник впоследствии стирается
   по требованию референта — наследует ли инсайт стирание автоматически, или живёт независимо? Без
   этого правила возникает риск «зомби-памяти» (угроза, которую L0 явно называет для фазы «Забыть»,
   строки 49/51) — эмерджентный инсайт может пережить референта, потребовавшего удаление источника.
   Место правила — здесь и/или в FQ7 как перекрёстная связь.
2. Явно назвать место эмердженса в цикле L0 (новый 7-й глагол vs подвид «Переработать») — сейчас
   термин не входит в 6 канонических глаголов.
3. Добавить обратные ссылки из `V4-vitalnost.md` (эмердженс=ребро-инсайт, Реляционность) и из
   `L0-memory-unit.md` на этот файл — сейчас связь идёт только в одну сторону.

## Возражения / что может сломать

- Стилман 1: забывание и эмердженс НЕ в оппозиции — оба помещаются в фазу C как разные глаголы,
  ресурс не общий; рамка «X важнее Y» — риторический остаток раннего «дожима Fable», не отражение
  архитектуры.
- Стилман 2: забывание объективно важнее для приватности — на нём держится право на забвение (FQ7
  hard-erase), тогда как эмердженс — функция обогащения, не критичная для death-by-design
  обязательств. Сравнивать важность двух неконкурирующих глаголов не нужно для ответа на (б).
- Скрытое допущение исходного FQ5: эмерджентные узлы/рёбра, рождённые из данных о третьем лице,
  автоматически подчиняются участи источника при hard-erase. Это нигде не написано ни в FQ5, ни в
  FQ7 — пока не написано, статус «закрыто» преждевременен.
- Анатомия вопроса объективно ниже нужной для статуса «закрыто»: 1 файл, «зачем» = атрибуция
  источника («Дожим Fable»), варианты A/B без плюсов/минусов, план действий отсутствовал —
  несоразмерно с эталоном FQ7 (3 файла, план, конституционная связь).

## Критерии готовности
