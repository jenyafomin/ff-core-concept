# FQ21 · Обзор вариантов

## Тест несводимости (общий для всех вариантов)
- Как «класс целей» — тест **ПРОХОДИТ**: есть невыразимый остальными 7 ценностями остаток
  («конституирует ли меня этот узел»). Феномен реален и ортогонален, не шум.
- Как «ценность-ЕДИНИЦЫ» (свойство ВЕЩИ, как 7 базовых) — тест **ПРОВАЛИВАЕТСЯ**: это свойство
  РЕБРА человек→узел, той же категории, что уже отклонённая Г38 «значимость-для-человека»
  (свойство ребра, не ось узла — FQ8/V7). Вывод: феномен настоящий, но не кандидат в 8-ю ось
  базиса unit-ценностей.

---

## Вариант 1 — принять 8-й ЦЕННОСТЬЮ
Расширить базис 7 → 8, добавив «Конститутивность для личности» как самостоятельную ось узла.

- Плюс: явный первоклассный статус для «нельзя забыть без кризиса»; движок сразу отличает
  несущий принцип от расходного факта.
- Минус: **ломает FQ9** («базис 7 ЗАМКНУТ», ✅) — прямой конфликт статусов в реестре.
- Минус: противоречит собственному правилу Fable «значимость (Г38) = свойство ребра, не ось» —
  конститутивность структурно та же категория.
- Минус: противоречит итоговой самопереоценке автора (fable2): конститутивность — «свойство
  встречи», не «свойство вещи».
- **Не рекомендуется.**

## Вариант 2 — под-ось/грань через FQ24 + тип `principle` + successor FQ18 (рекомендация критика)
НЕ внутри Тождества/Согласия (это опровергнуто FQ2 — см. ниже), а как:
- свойство РЕБРА человек→узел «конституирует ли меня этот узел»,
- разрешаемое нулевым правилом FQ24 (ВЕЩЬ⟂ВСТРЕЧА): встреча-свойства вычисляются движком по
  путям, не хранятся полем паспорта,
- через тип узла `principle` (План II — Намерение) для узлов-принципов («семья важнее карьеры»),
- с релевантностью для successor уже через принятый мета-узел Самости (FQ18, ✅).

- Плюс: FQ9 сохраняется (базис замкнут по unit-ценностям; свойства встречи — отдельный класс).
- Плюс: феномен получает корректный категориальный дом, а не произвольный.
- Плюс: не решает четыре смежных спора (FQ21/FQ24/FQ18/Г38) порознь — сводит их в одну категорию.
- Минус: требует, чтобы FQ24 (тоже пока ⚠️🌟 спорно) был решён первым — зависимость.
- **Рекомендуется.**

## Вариант 3 — отклонить полностью
Покрыть поведение «нельзя забыть без кризиса» существующими механизмами без нового домена:
decay=0 в Витальности (Ц-4, предельный параметр метаболизма) + высокая salience.

- Плюс: минимум новых сущностей, ничего не ломается.
- Минус: без явного дома («какая метка говорит, что это принцип, а не факт») поведение может
  снова «выпасть», как когда-то выпадал конфликт-протокол в FQ2, пока ему не нашли явное место.
- Слабее варианта 2: не даёт движку прямого критерия для successor/принципов, только косвенный
  через decay-параметр.

## Опровергнутая старая формулировка (для истории)
Прежний вариант B в INDEX.md («грань внутри Тождества/Согласия») **опровергнут FQ2**: разбор FQ2
доказывает, что идентичность ЛИЧНОСТИ владельца несводима к Тождеству ЯЧЕЙКИ (объект vs целое —
«ложный друг»). Поэтому «грань внутри Тождества» больше не рассматривается; вариант 2 выше —
его замена (грань ребра, не грань существующей unit-ценности).

## Кто сильнее — FQ21 или FQ10 — как кандидат в Ц-8?
Оба (FQ21 и FQ10 «опека vs автономия») проваливают тест «ценность-ЕДИНИЦЫ» по одной структурной
причине: оба — про ОТНОШЕНИЕ/ПОВЕДЕНИЕ, не про единицу-субстрат. FQ10 уже под-ось Согласия
(отложен). FQ21 глубже и всепроникающе — но именно поэтому он корневое различение (FQ24), а не
пиковая ось. Ни один не должен стать 8-й ценностью.
