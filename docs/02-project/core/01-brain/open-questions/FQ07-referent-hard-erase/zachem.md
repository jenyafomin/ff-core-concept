# FQ7 · Зачем / почему возник

Единственный вопрос класса «сейчас» с death-by-design. Если не заложить грань «эта запись про
третье лицо» сразу, потом **нельзя задним числом** понять, какие из миллионов записей касаются
третьих лиц. Без этого право на забвение (`hard-erase`) и согласие референта становятся
нереализуемыми — их некуда подвесить. Отсюда: резервировать грань с 1-й итерации, а не позже.

Связь: конституционный инвариант «согласие референта нельзя переопределить политикой владельца»
(первый жилец уровня Конституции, см. FQ3).
