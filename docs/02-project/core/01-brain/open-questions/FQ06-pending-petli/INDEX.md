# FQ6 — Открытые петли (незакрытые намерения)

> ⚠️ Прежний склон «да → спец-статус `pending`» СНЯТ перепроверкой ([checks/2026-07-07-recheck.md](checks/2026-07-07-recheck.md)).

## 1. Вопрос

Где живёт «открытая петля» (незакрытое намерение/вопрос между сессиями) — как **отдельная
грань/статус паспорта** ячейки, или как **производный вид**, вычисляемый из графа рёбер?

Разделяем то, что раньше было склеено:
- **БОЛЬ** (реальна): не терять открытые намерения между сессиями — компакт-тревога.
- **МЕХАНИЗМ** (спорно): нужно ли под эту боль отдельное поле паспорта, или боль уже покрыта
  существующими планами.

## 2. Рекомендация

Рекомендация агента (recheck, уверенность ~70%): **вариант C** — `pending` НЕ поле паспорта.
«Петля открыта» выводима из графа: узел-намерение (план **Намерение**, FQ16), на который
не указывает ребро `answers/closes`. Это запрос/вид, а не хранимый флаг — 0 новых полей,
тонкий паспорт (ADR-0002) не нарушается. Полный разбор → [overview.md](overview.md), почему
боль вообще возникла → [zachem.md](zachem.md).

Финальное решение — за владельцем (см. п.3).

## 3. Выбор / что делаем

**⚠️ Развилка ждёт владельца:**

- **(A)** Спец-поле/статус `pending` в паспорте ячейки — состояние явно лежит на узле,
  но нарушает тонкий паспорт «0 новых полей» и дублирует план Намерение (FQ16).
- **(C)** Производный вид над планом Намерение + всплытие через salience (FQ17) — 0 новых
  полей, ретрофит возможен в любой момент, петля живёт в рёбрах/виде, не в хранимом флаге.
  *Рекомендация агента: C.*

## Возражения (раздел B recheck)

Против прежнего «склоняюсь да» (спец-поле сейчас):
1. Противоречит ратифицированному инварианту «0 новых обязательных полей паспорта» (L0/ADR-0002).
2. Открытость петли выводима из графа (нет ребра `answers/closes` от намерения) → вычислимо
   в любой момент, не требует хранения.
3. Дублирует план **Намерение** (FQ16 ✅) — тот уже даёт намерениям дом.
4. Боль (компакт-тревога) уже адресована на уровне L0 («контракт повторного входа», FQ12
   снапшот, метаболизм) — не требует нового поля.
5. **Не death-by-design** (в отличие от FQ7): открытость всегда пересчитываема из рёбер задним
   числом → «заложить сейчас» не обосновано ретрофитом.

Скрытые допущения, которые критик отметил: петля не бинарна (open/closed) — реально есть
брошено/отложено/заблокировано/частично, флаг это прячет; `pending` может принадлежать
runtime-состоянию сессии агента, а не грани памяти вообще.

## Критерии готовности

- [ ] Владелец выбрал A или C (развилка выше).
- [ ] Если C: подтверждён механизм «нет ребра `answers/closes` → петля открыта» как часть
