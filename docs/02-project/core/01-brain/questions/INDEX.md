## Анатомия папки-вопроса (канон · v2 после перепроверки 2026-07-07)

Каждый вопрос = **папка** `FQxx-slug/`. Внутри `INDEX.md` — спина по секциям (эталон — [FQ7](FQ07-referent-hard-erase/INDEX.md)):

1. **frontmatter** — Status · Owner · Date · Scope · Related (обязателен).
2. **Вопрос** — сам вопрос (острый, один, не наводящий).
3. **Рекомендация** — кратко (или ссылка на `rekomendaciya.md`), ПЕРЕД выбором.
4. **Выбор / что делаем** — решение + **план** (1-3 пункта). Если найдена развилка/ОСПОРЕНО —
   «⚠️ Развилка — ждёт владельца» + варианты (решение НЕ принимается за владельца).
5. **Связи** — перекрёстные ссылки на смежные FQ и ценности (`refines / tension-with / depends-on /
   duplicate-risk / grounds`). Раньше массово пустовали — теперь обязательны.
6. **Возражения / что может сломать** — зафиксированный стилман-контра.
7. **Критерии готовности** — когда вопрос закрываем и от чего зависит.
8. **Статус** — ✅ / ⚠️ / 🔴 / 💬 / 🌟 + строка `перепроверено <дата> → checks/…`.

**Вспомогательное:** `zachem.md` (origin) · `overview.md` (варианты/данные) · `rekomendaciya.md` ·
`checks/` (перепроверки).

**Правило роста:** простой (✅) → хватает `INDEX.md`. **Спорный (⚠️/🌟) → ОБЯЗАТЕЛЬНЫ** `zachem.md`+`overview.md`.

**Инвариант source-of-truth:** статус в этой карте = статусу в файле вопроса (одна правка меняет оба).
