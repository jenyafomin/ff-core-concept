# FQ6 · Зачем / почему возник

Origin — **компакт-тревога владельца**: страх потерять контекст открытых дел/вопросов при
компакте сессии или между сессиями («что я не докрутил, куда возвращаться»). Отсюда вопрос —
нужен ли специальный статус `pending` для незакрытых петель.

Recheck (2026-07-07) показал: боль реальна, но она уже адресована на уровне L0 в целом
(«контракт повторного входа», снапшот-в-момент FQ12, метаболизм памяти) — а сама петля как
явление выводима из графа (узел-намерение без ребра `answers/closes`), а не требует нового
хранимого поля. Поэтому вопрос переформулирован: не «нужен ли pending против компакт-тревоги»
(наводяще), а «где живёт петля — поле паспорта или производный вид» (см. [INDEX.md](INDEX.md)).

Связь: план **Намерение** (FQ16) — вероятный дом; **salience** (FQ17) — механизм всплытия петель.
