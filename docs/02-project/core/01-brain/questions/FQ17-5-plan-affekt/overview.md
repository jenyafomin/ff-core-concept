# FQ17 · Обзор вариантов

## Ось 1 — план vs грань

- **A — 5-й план «Аффект»** (исходное предложение, отклонено критиком).
  Плюс: явный, отдельно адресуемый базис. Минус: ортогональность 4 планам (FQ16) не показана;
  без doказательства — самовольное расширение базиса. Не death-by-design (ретрофит возможен) →
  спешить незачем.
- **B — грань существующего плана «Точка зрения» (FQ16)** (дефолт-рекомендация критика).
  Аффект = оценочная позиция субъекта → естественно ложится гранью, а не новым базисом.
  Плюс: не трогает базис 4 планов, ретрофитится в любой момент.
- **C — оставить 4 плана, без аффекта вовсе** (пока не определена ветка «чей аффект»).
  Актуально, если развилка ниже разрешится в пользу «человек» (см. Ось 2) — тогда аффект уже
  покрыт FQ8/Ц-4 и отдельной сущности не требуется вовсе.

## Ось 2 — чей аффект (развилка, ждёт владельца)

- **(а) Аффект ЧЕЛОВЕКА** на записи.
  → Дубликат FQ8 (значимость на ребре) + Ц-4 Витальность (salience). FQ17 закрывается без
  нового механизма; вариант C.
- **(б) Собственный аффект БРЕЙНА** (агент/движок «чувствует» состояние по отношению к записи).
  → Новая сущность, но НЕсрочная и спекулятивная: неизмерима без дополнительного определения
  (кто пишет, кто верифицирует, integrity-as-duty иначе повисает). Если выбрана — далее решать
  Ось 1, дефолт B (грань Точки-зрения), не A.

## Что уже решено и не пересматривается
- **Значимость** (вес записи для человека) — НЕ часть FQ17. Дом = FQ8 (ребро) + Ц-4 (salience).
  Любой вариант выше не возвращает значимость в объём FQ17.

## Рекомендация критика при неопределённости
Если владелец не готов решать сейчас — дефолт: **отложить**, вариант **(б)+B** как рабочая
гипотеза (грань Точки-зрения), без резервирования нового плана. Ретрофит открыт, срочности нет.
