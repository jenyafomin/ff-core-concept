# FQ21 — 8-я ценность «Конститутивность для личности»? ⚠️🌟

## 1. Вопрос
Нужна ли 8-я ценность «Конститутивность для личности» (Идентичность-ЛИЧНОСТИ ≠ Тождество-ЯЧЕЙКИ
из FQ2)? Феномен: некоторые узлы «конституируют» владельца — их нельзя забыть без кризиса,
опровержение — не рядовой апдейт, а перелом.

## 2. Рекомендация
**ОСПОРЕНО** (независимый перечёт, уверенность ~75%; полный разбор →
[checks/2026-07-07-recheck.md](checks/2026-07-07-recheck.md)). Оспаривается не реальность
феномена, а его ТИП: конститутивность реальна и ортогональна 7 ценностям, но она —
**свойство ВСТРЕЧИ (ребра человек→узел), не свойство ВЕЩИ (не ось узла)**. Как 8-я ценность
базиса — отклонить, это ломает FQ9. Как грань, разрешаемую через FQ24 (нулевое правило
ВЕЩЬ⟂ВСТРЕЧА) + тип узла `principle` (План II) + successor (FQ18) — принять. Не death-by-design:
ретрофит возможен, спешить не нужно (почему → [zachem.md](zachem.md)). Разбор вариантов →
[overview.md](overview.md).

## 3. Выбор / что делаем
**⚠️ Развилка ждёт владельца.** Три варианта:

1. **8-я ценность** — расширить базис до 8. Ломает FQ9 (базис 7 замкнут, статус ✅), противоречит
   собственному правилу Fable «Г38/значимость = ребро, не ось» и итоговому выводу fable2
   (fable2 сам переклассифицировал конститутивность из ценности в свойство встречи).
2. **Под-ось/грань через FQ24 + тип `principle` + successor FQ18** (рекомендация критика) — НЕ
   внутри Тождества/Согласия, а как свойство ребра человек→узел, разрешаемое нулевым правилом
   FQ24, типом узла `principle` (План II) и релевантностью для successor (FQ18). Механизм —
   движок по путям, не поле паспорта. FQ9 сохраняется.
3. **Отклонить полностью** — покрыть через decay=0 (Витальность) + high salience без явного
   дома. Риск: без явного дома может «выпасть», как когда-то выпадал конфликт-протокол в FQ2.

## Возражения (тест несводимости)
- **Как «класс целей» — тест ПРОХОДИТ**: есть невыразимый остальными 7 остаток («конституирует
  ли меня»). Феномен ортогонален, не шум.
- **Как «ценность-ЕДИНИЦЫ» (свойство ВЕЩИ) — тест ПРОВАЛИВАЕТСЯ**: это свойство РЕБРА
  человек→узел, той же категории, что уже отклонённая Г38 «значимость-для-человека» (свойство
  ребра, не ось узла; FQ8/V7). Ставить 8-й осью рядом с 7 unit-ценностями — категориальная ошибка.
- Скрытое допущение «важно ⇒ ценность» не выдерживает: всепроникаемость феномена — признак
  корневого различения (FQ24), а не пиковой оси базиса.
- ~~Старый вариант B «грань внутри Тождества/Согласия»~~ — **опровергнут FQ2**, который явно
  доказывает несводимость идентичности личности к Тождеству ячейки (объект vs целое, «ложный
  друг»). Заменён вариантом 2 выше (грань ребра через FQ24+principle+FQ18).
