# FQ21 · Зачем / почему возник

3-й раунд вопросов Fable (брейн как СУБЪЕКТ). Наблюдение: не все узлы равны для владельца — есть
такие, потерять которые означало бы не «забыть факт», а перестать быть собой (bus factor,
successor, «кто я»). Идентичность ЛИЧНОСТИ владельца ≠ Тождество ЯЧЕЙКИ (FQ2 — про объект vs
целое). Отсюда вопрос: нужна ли отдельная 8-я ценность «Конститутивность для личности» поверх
уже замкнутого базиса 7 (FQ9)?

Родился ПОЗЖЕ, чем закрылся FQ9 («базис 7 ЗАМКНУТ», ✅) — Fable в nonlinear-dig прямо писал
«не пложу восьмую… лишней нет». FQ21 всплыл в финальном чеке уже после этого, поэтому конфликт со
статусом FQ9 не косметический, а прямой (см. [checks/2026-07-07-recheck.md](checks/2026-07-07-recheck.md), раздел C).

Позднее сам Fable (fable2, синтез «субклетка и ревью») переклассифицировал конститутивность:
«биография, аффект, конститутивность-для-личности — все свойства ВСТРЕЧИ, не свойства ВЕЩИ» →
если про встречу, живёт не в паспорте узла, а вычисляется движком по путям (домен FQ24, нулевое
правило ВЕЩЬ⟂ВСТРЕЧА). Это ключевой сдвиг, который и делает вопрос спорным: кандидат в ценность
сам был переопределён его автором в другую категорию.

**Не death-by-design** (в отличие от FQ7): конститутивность ретрофитится — статус узла можно
доразметить позже из типа `principle` + использования + тега владельца, информация не
уничтожается. Значит спешить с решением развилки не нужно, но папку нужно было дорастить до
уровня, на котором решение вообще можно принимать (эталон FQ7: INDEX+zachem+overview).
