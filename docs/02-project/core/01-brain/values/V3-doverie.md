# Ц-3 · ДОВЕРИЕ (Living Trust)

> Статус: draft · Родитель: [../INDEX.md](../INDEX.md)

**Определение.** Насколько это правда — калибруется использованием, несёт провенанс, защищено от отравления.

**Несёт цели:** Г7 (актуальная истинность) · Г8 (годность вперёд) · Г9 (снапшот назад/аудит) · Г10 (провенанс) · Г11 (защита от отравления).

**Идеи / куда копать (L2):** байесовское обновление confidence · W3C PROV `wasDerivedFrom` · bitemporal · авторизация записи (capabilities) · supersession-duty (`contradicted-by` самоаннулирует при чтении, Opus #6). Двойное попадание с Согласием (авторизация).

**Открытые вопросы:** зомби-память (единый порог доступа на ВСЕ каналы) · недетерминизм параллельной записи агентов (DB-control) · «тихая ложь» единиц/локали/валюты (DATA-side, заложить сейчас).

**Сценарии:** агент на устаревшей ячейке → катастрофа (Opus #6) · данные под одним согласием для другого (Opus #4, → Согласие) · деградация СВЯЗЕЙ, а не данных (Sonnet #7).

**Связи:** ↔ Витальность(годность) · ↔ Реляционность(конфликт) · ↔ Согласие(кто вправе писать).
