# IDEA — Supersession self-annul (самоаннулирование при чтении)

**Суть:** Запись с полем `contradicted-by` не пассивно хранит устаревший высокий confidence — она несёт ОБЯЗАННОСТЬ (policy-as-data) при каждом чтении проверить, не опровергнута ли она, и если да — самостоятельно понизить отдаваемое значение confidence до чтения агентом/человеком. Предотвращает Opus-сценарий "агент на устаревшей ячейке → катастрофа".

**К какой под-грани относится:** Д6 (Supersession-duty).

**Открытые вопросы:** Это обязанность самой записи (policy-as-data, дорого — каждая запись несёт логику) или примитив движка (дёшево, но требует единого протокола проверки для ВСЕХ записей — конфликт с Суверенностью)?
