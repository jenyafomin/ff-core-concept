# IDEA — source = origin + effective

**Суть:** Разделить провенанс на два поля: `origin` (кто ИЗНАЧАЛЬНО внёс факт — человек/агент/система) и `effective` (кто СЕЙЧАС подтверждает/поддерживает его актуальность). Confidence считается функцией обоих — не только "откуда пришло", но и "кто до сих пор за это ручается". Это уже есть в канон-брифе как заложить-сейчас пункт — здесь конкретизируется как механизм Д1+Д2.

**К какой под-грани относится:** Д1 (Провенанс), Д2 (Калибровка использованием).

**Открытые вопросы:** Если `origin` и `effective` расходятся (первый автор давно неактивен, но никто не опроверг) — деградирует ли confidence автоматически по времени, или держится, пока явно не оспорено?
