## Суть

Единица должна отвечать «стоит ли меня брать» и «во сколько обойдётся меня прочитать» —
**не открывая payload**. Объект защиты — самый первый, самый дешёвый акт чтения: обзор
графа из сотен/тысяч узлов должен быть возможен без единого полного чтения. Закрывает
П1 (дешёвый паспорт) и П6 (self-pricing / `price_hint`) как одну неразрывную пару: знать,
что там, и знать, сколько будет стоить узнать больше.

## Границы

- **Входит:** минимальный обязательный шейп паспорта (id/type/label/salience/temperature —
  вопрос Q1); `price_hint` как оценка стоимости чтения на каждом уровне; кто и когда считает
  цену (запись vs чтение); бейдж авторства (system/human/agent) как дешёвое поле; стресс-тест
  «остаётся ли паспорт дешёвым» при росте графа до реалистичного N.
- **НЕ входит:** сама многогранность содержимого, кому какая грань положена (→ 02
  polysemy-lens — паспорт даёт ОДНУ, самую дешёвую проекцию всем одинаково, полисемия
  начинается уровнем выше); лестница промежуточных ступеней раскрытия (→ 03
  progressive-disclosure, паспорт — только нулевая, самая дешёвая ступень этой лестницы);
  кто решает и меняет температуру (→ 04, здесь температура — просто ПОЛЕ паспорта, не
  механизм).
- **Тонкая граница с 03:** 01 — что лежит на самом дне (дешевле некуда); 03 — вся лестница
  НАД этим дном и переходы между ступенями.

## Развилки (веер «как», не режем)

1. **Обязательный минимальный шейп (Q1).** Жёсткий общий шейп на все типы ячеек
   (id/type/label/salience/temperature) [+ единый обзор графа без знания типа заранее /
   − давит на суверенность типов (шов с Ц5, policy-as-data)] vs каждый тип решает сам, что
   в паспорте (чистый policy-as-data) [+ гибкость / − граф нечитаем без знания типа —
   нарушает П1 напрямую] vs гибрид: общий «конверт» + суверенные доп.поля поверх [+
   совмещает оба / − две системы полей, сложнее валидировать].
2. **Кто считает `price_hint`.** Сама ячейка при записи (дёшево для чтения, риск устареть
   при правке payload) [+ дёшево / − протухает] vs движок лениво пересчитывает при первом
   обращении после изменения [+ свежо / − доп. нагрузка на движок] vs грубая эвристика по
   размеру payload без явного пересчёта (bytes → категория) [+ почти бесплатно / − неточно
   для сложных/составных типов].
3. **Точность цены (Q3).** Точный расчёт (токены) [+ точно / − сам расчёт должен быть
   дешевле того, что оценивает — парадокс] vs категория S/M/L/XL [+ дёшево, достаточно для
   бюджетирования / − агент может промахнуться на границе категорий] vs диапазон с
   доверительным интервалом [+ баланс / − сложнее объяснить человеку одним взглядом].
4. **Авторство как поле паспорта.** Обязательное поле сразу в минимальном шейпе [+ доверие
   калибруется одним взглядом до чтения / − раздувает Q1-минимум, конфликт с «держать
   паспорт тонким»] vs отдельная ось у Доверия (Ц3), паспорт лишь ссылается на неё [+ чистое
   разделение ценностей / − теряется «увидеть источник» одним взглядом на дешёвом уровне].
5. **Верификация «дёшево остаётся дёшево» на масштабе.** Синтетический бенчмарк ДО выбора
   движка хранения (N узлов, M рёбер, замер стоимости обзора) [+ ловит проблему рано, пока
   дёшево чинить / − нужен реалистичный порядок N, кто-то должен его назвать] vs полагаться
   на профилирование post-factum после MVP [+ не тормозит текущий дизайн / − переделка
   движка задним числом стоит дорого].

## Пул идей

| Идея | Индекс | Задевает ещё | Метка |
|---|---|---|---|
| Минимальный обязательный шейп паспорта (Q1: id/type/label/salience/temperature) | P1 · M · высок | Ц5 (суверенность: общий шейп ⟂ per-type policy-as-data) | **→ infra** — фундамент для 02-06 внутри самой Читаемости тоже, но подъём именно из-за шва с Ц5 |
| `price_hint` — ценник самоописания цены на каждом уровне | P1 · S · высок | — | новое (из `IDEA-passport-price-tag`) |
| Бейдж авторства (system/human/agent) в паспорте | P2 · S · сред | Ц3 доверие | **→ infra** (из `IDEA-authorship-badge`) |
| Стресс-тест читаемости на масштабе (бенчмарк до выбора движка) | P2 · M · высок | Ц4 витальность (метаболизм тоже обязан масштабироваться) | **→ infra** (из `IDEA-legibility-stress-test-at-scale`) |
| Грубая эвристика цены по размеру payload (без явного пересчёта) | P2 · S · сред | — | новое |

> Теги: Ц3 (авторство/доверие), Ц4 (масштаб метаболизма), Ц5 (шов self-describing/суверенность,
> развилка 1). Внутри направления: 02 (полисемия — паспорт как общая точка входа), 03 (нулевая
> ступень лестницы), 04 (температура как поле паспорта) — не подъём, просто соседи по ценности.
