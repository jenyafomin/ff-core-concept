## Суть

Та же единица (тот же `canonical_id`) меняет **оценку/смысл своего содержимого** во времени —
классический пример владельца: обида превращается в благодарность к тому же самому воспоминанию, —
не теряя Тождества. Это шестой глагол, явно выделенный отдельно от «Переработать» (дедуп/консолидация
нескольких единиц) в L0, но так и не разложенный на развилки. Объект защиты — **честный след того, как
я думал раньше**, при том что «сейчас» тоже должно быть чистым, не захламлённым старой интерпретацией.

## Границы

- **Входит:** переосмысление как отдельный контракт (не форк, не эмердженс, не забывание); связь с
  bitemporal-версией того же `canonical_id` (В2 из L0); что происходит со старой интерпретацией
  (видна ли as-of T); кто инициирует переосмысление.
- **НЕ входит:** дедуп/консолидация НЕСКОЛЬКИХ единиц в одну (→ 02 consolidation-emergence — другой
  глагол, другое число источников); Забыть — меняет доступность, не содержимое (→ 03
  forgetting-lifecycle); намеренный вариант/ветка (Г28 из L0, «проявление в пространстве» — другая
  ось многомерности, не витальность).
- **Тонкая граница с 02:** консолидация меняет ГРАНИЦЫ единицы (сколько единиц стало одной);
  переосмысление меняет ОЦЕНКУ содержимого ОДНОЙ единицы без нового сырья извне.

## Развилки

1. **Механизм переосмысления.** Новая bitemporal-версия того же `canonical_id` (valid-time вперёд,
   старая версия читается as-of T) [+переиспользует уже решённый В2-механизм, ничего нового не
   изобретаем / −неявно перегружает «версию» двумя разными смыслами: факт изменился vs смысл того же
   факта изменился] vs отдельное поле `reinterpretation_of` + новый узел, который НЕ заменяет, а
   сосуществует рядом со старым (обе точки зрения видны одновременно) [+честно показывает «было/стало
   понимание» как две равноправные записи / −плодит узлы, по факту сближается с эмердженсом] vs
   правка «оценки» (валентности/confidence) без новой версии вообще, только апдейт метаданных [+дёшево
   / −теряет исторический след «как я думал раньше», нарушает Г9 (аудит момента решения)].
2. **Кто инициирует.** Только человек явно, «я передумал» [+намеренность, безопасно / −агент не
   может подсветить момент, когда пора] vs агент-садовник ПРЕДЛАГАЕТ переосмысление по паттерну
   (например, долго не подтверждаемая «обида»-метка при новых позитивных сигналах рядом) [+проактивно
   ловит момент / −патернализм: переписывание чужих чувств без явного спроса — тонко и рискованно].
3. **Видимость старой интерпретации.** Всегда доступна as-of T по запросу (аудит, Г9) [+честно / −
   может быть неприятно «воскресить» старую обиду по случайному запросу] vs старая версия по
   умолчанию скрыта, доступна только по явному запросу владельца [+защищает от нежеланного всплытия /
   −менее прозрачно для агента, который решает, доверять ли текущей интерпретации].
