# Направление 06 — Акт сокрытия как аудируемая ячейка

- **Status:** draft — дивергенция · **Owner:** JenyaFomin · **Date:** 2026-07-09
- **Related:** `../README.md` (ценность Ц-7) · `../V7-soglasie/ideas/IDEA-custodial-override-as-cell`
  (исходная карта) · Ц-3 Доверие (полнота/правда) · Ц-1 Читаемость (видно, что ИИ делает) ·
  сценарий «милосердная ложь владельцу» · паттерн event sourcing

## Суть

Когда владелец/агент решает **скрыть или исказить** что-то от человека (напр. «милосердная ложь» — не
показать правду ради его же блага), это действие само становится **аудируемой ячейкой-событием**
(`type: consent-action`), ссылающейся на исходную запись, — **а не тихой мутацией** поля видимости.
Иначе согласие превращается в инструмент незаметной манипуляции. Объект защиты — **мета-акт сокрытия**:
чтобы «скрыть» всегда оставляло след.

## Границы

- **Входит:** материализация акта сокрытия как ячейки-события; провенанс/ссылка на скрытое; видимость
  самого акта (кому); обратимость сокрытия для системы; кто вправе инициировать.
- **НЕ входит:** обычная настройка visibility без обмана (→ 02); отзыв согласия референтом (→ 05);
  hard-erase (→ 05).
- **Тонкая граница с Ц-3 Доверие:** сокрытие намеренно снижает полноту для конкретного человека здесь и
  сейчас, но обязано оставаться **правдивым и обратимым для системы/аудита** — трение с идеалом «доверие
  калибруется правдой» разрешается тем, что скрыт факт, а не сам факт сокрытия.

## Развилки (веер «как», не режем)

1. **Форма акта.** Отдельная ячейка-событие (event sourcing, `consent-action`) [+ полный аудит, обратимо /
   − объём] vs скрытая мутация поля видимости [− незаметная манипуляция, **отвергнуто**] vs подписанная
   запись в общий журнал согласий [+ компактно / − не в графе, слабее связи].
2. **Видно ли обманутому человеку.** Да, если прямо спросит «скрывали ли от меня что-то» [+ честно, не
   патернализм / − обесценивает саму милосердную ложь] vs нет для человека, да для системы/агента
   [+ сохраняет функцию сокрытия / − патернализм] vs зависит от класса (медицина ≠ финансы ≠ быт).
   (Q-custodial-override-visibility)
3. **Кто вправе инициировать.** Только владелец [+ контроль / − агент не может защитить в моменте] vs
   агент по политике [+ автономно / − риск злоупотребления] vs требует со-подписи (Конституция 07.C).
4. **Обратимость.** Сокрытие всегда откатываемо системой (правда не теряется) [+ не теряем истину /
   − хранение скрытого] vs может стать постоянным по политике [+ чисто / − риск потери правды].
