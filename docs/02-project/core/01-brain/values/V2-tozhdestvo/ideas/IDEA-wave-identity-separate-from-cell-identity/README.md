# IDEA — тождество проекции (волны) отдельно от тождества ячейки

**Суть.** Автоматически собираемые домены/индексы («волна», линза-проекция, тема B
владельца) читают существующие `canonical_id` ячеек, но НЕ присваивают собственных
тождеств узлам при группировке. Если волне понадобится собственная стабильность
(например, «этот домен» узнаётся между сессиями), это отдельный, второй вид
идентичности — идентичность проекции, а не ячейки — иначе пересборка индекса начнёт
плодить дубли памяти.

**К какой под-грани относится:** тема B (авто-индекс/домен-как-волна), пересекается
с п.1 Декомпозиции (Идентификатор-якорь).

**Открытые вопросы:**
- Нужна ли волне вообще персистентная идентичность, или она принципиально
  одноразова (пересобирается с нуля при каждом запросе, без состояния)?
