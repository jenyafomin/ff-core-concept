# IDEA — event-anchor: co-referencia события ≠ тождество записи

**Суть.** Три свидетеля одной сцены создают три РАЗНЫЕ единицы памяти, каждая
тождественна самой себе, но со-референтна одному событию через ребро
`same-event-as`. Смешение «то же событие» и «та же память» — систематическая ошибка,
которую нужно исключить на уровне модели данных: co-referencia — это связь между
узлами, а не повод их слить.

**К какой под-грани относится:** п.4 Декомпозиции (Co-referencia события).

**Открытые вопросы:**
- Как агент отличает «это два независимых свидетельства одного события» от «это
  дубликат одной и той же записи, пришедший дважды»? Нужен явный маркер
  источника/канала.
