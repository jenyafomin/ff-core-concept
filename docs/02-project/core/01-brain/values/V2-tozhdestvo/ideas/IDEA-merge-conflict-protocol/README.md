# IDEA — конфликт-протокол слияния как первоклассный примитив

**Суть.** Явный, декларативный протокол на случай «две записи претендуют на один и
тот же референт»: правило приоритета (свежесть/источник/явное решение), а не
результат неявного порядка операций. Протокол — часть конституции (Ц2 надёжен только
если он не оставлен на волю случая), а не деталь реализации отдельного агента.

**К какой под-грани относится:** п.2 Декомпозиции (Граница слияния) — прямое
закрытие зоны, помеченной в L0 как «не покрыто!».

**Открытые вопросы:**
- Слияние — необратимая операция или всегда оставляет след (кто с кем слился, когда,
  по какому правилу), чтобы можно было откатить ошибочное слияние?
- Конфликт правды (Доверие, Ц3) и конфликт тождества (Ц2) — разные протоколы или
  один комбинированный?
