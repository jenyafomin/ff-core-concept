# IDEA — три разных отношения: версия / вариант / новая единица

**Суть.** Формализовать три разных отношения, которые легко перепутать: (1) версия
во времени — та же единица, тождество сохраняется, меняется срез (bitemporal-пара
«когда произошло / когда узнали»); (2) вариант — сосуществующая альтернатива, общее
происхождение, но раздельное тождество (`variant-of`); (3) новая единица — тождество
разорвано намеренно (после расщепления или смены типа). Каждое требует своего ребра
и своей семантики отображения в UI/агенту.

**К какой под-грани относится:** п.6 Декомпозиции (Bitemporal-версия vs новая
единица, В2).

**Открытые вопросы:**
- Есть ли автоматическое правило превращения «варианта» в «новую единицу» со
  временем (если варианты расходятся достаточно далеко), или это всегда явное
  решение?
