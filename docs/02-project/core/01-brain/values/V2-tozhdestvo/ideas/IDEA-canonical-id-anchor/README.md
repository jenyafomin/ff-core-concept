# IDEA — canonical_id как неизменяемый якорь

**Суть.** Каждая единица получает `canonical_id`, присваиваемый один раз при рождении
и никогда не пересчитываемый по содержимому. `payload` может меняться (версии,
консолидация), `canonical_id` — никогда. Это единственный технический факт, на
котором держится всё остальное различение «та же/другая».

**К какой под-грани относится:** п.1 Декомпозиции (Идентификатор-якорь).

**Открытые вопросы:**
- Какой формат id (UUID, content-hash при рождении, составной)? Content-hash
  конфликтует с «неизменяемостью после рождения», если payload при рождении ещё
  формируется.
- Кто выдаёт id — движок централизованно или ячейка сама (важно для plug-in/оффлайн
  создания)?
