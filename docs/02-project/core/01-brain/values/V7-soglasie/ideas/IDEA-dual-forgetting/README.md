# IDEA · Два разных примитива забывания

**Суть:** движок получает ДВА независимых механизма, а не один. (1) Обратимое затухание —
salience→0, «спит», bitemporal хранит полную историю («забыть≠удалить», дефолт для
владельческого забывания). (2) Hard-erase/tombstone — настоящее необратимое удаление payload,
запускается только по требованию референта, конституционно обязательно к исполнению.

**К какой под-грани:** #6 Отзыв и его горизонт (revocation + hard-erase).

или id тоже освобождается (Q-hard-erase-id)? Как это согласуется с Ц2 Тождество?
