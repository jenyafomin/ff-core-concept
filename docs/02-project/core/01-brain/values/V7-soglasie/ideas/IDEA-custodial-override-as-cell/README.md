# IDEA · Акт сокрытия — сама ячейка, не скрытая мутация

**Суть:** когда владелец/агент решает скрыть или исказить что-то от человека (напр. «милосердная
ложь»), это действие материализуется как отдельная ячейка-событие (`type: consent-action`),
ссылающаяся на исходную запись и аудируемая. Никогда не тихая мутация существующего поля
видимости — иначе согласие превращается в инструмент незаметной манипуляции.

**К какой под-грани:** #7 Акт сокрытия как аудируемое событие (custodial-override).

**Открытые вопросы:** видна ли эта ячейка-событие самому обманутому человеку, если он прямо
спросит «скрывали ли от меня что-то» — и не обесценивает ли это саму идею сокрытия
(Q-custodial-override-visibility)?
