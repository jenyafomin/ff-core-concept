# IDEA · Грань `referent` в паспорте с 1-й итерации

**Суть:** добавить в паспорт единицы поле `referent` (список id, по умолчанию пуст) — отдельно от
`owner`/`author`. Пустой referent = запись о мире/себе (дефолт, 99% случаев, ничего не меняется).
Непустой = включается вторая ось субъектности: видимость и использование ячейки теперь ограничены
не только владельцем, но и правами референта.

**К какой под-грани:** #1 Референт (referent).

**Открытые вопросы:** кто выставляет visibility-consent от имени референта, пока тот не имеет
доступа к платформе (см. Q-referent-scope в ../../questions.md)? Нужна ли роль «опекун согласия»?
