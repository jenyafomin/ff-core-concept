# IDEA: Ребро — это тоже ячейка (property-graph, не foreign key)

Ребро получает собственный id, паспорт (актор/время/акт создания) и опциональный
salience/confidence — структурно такая же мини-единица, как узел, а не пара указателей
`from_id/to_id` внутри узла. Позволяет версионировать связь отдельно от версий узлов и хранить
провенанс утверждения «A связано с B» независимо от провенанса A и B.

**Относится к грани:** 1 (Ребро как единица памяти).

**Открытые вопросы:**
- Отдельное хранилище рёбер или атрибут узла с расширенной схемой? (см. RQ1)
- Нужен ли ребру собственный полноценный lifecycle (nascent → confirmed → stale), как у узла?
