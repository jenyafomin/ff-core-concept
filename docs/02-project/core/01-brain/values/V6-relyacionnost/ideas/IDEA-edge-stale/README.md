# IDEA: `stale` — атрибут связи, отдельный от `stale` узла

Связь стареет по собственной динамике: узлы живы и валидны, но контекст изменился, и связь между
ними уже не отражает реальность (например, «работает в компании X» после увольнения — оба узла
целы, ребро протухло). Даём ребру собственные поля `confidence`/`last-affirmed`, которые движок
может пересчитывать периодически или по триггеру, независимо от полей узлов.

**Относится к грани:** 5 (Деградация связи как отдельный процесс).

**Открытые вопросы:**
- Кто пересчитывает — движок по расписанию или агент по запросу? (см. RQ3)
- Порог, после которого `stale`-ребро скрывается из дефолтного среза графа?
