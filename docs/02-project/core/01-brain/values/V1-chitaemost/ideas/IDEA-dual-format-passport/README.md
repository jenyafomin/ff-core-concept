# IDEA — Двойной формат паспорта (структура + естественный язык в одном объекте)

**Суть.** Паспорт не выбирает между «машинным JSON» и «человеческим текстом» — это один
объект с обеими проекциями синхронно: структурные поля (id/type/salience) + `summary` на
естественном языке, сгенерированный из тех же полей. Не два источника правды, один.

**Относится к под-грани:** П7 (читаемость для агента ≠ для человека).

**Открытые вопросы:** кто генерирует natural-language summary при создании ячейки — LLM
на лету при первом чтении (дороже, но актуальнее) или при записи (дешевле для чтения, риск
устаревания при изменении полей).
