# IDEA — Стресс-тест читаемости на масштабе (первая ломающаяся грань)

**Суть.** Читаемость — единственная ценность, которая физически несёт нагрузку роста графа
(тема C): при тысячах/миллионах узлов дешёвый паспорт (П1), промежуточные ступени (П3) и
известная цена заранее (П6) — первое, что ломается. Предлагается заложить синтетический
бенчмарк-сценарий (N узлов, M связей) как часть верификации ДО того, как выбирается движок
хранения.

**Относится к под-грани:** П1, П3, П6 (все три несут нагрузку масштаба одновременно).

**Открытые вопросы:** какой порядок N считается «реалистичным для агрегатора жизни за 5 лет»
— нужна оценка от владельца, чтобы бенчмарк не был произвольным числом.
