# IDEA — Линза как единица памяти

**Суть.** Линза («как я смотрю на этот кусок жизни») — не служебный фильтр, а такая же
сохраняемая, переносимая единица графа со своим паспортом и провенансом. Это позволяет
переиспользовать точку зрения (агент применил линзу «финансовый риск» вчера — сегодня другой
агент может взять ту же линзу, не изобретая заново).

**Относится к под-грани:** П4 (линза / точка зрения) — прямое попадание в тему B (авто-индекс
как волна): домен собирается ЧЕРЕЗ линзу, а не хранится статичным полем.

**Открытые вопросы:** Q2 в questions.md (где живёт линза, вычисляемая или сохраняемая);
нужен ли у линзы собственный паспорт (рекурсия читаемости).
