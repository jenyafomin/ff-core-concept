# IDEA — Бейдж авторства в паспорте (authorship badge)

**Суть.** Лёгкое поле в паспорте (не в payload) явно называет происхождение: `system` /
`human` / `agent`. Читатель калибрует доверие к one-liner'у ДО чтения полного тела — «это
машина сгенерировала при импорте» читается иначе, чем «это я написал вручную».

**Относится к под-грани:** П1 (дешёвый паспорт) — прямое попадание в тему A (авторство/
владение): различие «системные vs пользовательские данные» должно быть видно на уровне
паспорта, не глубже.

**Открытые вопросы:** Q6 в questions.md — входит ли authorship в минимальный обязательный
шейп паспорта (Q1), или это отдельная ось ближе к Доверию (Ц3).
