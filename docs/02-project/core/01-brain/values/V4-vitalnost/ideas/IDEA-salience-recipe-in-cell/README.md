# IDEA · Рецепт затухания живёт в ячейке (policy-as-data для salience)

Параметры формулы salience (recency/importance/use_freq, их веса и темп затухания) — часть
паспорта ячейки, не глобальная константа движка. Движок предоставляет только примитив расчёта;
разные классы единиц (задача vs факт vs эмоция) метаболизируют по собственному рецепту.

**Относится к под-грани:** 1 (затухание), 7 (бюджет внимания как инвариант базы).

**Открытые вопросы:** где граница между «своим рецептом ячейки» и общим бюджетом базы (VQ2) —
можно ли рецептом обойти общий лимит и получить себе незаслуженную вечную видимость?
