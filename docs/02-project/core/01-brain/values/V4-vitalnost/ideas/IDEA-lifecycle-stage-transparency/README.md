# IDEA · Наблюдаемые стадии жизненного цикла (lifecycle-tiering)

Явный конечный автомат `nascent → active → cooling → cold → (dormant | erased)` вместо непрерывной
скрытой цифры salience. Каждый переход — событие с причиной (не магия чёрного ящика), доступное
для аудита садовника и, по запросу, человека.

**Относится к под-грани:** 4 (soft-забывание), 6 (lifecycle-tiering).

**Открытые вопросы:** сколько стадий реально нужно (не переусложнить); как стадии соотносятся с
cold-режимом Читаемости (Ц-1) — не задвоить логику перехода.
