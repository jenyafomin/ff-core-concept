# Ц-2 · Тождество (Identity)

> Родитель: [../INDEX.md](../INDEX.md) · Слой L1→L2 · draft

**Определение.** Единица знает, где кончается «та же самая» и начинается «другая». Условие осмысленности метаболизма и слияния конфликтов: нельзя «менять не теряя себя», пока не определено «себя».

**Несёт:** canonical_id · Г12 (менять не теряя) · В2 (bitemporal: вариант ≠ эволюция) · **конфликт-протокол двух частиц об одном факте** (в L0 помечен «не покрыто!»).

**Куда копать (L2 идеи):** bitemporal-версии · canonical_id + `variant-of` · DAG+union-find для слияния · дедуп ДО импорта (не после).

**Открытые вопросы / идеи:**
- FQ2: принять Тождество как отдельную несводимую ценность.
- Sonnet: **композиция/распад** (у композита свой id или производный?) · смена ТИПА ячейки.
- Opus: **event-anchor** — ко-референция разных памятей об одном событии ≠ «тот же носитель».
- DB-control: глобальный порядок времени, конкуренция записи агентов (Тождество зависит от них).

**Затрагивающие сценарии:** три свидетеля (Opus-1) · композиция (Sonnet-1) · рассинхрон часов.
**Соседние:** Витальность (что метаболизирует), Реляционность (варианты/связи).
