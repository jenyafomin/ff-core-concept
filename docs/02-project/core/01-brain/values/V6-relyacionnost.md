**Несёт цели:** Г16 (мультиарендность) · Г17 (конфликт видим третьему) · Г25/Г28 (варианты-веер, ветки) · Г32 (наследование/переиспользование) · ребро-инсайт «A→B» как единица памяти.

**Идеи / куда копать (L2):** property-graph / RDF-star (ребро-с-паспортом) · git-ветка (варианты, `variant-of` + активная ветка) · шаблон→экземпляр (наследование) · различать `derived-from` (падает с родителем) vs `caused` (переживает, Opus #2) · ссылочная целостность и сироты-рёбра (DB-control).

**Открытые вопросы:** В4 (ребро-с-паспортом — принято, узко) · деградация СВЯЗЕЙ, не данных (ребру нужен свой `stale`, Sonnet #7) · циклы в графе (DB-control) · конфликт линз разных ролей (Sonnet #6).
