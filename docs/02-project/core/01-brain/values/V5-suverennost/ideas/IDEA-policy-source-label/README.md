# IDEA — Метка источника политики (`policy_source`)

Каждая ячейка несёт поле `policy_source`: `system-default` / `user-defined` /
`agent-proposed+user-approved`. Позволяет отличить «суверенитет по умолчанию, не тронутый владельцем»
от «суверенитет, реально утверждённый владельцем» — без этой метки движок и агенты не знают, чью волю
на самом деле исполняют.

**Относится к под-грани:** п.1 (self-describing), п.8 (конституционный потолок), тема A (авторство/владение).

**Открытые вопросы:** нужен ли отдельный статус «ожидает суверенизации» для ячеек, чья политика ещё
не подтверждена владельцем явно? Совпадает ли это поле с полем авторства узла (кто создал), или это
разные оси (создатель ≠ автор политики)?
