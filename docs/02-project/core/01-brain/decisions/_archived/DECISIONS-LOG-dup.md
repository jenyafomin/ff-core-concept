# Brain — журнал решений (замки)

> Тип: `decisions` (см. реестр типов). Сюда — только ПРИНЯТЫЕ замки по единице памяти.
> Открытые развилки живут в `../open-questions/INDEX.md`, не здесь.

## Замки (ратифицировано боем / владельцем)

- **Единица = роль/цикл, не тип.** Определяется тем, как ведёт себя в графе, а не «какого типа файл».
- **Хребет — три уровня:** Конституция > policy-as-data > integrity-as-engine-duty (доверие/источник/согласие текут по графу).
- **Брейн = 4 плана существования** + «Биография» как род узлов.
- **Под-ячейка = узел-Профиль** (не «этаж»), + нулевое правило «вещь ⟂ встреча».
- **Дом ратифицирован** практикой (CRM/InstaApp).
- **В2 — bitemporal** (два времени: когда произошло / когда узнали).
- **В4 — паспорт есть и у ребра** (ребро — полноценный узел с происхождением).
