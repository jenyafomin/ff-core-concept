# Рост домена — INSERT, не миграция

> Схема (2 таблицы: узлы, рёбра) не меняется от крошечной БД до огромной. Рост = добавление СТРОК в
> реестры (node-type, edge-type, view-def, VariantGroup), а не ALTER TABLE.

## Три оси роста
1. **Новый node-type** — INSERT строки реестра (смысл, паспорт-поля сверх общих, форма payload). Пример:
   понадобился тип «событие» — не создаём таблицу `events`, добавляем строку `event` в `node-types.md` +
   реестр, старые cell/document не трогаем.
2. **Новый edge-type** — INSERT строки в seed-реестр рёбер, с гейтом (объявленная policy, не свалка
   синонимов — риск, названный консилиумом). Пример: понадобилось «tension-with» для диалогового графа —
   добавили тип, endpoint=canonicalId, класс (assertion) сразу заявлен.
3. **Новый view/flow** — INSERT `view-def`, не новая таблица агрегатов. Пример: нужен «дайджест за неделю»
   — не пишем ETL-джобу в отдельную таблицу, декларируем обход + фильтр по bitemporal.

## Сценарий роста (иллюстрация)
- **День 1**: одна заметка = один `cell`, паспорт пустой (дефолты), payload = текст. Ноль рёбер.
- **Неделя 1**: заметки начинают ссылаться друг на друга → появляются `assertion-edge` (`caused`,
  `refines`). Реестр edge-type пополняется по мере надобности, не заранее.
- **Месяц 1**: заводится первый `container` (папка-проект) + `member-of`; первый `policy-node` (напр.
  Ц-7 Согласие для приватных заметок).
- **Год 1**: домен полон `document`, `event`, `concept`, `VariantGroup` для конфликтующих версий факта,
  `view-def` под разные проекции (по проекту / по времени / по доверию). Схема БД — та же с дня 1.

## Что подтверждает retrofit-cost-гейт (Н-6)
Три «заложить сейчас» инварианта (тип ребра из реестра, endpoint=ID, DAG на derived) существуют именно
потому, что их нельзя дописать задним числом без миграции по данным. Всё остальное (view, поток,
папка-как-узел, реактивный триггер) — сознательно отложено, потому что дёшево добавляется INSERT-ом позже.

## Открыто
Нет ещё явного правила «когда добавление edge-type требует ревью, а когда происходит само» — риск свалки
синонимов назван (консилиум B), но процесс гейта не описан здесь, только упомянут.
