# Вопрос: осознанна ли промоция F2/F3/F4 в критические 20% граней?

## Суть
Census-синтез 2026-08-06 в ОДНОМ документе противоречит сам себе: §1-матрица метит F2/F3/F4 как `🟥 БЛОК`,
а §2-рекомендация относит их в «отложить-с-домом» без видимой аргументации разрыва. Отдельно: первоисточник
называет F3+F4 ОДНОЙ «глубочайшей механической дырой» (одна write-гонка journal-fsync / blob-write), но
синтез разрезал пару и словом «runner-up» понизил F3 отдельно от F4. Нужно подтверждение владельца перед S4+.

## Варианты (без вердикта)
- **(А)** даунгрейд был осознан → F2/F3/F4 остаются «отложить-с-домом», топ-критические = F6 + §9-4 только.
- **(Б)** разрыв = неаккуратность свода карт → F2/F3+F4 промотируются в критические 20-26% (текущая
  рекомендация ноды после критик-проверки).
- **(В)** частично — F2 промотировать, F3+F4 оставить отложенными (или наоборот) с явным основанием.
- **Отдельно:** держать F3+F4 ПАРОЙ (по первоисточнику) или есть основание разносить их.

## Рычаг
Прямой вход в pre-S4 ворота — владелец ратифицирует список «критических 20% граней» ДО первой сессии S4.
Эта карточка = готовый черновик под подтверждение/правку одним проходом, не сбор с нуля.
