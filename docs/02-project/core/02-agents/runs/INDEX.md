# runs — реестр агентских прогонов (ТОЛЬКО ссылки)

> Место, где видно «кто / что / сколько контекста делает». Сами результаты работы
> лежат в документах доменов; здесь — лёгкий журнал-указатель.

Что сюда кладём (только строки-ссылки, не тела):
- `YYYY-MM-DD — роль/модель — задача — контекст-бюджет — → ссылка на артефакт`.
- Никакого сырья и полотен: тело работы всегда в целевом документе.
- Правило: строка добавляется, не удаляется; журнал растёт вниз по дате.
