# 📍 01-state — механизм STATE (L1, читать ПЕРВЫМ)

> **Переехало 2026-07-19** из `01-brain/state/` (L1-def). Дом механизма `state` в модуле оркестрации:
> узел `state`, обновляемый актами; глобальное состояние + состояния планов + состояния агентов.
> Единая точка «на чём мы сейчас». Тонкий указатель: истина — по ссылкам, здесь срез + лог.
> ⚠️ Пока форма — md. Цель: **состояние = первоклассный механизм в базе** (узел `state`, обновляемый
> актами; глобальное состояние + состояния планов + состояния агентов) — проектирует архитектор (в работе).

## Модель состояний (замысел владельца)
- **Наше состояние** — то, в котором мы общаемся/проектируем (это).
- **Состояния агентов** — каждый агент несёт своё (в промпте/топике), читает первым, обновляет во времени.
- **Состояния планов** — фокус на цели плана; логируют выполненное.
Все — одна механика `state`, разные экземпляры. Читается первым, чтобы держать фокус и не терять контекст.
