## Три карты (для кого какая)
- **Эта `INDEX.md`** — для человека (владельца): где что, куда идти. 🟢
- **`concept.json`** — для машины/агента-навигатора: решения, вопросы, next-moves. 🟢
- **Мета-слой «система о самой себе»** — новая идея владельца: данные, что описывают, ЧТО есть и к чему
  обращаться, чтобы САМ агент понимал устройство (тоже узлы в базе). 🔜 на совете у Fable (D-meta).

## Решения (Fable ответил — ждут ратификации владельцем)
- **Q-12 форма `view`** ✅ Fable: 4-стадийный запрос `from·traverse·filter·shape+params`, filter читает конверт → права = тот же запрос (DEC-11).
- **Q-13 инверсные рёбра** ✅ Fable: хранить одну сторону, инверсию вычислять индексом `_generated/` (DEC-12).
- **D-meta слой** ✅ Fable: типы/предикаты = узлы `meta:`, регрессия обрывается `meta:type/type`; «карта системы» = сама `view:system-map`; `example` обязателен (DEC-13).
- Ещё висят: Q-8 дубль edges/body · Q-9 стопкран лупа · Q-10 учёт затрат (дерево/прямые) · Q-11 делить ли space/role.
- Разбор совета: `../../../../_log/2026-07-23-agent-manager-example/FABLE-ADVICE.md`
