# _schema — общий язык всех примеров

> **Зачем поднято сюда.** Конверт узла (системные поля), словарь предикатов и понятие политики —
> это НЕ про agent-manager, а про **любую** нашу систему-пример. Поэтому живёт на уровне контейнера
> `examples/` как общий фундамент. Каждый конкретный пример (`01-agent-manager/…`) лишь **применяет**
> этот язык к своим типам узлов.

## Что здесь общего (переиспользуется каждым примером)
- **`envelope.md`** — системный конверт: `id · type · state · edges · view(lens) · visibility · access · acts · policy_ref` + `body` (обычные поля).
- **Словарь предикатов и инверсий** — канонические пары рёбер (прямой/обратный), чтобы граф читался с обеих сторон.
- **Понятие `policy`** — настройка поведения как ДАННЫЕ (first-class гибкость).

## Что остаётся в конкретном примере
- Список **типов узлов** этой системы (у agent-manager: agent/user/project/…).
- **Обычные поля** каждого типа (`body`).
- **Применение** политик/линз под свои механики.

## Правило
Если приём/поле оказалось нужно ДВУМ+ примерам — оно поднимается СЮДА (в `_schema`), а не копируется.
Специфика примера — вниз, в его папку.
