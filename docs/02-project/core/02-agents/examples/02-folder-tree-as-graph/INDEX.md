## Связь с `01-agent-manager` (что берём, где НЕ повторяем ошибку)
- **Берём:** общий конверт (`_schema`), закон «конструктор не массив», два навигатора, пары рёбер,
  петлю качества (делаю→агентам→сам перепроверяю→циклич. вопросы).
- **НЕ повторяем:** там модель «разошлась сама с собой» — накидали 13 единиц, но ни одну не завернули
  в конверт (B1) и не прогнали на данных → вердикт «условно-НЕТ». Здесь: **сначала ОДИН killer-кейс на
  реальных папках**, потом ширина.
