# 💡 Idea — межагентная коммуникация

> **Захват, не стройка.** Владелец накидал параллельно (голос, 2026-07-27) во время планирования M1.
> Фиксируем узлом, чтобы не потерять; в текущую стройку (M1-инжест аренды) НЕ входит.

## Суть (как сказал владелец)
Дополнительная возможность **взаимодействия между агентами**: чтобы агенты **понимали друг друга**,
имели **канал/чат** между собой, и у них были **разные нюансы коммуникации** — не только «оркестратор
раздал → собрал», а агенты могут общаться/уточнять напрямую.

## Зачем (гипотеза ценности)
- Сейчас координация = звёздная (оркестратор в центре, агенты слепы друг к другу). Прямой канал →
  агенты сверяют находки, не дублируют, ловят противоречия раньше синтеза.
- Связано с «агенты понимают ЗАЧЕМ работают» (глобальный контекст, не плоская задача).
