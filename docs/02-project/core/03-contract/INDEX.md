# 03-contract — интерфейс brain ⟷ агенты

> ⟷ УЗЕЛ СВЯЗИ двух ядер. Что brain выставляет наружу и что агенты обязаны соблюдать,
> когда читают/пишут граф. «Клапан» доверия — только на внешние необратимые действия.

Что сюда кладём:
- Контракт чтения: как агент видит узел/паспорт (всё видно ИИ; ИИ не ограничен).
- Контракт записи: как агент пишет обратно, эпистемический статус = метка, не стена.
- Границы: что агент НЕ имеет права (клапан на необратимое, согласие референта).
