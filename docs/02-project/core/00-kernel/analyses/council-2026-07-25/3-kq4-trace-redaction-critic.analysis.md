# KQ-4 · Критик-прогон: редакция trace-ноги (I-7 / тест T-5)

**Мой исходный лин:** trace хранит указатели, не значения → зажимать на ЧТЕНИИ (clamp-on-read),
field-ссылки ре-резолвятся под читателя; вариант 1 (writer редактирует на записи) слабее.

**Вердикт критика: `AMEND`.** Лин чинит не ту сторону.

## Сильнейшее возражение
Утечка в реальном сценарии T-5 происходит на **ЗАПИСИ**, не на чтении:
- trace может писать **сырой pre-filter вывод** (что вернули `from`/`traverse`) ДО стадии `filter`, где
  зовётся `resolve()` → значение уже сериализовано в лог, который `resolve()` не гейтит. Зажимать на
  чтении **поздно**.
- LLM пишет **свободный текст**, а не «структурные field-ссылки» → перефраз-утечка («зарплата высокая»)
  не ловится детерминированно (ломает I-9 fail-closed как поведение).
- trace живёт в `_log/` **plaintext, gitignored** → сырой `Read`/`cat` обходит `resolve()` целиком (это и
  есть путь-в-обход PEP, запрещённый I-7). Clamp-on-read — свойство ГЕЙТИРОВАННОГО пути запроса, а такого у
  сегодняшнего trace нет.

## Минимальное правило, чтобы T-5 реально проходил
1. **Хукать trace-инструментацию ПОСЛЕ стадии `filter`** (после `resolve()`) — trace пишет то, что агент
   ПОЛУЧИЛ в контекст, а не сырой возврат traversal/retrieval. CI-проверяемо (в trace нет ничего, чего нет
   в гейтированном выводе ног 1/2/3).
2. Free-text-остаток (chain-of-thought, перефраз) — **честно метить `OPEN / bounded-not-closed`**, не PASS.
3. Пока trace не стал `resolve()`-гейтированным узлом/путём — **гейтить доступ к trace на уровне
   сессии/файла** (читатель = superset-права автора trace), а не пытаться зажимать по-полю. Детерминированно,
   fail-closed-совместимо, не требует решать free-text редакцию.
4. **KQ-8 = жёсткое предусловие**, не сноска: append-only trace + запрос стирания = структурный конфликт
   (значение, записанное в trace, нельзя ретроактивно вычистить, не нарушив append-only).

## Напряжение, которое надо назвать
Полная объяснимость (T-7 explain-chain: цепочку видит владелец/ops) ↔ полная защита от утечки (T-5).
Это реальный trade-off, а не деталь — зафиксировать в ADR, который закроет KQ-4.
