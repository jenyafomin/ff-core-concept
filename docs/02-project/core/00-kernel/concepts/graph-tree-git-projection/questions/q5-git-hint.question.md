# Q5 — git подсказывает направление: когда закладываем?

## Контекст
Ты сказал: сам git может подсказывать путь и направление (по тому, как акты идут по веткам).

## Вопрос
«Git подсказывает направление» — это:

- отдельный проектор / вид работы, который читает историю веток и предлагает путь, Фаза 2 и дальше, или
- крючок, который закладываем в модель уже сейчас (чтобы потом было куда встроить)?

## Почему важно
Это про то, тратим ли мы силы на это сейчас или помечаем как будущее и идём дальше.
