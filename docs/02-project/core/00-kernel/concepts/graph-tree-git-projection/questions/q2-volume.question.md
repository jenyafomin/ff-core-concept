# Q2 — что живёт в коде/git, а что в графе?

## Контекст
Ты сказал: держать всё вместе тяжело; часть фактов пусть живёт по веткам в коде.
Значит нужен порог: что поднимаем в граф, что оставляем в коде.

## Вопрос
Где проходит водораздел?

- В коде / git-ветках: какие типы? (догадка: сырые факты, детали, трейс изменений)
- В графе: какие типы? (догадка: акты, связи, паспорта узлов, политика доступа)

## Опора (уже решено, не переоткрываем)
ADR-0006 уже говорит: одна адресуемая модель над многими хранилищами. То есть git — это
ещё одно хранилище под графом, а не отдельный мир. Вопрос лишь — что куда кладём.

## Почему важно
Это решает объём и производительность: граф не должен раздуться до неподъёмного.
