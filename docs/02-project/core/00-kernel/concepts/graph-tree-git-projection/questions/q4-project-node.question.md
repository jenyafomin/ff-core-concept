# Q4 — что такое проект в графе?

## Контекст
Ты сказал: проект можно сохранить целиком отдельно, но его видимость надо разбивать
на под-пункты для описания (не всё-или-ничего).

## Вопрос
Проект — это:

- один узел с гранулярной видимостью (видимость настраивается по полям, как зарплата у person), или
- под-дерево узлов (проект раскладывается на много связанных узлов)?

«Разбить видимость на под-пункты» — это про политику на полях одного узла, или про
декомпозицию проекта на части?

## Почему важно
Это решает, как проекты живут рядом и как безопасно показывать их части разным агентам.
