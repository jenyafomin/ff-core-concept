# Q3 — как git относится к графу?

## Контекст
Ты говоришь об актах по разным веткам и о том, что git может подсказывать путь.
Надо понять, чем ветка является для графа.

## Вопрос
Git-ветка — это:

- проекция / вид на узел (граф главный, ветка это его отражение), или
- отдельный scope / тип узла (ветка это самостоятельная сущность в графе)?

И «акт по ветке» (коммит) — граф его хранит как свой акт (наблюдение), или git это просто
внешний сигнал, который граф читает, но у себя не держит?

## Почему важно
От этого зависит, синхронизируем ли мы git и граф или граф просто читает git снаружи.
