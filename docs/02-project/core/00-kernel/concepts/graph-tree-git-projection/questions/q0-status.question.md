# Q0 — чем является связка граф-дерево-git для базы?

## Контекст
Ты сам сказал, что не уверен: это либо база учитывает это как тест, либо как доп-функционал,
либо как взаимосвязку. Это важно решить первым — от статуса зависит, куда концепт вообще растёт.

## Вопрос
Чем это является?

- A — тест / полигон. Проект (agents-manager) = проверочный жилец, на нём обкатываем связку.
- B — доп-функционал. Отдельный модуль связи граф-git поверх ядра, опциональный.
- C — взаимосвязка / ядро. Это фундамент: как вообще устроен субстрат.

## Подсказка (по твоему принципу свойств)
Может быть не или-или: стартуем как A (тест), где проверяем C (взаимосвязку), а B — то, как
плагин её выставляет наружу. Но мне нужно твоё направление, с чего заходить.

## Почему важно
Статус решает всё дальнейшее: тест = быстрый эксперимент; ядро = проектируем строго и надолго.
