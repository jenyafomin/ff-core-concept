- **Родитель:** `../INDEX.md`
- **Внешние источники:** `github.com/agentpatternscatalog/patterns` · `github.com/nibzard/awesome-agentic-patterns` (+ смежные)

## Scope этого направления
Снять **каталог паттернов агентных систем** (форма цикла, память, видимость инструментов, верификация/аудит/стоп,
multi-agent, routing, reflection и т.д.), отобрать **релевантные нам**, и показать, **как они ложатся в нашу базу
как узлы графа** (паттерн = узел с id/типом/связями) — чтобы дополнять их своими.

## Наполнение (растёт; file-first)
- `catalog/` — паттерны как записи (по одному файлу/паттерн или сводный реестр)
- `analyses/` — `*.analysis.md` — отбор релевантных, маппинг на наш граф/ценности
- `questions/` — открытые вопросы и связки к A/B
