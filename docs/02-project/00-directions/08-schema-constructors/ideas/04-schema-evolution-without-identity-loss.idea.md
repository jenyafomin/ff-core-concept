# Идея 04 · Эволюция схемы без потери тождества

> ⚗️ Reserved-Form. Опирается на только что построенный edge-identity/`canonical_id` — надстройка, не переоткрытие.

## Суть
Схему и тип НАДО усложнять (это цель направления) — но усложнение НЕ должно ломать **тождество** уже
существующих единиц и связей. Единица может сменить тип, обрасти гранями, слиться с другой — и остаться
СОБОЙ: `canonical_id` и история merge/split переживают эволюцию. «Меняем не теряя себя» (Ц2) — буквально.

Это критичный шов с недавней работой: **edge-identity / `canonical_id`** уже построены (спайн-ночь, форма
D4). Данная идея — как эволюция схемы садится ПОВЕРХ этого тождества, не подрывая его.

## Как усложнять, не теряя себя
- **Тождество отделено от схемы.** `canonical_id` — не производная от текущего типа/полей. Меняем схему →
  id стабилен. Тип единицы = грань, а не её сущность (уже заложенный разрез «ядро/грань = цель в форме данных»).
- **Эволюция как версия типа, не подмена.** Тип v2 добавляет грани к v1; единицы v1 не теряют id и историю,
  а мигрируют аддитивно (или живут как есть). Никогда «стёр старый тип, создал новый».
- **Merge/split — операции с паспортом.** Слияние двух единиц и разделение одной несут провенанс: кто/когда/
  почему, обе истории сохраняются (LOSE-NOTHING). Ребро тоже несёт своё тождество (Ц6) → не плодим сироты.
- **Supersession, не удаление.** Устаревшая версия схемы/типа помечается superseded со ссылкой на новую;
  единица переосмысляется (Ц4 Витальность), а не обнуляется.

## Привязка к ценностям
- **Ц2 Тождество** — несущая. `canonical_id`, история merge/split, стабильность при смене типа/варианта.
- **Ц4 Витальность** — единица переосмысляется и консолидируется по мере роста схемы, оставаясь живой.
- **Ц6 Реляционность** (косвенно) — эволюция схемы связей сохраняет паспорт ребра и ссылочную целостность.

## Риск, названный честно
🔴 **Тихая подмена идентичности.** Loop-агент (идея 02), «улучшая» тип, может по неосторожности пересоздать
единицы → новый id → потеря истории. Это ровно то, что нельзя сделать retrofit (вопрос б). Инвариант
«эволюция не трогает `canonical_id`» должен быть СИСТЕМНЫМ правилом (идея 01), не управляемым.
🔴 **Раздувание истории.** Полная история всех merge/split/версий может расти неограниченно (стык с Ц1/Ц4).
