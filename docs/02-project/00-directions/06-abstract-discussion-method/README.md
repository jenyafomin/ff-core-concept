# D6 · Метод «абстрактного обсуждения» (линза над результатами волн)

## Маркер узла
- **Что это:** НАПРАВЛЕНИЕ-МЕТОД (method-idea). Из метаинструкций владельца.
- **Scope:** GLOBAL (метод/процесс, метá над всеми направлениями).
- **Тип:** метод-идея.
- **Зависимости:** метá над D1-D5; дополняет `recursive-orchestration-method`.
- **Статус:** draft · needs-home.
- **Предлагаемый постоянный дом:** `01-organization/` — расширить `recursive-orchestration-method`
  (мандат помощника уже частично покрывает) ИЛИ новый метод-узел. Правки метода — через `agent-builder`
  + одобрение владельца (R1). needs-home.

## Ответ владельца (вербатим-по-смыслу, N-001…N-004)
- Работать МИКРОЗАДАЧНО, командами агентов, не упуская нюансов/деталей (N-001).
- FILE-FIRST, два режима: где-то лог, где-то явно «в боксах» и толкать дальше. Многое сохранять СРАЗУ
  ЦЕЛОЙ ПАПКОЙ с маркером (глобально/локально · зависимости · идея/вопрос/начало) — узел-папка под рост (N-002).
- Смотреть ~10 ШАГОВ ВПЕРЁД: как будем ЗАПОЛНЯТЬ структуру; планировать наперёд, но экономно (токены) →
  ВОЛНАМИ, потом выход на АБСТРАКТНЫЙ уровень, обсуждение, дальше (N-003).
- **Возможно завести ОТДЕЛЬНОЕ направление «абстрактного обсуждения»:** смотрит на результаты команд и
  на их основе помогает ВЫБИРАТЬ, КУДА двигаться дальше (N-004).
