# 02 — Проект FF (ЧТО мы строим)

> Домен «сам продукт». FF = организационный уровень + два тулза внутри, которые надо ЯВНО связать:
> **brain** (единица памяти) и **система агентов** (руки). Фундамент под ними — субстрат (граф узлов).

Что сюда кладём:
- **substrate/** — фундамент: граф узлов / БД / движок как ПРОДУКТ (не каноны-правила — те в 01-organization/data-canon).
- **core/** — два ядра и их СТЫК:
  - `01-brain/` — единица памяти (проектируется сейчас).
  - `02-agents/` — система агентов через Telegram (+ реестр прогонов).
  - `03-contract/` — ⟷ КОНТРАКТ brain↔агенты (память = руки; кто читает/пишет граф).
- Цель проекта ≠ обязательно продукт: сюда же — цели, гипотезы, что за боль решаем.
