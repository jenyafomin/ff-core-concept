# 70-ideas — Ideas and Research Tasks

**Group purpose:** Unvalidated ideas, feature candidates, and research task stubs.
Low commitment — this is the inbox before ideas get a proper spec.

## What lives here
- `IDEA-topic.md` — a rough idea not yet validated
- `TASK-topic.md` — a research or investigation task stub

## Ordering rule
No date prefix — sorted alphabetically by topic.
When an idea gets validated and becomes a spec → move stub to 90-historical, write SPEC in 00-canon/SPEC/.

## Process
- Ideas arrive here raw (from owner voice, telegram, brainstorm).
- Validated idea → Spec → 00-canon/SPEC.
- Rejected idea → add `Status: rejected` comment, leave file (history).
