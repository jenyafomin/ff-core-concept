# Рабочая папка топика «Читатель памяти» (gw-reader v0)
- **Status:** experimental · **Owner:** jenya.stasik@gmail.com · **Date:** 2026-10-12
- **Потребитель:** агент топика, привязанного сюда (`/bind` или `config.json {"cwd": ...}`) · **Поглощает:** ничего
- **Related:** `docs/architecture/ADR/ADR-0018-gateway-log-reader.md` · `packages/gw-reader/README.md`

Только этот cwd подключает MCP `gw-reader` (ADR-0018, M2: не во всех топиках). Читатель: только чтение лога шлюза,
секреты скрываются ДО модели, пересланное и чужие исключены. Метки открыто/закрыто/не напоминать — в `~/.ff-gw-reader/labels.jsonl`.

## Протокол агента в этом топике
1. На «что у меня открыто?» → `gw_recent` (по умолчанию 14 дней) → ≤10 кандидатов с адресами `gw:…`.
2. Владелец ставит метку → `gw_label`. Ничего не пишем в мозг (он не запущен), не копируем тексты в файлы.
3. Если видишь `redacted` — не пытайся восстановить скрытое.
