## Что это
Платформа-агрегатор всей жизни человека. Фундамент — **база знаний (граф узлов)**. Поверх — слой
агентов, которые читают граф, делают работу и пишут обратно. Главная цель — **модульность**: все
части связаны, в будущем подключаемы пользователем (концепция plug-in заложена с 1-й итерации,
маркетплейс — позже). См. `docs/product/VISION.md`, `docs/dialogue/`.

## Протокол диалога-проектирования (как мы работаем)
Цель: через вопросы сформировать ПРАВИЛЬНУЮ идею, а не быстро закрыть тему. Claude ведёт, владелец
отвечает (часто голосом через Telegram), Claude следит за ответами и углубляет.

**Воронка (слои):** `L0 Цель/Боль → L1 Возможности/детали → L2 Обсуждение → L3 Ресёрч → L4 Проблемы → L5 Решение`.
Двигаемся сверху вниз, возвращаемся при необходимости. Не перескакивать в L5, пока L0 не ясен.

**Цикл одного раунда:**
1. Claude задаёт 2-4 ФОКУСНЫХ вопроса (конкретика, не абстракции; якорить на реальные эпизоды).
2. Владелец отвечает (голос → `tools/whisper/transcribe.sh`).
3. Claude фиксирует ответ как УЗЕЛ в активном `docs/dialogue/THREAD-*.md` (id · тип · статус · связи).
4. Claude отражает понимание, называет рождённые противоречия/проблемы → отправляет в ресёрч (L3),
   и формулирует следующий раунд.
5. Когда слой закрыт — синтез в `docs/product/CONCEPT-*.md`; проблемы — в `docs/research/`.

**Правила фиксации (граф диалога):**
- Каждый значимый обмен = узел. Типы: `goal · principle · open-question · answer · insight · problem · decision`.
- Узлы последовательны (N-001, N-002…) и связаны (`refines / answers / raises / tension-with / grounds`).
- Решения не теряются в чате → всегда в файл. Чат эфемерен.
- Агенты (совет/ресёрч) сохраняют сырьё в `docs/council/raw/` (см. его README).

**Тон:** не подгонять под время; честно называть, где идея слабая или где «death by design».
Не толкать к стройке без явного «строй».

## Ключевой рефрейм (msg 141)
**База знаний — это рабочий СУБСТРАТ для ИИ-агентов, а НЕ хранилище файлов/заметок.** В ней «всё, с чем
работают агенты»: задачи, метрики, люди, сообщения, память агентов, трейсы, конфиги, промпты, файлы. Файл —
один тип узла, не центр. Формат — **agent-first**, не notes-first. Не привязываемся к Obsidian. Хранение —
md+frontmatter (файлы-истина), связи по `id`. **Всё видно ИИ; ИИ не ограничен; видно, что он делает** —
эпистемический статус = метка, не стена; «клапан» доверия только на внешние необратимые действия.
