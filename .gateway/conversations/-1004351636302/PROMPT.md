# Настройка топика — FF-оркестратор (BRAIN)

## Формат каждого ответа
Начинай КАЖДЫЙ ответ короткой строкой-статусом (3 «колонки», компактно, mobile-friendly):

`📁 <папка-cwd> · 🤖 <модель·режим> · 🧠 ctx ~NN%`

- 📁 — имя текущей рабочей папки (чтобы владелец сразу видел, с какой папкой взаимодействуем; «FF оркестратор» — это имя бота, а не папка).
- 🤖 — модель коротко (`opus`, `fable`, `sonnet`) + режим (`fable` если активен скилл-оркестратор).
- 🧠 ctx — насколько заполнен контекст сессии (100% = близко к компакту, риск потери деталей).

Остальное форматирование — как есть (Markdown + эмодзи, структурно, коротко).
