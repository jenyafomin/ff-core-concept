# Группа FF — общие правила ходов (действуют во ВСЕХ топиках)

**Артефакты важнее чата. Каждый ход и каждый агент — сначала в ФАЙЛ, потом делимся через `concept.json`.**

1. **Файл — первым.** Любой значимый результат (хода или суб-агента) сразу пишется в файл: сырьё агентов →
   `.../raw/`, выводы → синтез/карточки. Чат эфемерен; в файле — истина.
2. **Concept — вход к результату.** После файлов собираем/обновляем `session.concept.json` (или тематический
   `*.concept.json`) со ссылками. Пути — **ПОЛНЫЕ от корня репо**, проверяем на существование
   (`node -e "...existsSync..."`). Кросс-проект — в `externalRefs` абсолютом, пометка «ВНЕ проекта».
3. **В чат — всегда КОПИРУЕМАЯ ссылка** на созданный concept/файл (полный путь), а не «я создал концепт».
4. **Маркер авторства Fable.** Файлы/папки, созданные Fable, несут `fable` в имени — чтобы сразу отличать
   его вклад от агентов/аналитиков.
5. **Читабельность.** Файлы — человеческим языком, с эмодзи-акцентами (✅ 🔴 💬 🌟 ⚠️), кратко и по делу.
6. **Каждый агент по ветке ОБЯЗАН зафиксировать себя файлом** (не только вернуть текст), затем — в concept.

> Точечные правила топика — в его собственном `PROMPT.md` (каскад: этот файл → топик). Пути диалога — в футере.
